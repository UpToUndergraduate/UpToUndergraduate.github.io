# 2.3 单元格格式与数据有效性

> **考纲对应**：电子表格处理 第 3 条——掌握设置数据有效性和设置单元格格式的方法；第 4 条——掌握格式刷、边框、对齐等常用格式设置（层次：掌握）
> **教材对应**：单元 2 · 任务 2.1 建立学生成绩表

同一份数据，设成文本会左对齐，设成数值会右对齐，设成百分比会带上百分号——单元格格式决定了数据"看起来是什么样"，也影响计算能否正常进行。本节讲两件事：一是「单元格格式」对话框里的六张选项卡，二是用数据有效性把不合规的输入挡在门外。

## 一、单元格格式设置

### 1. 打开「单元格格式」对话框

选中单元格或区域，按 `Ctrl+1`，或右键→「设置单元格格式」。对话框含六张选项卡：数字、对齐、字体、边框、图案、保护。多数格式问题都能在这一个对话框里解决，比在功能区逐个按钮点击更准确。

### 2. 数字格式

| 格式类型 | 输入 1234.5 后的显示效果 | 典型用途 |
|---|---|---|
| 常规 | 1234.5 | 不做特殊处理，默认格式 |
| 数值 | 1,234.50（可设小数位数、千位分隔符） | 成绩、数量 |
| 货币 | ￥1,234.50 | 金额 |
| 会计专用 | ￥ 1,234.50（货币符号单独对齐） | 财务报表 |
| 日期 | 2026/11/28 | 出生日期、考试日期 |
| 时间 | 14:30:00 | 作息时间、比赛用时 |
| 百分比 | 123450.00%（输入 0.85 则显示 85.00%） | 及格率、增长率 |
| 分数 | 1/2（需先设为分数格式再输入） | 特殊表示方式 |
| 科学记数 | 1.23E+03 | 极大或极小的数 |
| 文本 | 001、4201… 原样保留 | 学号、身份证号、电话号码 |
| 特殊 | 中文大写数字、中文小写数字 | 票据金额 |

要点辨析：
- 数值格式只改变**显示**，不改变存储的实际值。`1,234.50` 参与计算仍是 1234.5，设置两位小数只是显示上四舍五入，实际值未变。
- 设为「文本」后，输入的数字按字符串处理，左对齐显示，`SUM` 求和会把它当作 0 忽略。
- 学号、身份证号、手机号这类长数字，若不先设为文本，超过 11 位会自动变成科学记数，末尾数字被舍入，数据永久失真。

除表中所列的类型外，「数字」选项卡的最后一项是「自定义」，可在「类型」框中直接书写格式代码：`0.00` 表示固定保留两位小数，`#,##0` 表示带千位分隔符且不留小数，`0%` 表示按百分比显示，`yyyy"年"m"月"` 可把日期显示为"2026年11月"。自定义格式同样只改变显示，不改变单元格里的实际值，删除格式后原值依旧完整。

### 3. 对齐、字体、边框、图案

- **对齐**：「水平对齐」「垂直对齐」各有靠左、居中、靠右、填充、两端对齐、分散对齐、跨列居中等选项；勾选「自动换行」让长文本在单元格内折行；「合并单元格」把选中的多个单元格合并成一个。需要提醒的是，合并后只保留左上角单元格的内容，其余单元格的内容会被丢弃；合并区域一旦参与排序、筛选或数据透视，也容易报错，所以表头之外的区域尽量不要合并。
- **字体**：字体、字形（加粗、倾斜）、字号、颜色、下划线；「普通字体」按钮可一键复位。
- **边框**：先在「线条」区选样式与颜色，再点「预置」中的「外边框」「内部」，或直接在预览框上点某一条边。只在预览中能看到线才算真正加上。给整张表加线的常用做法是选中数据区域后点「边框」按钮旁的下拉箭头，选「所有线框」，再对表头单独加粗外框。
- **图案**：填充单元格底色，可调图案样式与颜色。
- **保护**：勾选「锁定」「隐藏」，但只有在「审阅」→「保护工作表」之后才真正生效。

### 4. 格式刷

「开始」选项卡左部的格式刷按钮（刷子图标）：先选中已设好格式的单元格，单击格式刷，再单击或刷过目标区域，格式即被复制。

- 单击格式刷只能用一次，刷完自动弹起；
- 双击格式刷可连续多次使用，按 `Esc` 或再点一次格式刷按钮退出；
- 格式刷复制的是格式（数字格式、字体、对齐、边框、底纹），不复制内容，也不能复制数据有效性和条件格式。

**例 2.3-1** 把成绩表的标题行 `A1:F1` 设为：黑体、加粗、水平垂直居中、浅灰底纹、四周及内部细边框，并把这一格式套用到另一张工作表的表头。

**解**

1. 选中 `A1:F1`，按 `Ctrl+1` 打开「单元格格式」对话框。
2. 「字体」选项卡中把字体设为黑体，字形选「加粗」。
3. 「对齐」选项卡中「水平对齐」与「垂直对齐」都选「居中」。
4. 「图案」选项卡中选一种浅灰色作为单元格底纹，点「确定」暂不关闭也行。
5. 「边框」选项卡中先选细实线，再依次点「外边框」和「内部」，预览框四条边与中间格线都出现线条后点「确定」。
6. 双击「开始」选项卡中的「格式刷」，切换到另一张工作表，刷过对应的表头区域，完成后按 `Esc` 退出格式刷。

- **易错点**：① 只设「居中」不等于「合并居中」，前者只调整文字位置，后者会合并单元格并可能影响排序；② 边框只点「外边框」不会给内部加线，需要再点「内部」；③ 双击格式刷后忘记按 `Esc`，会一直处于刷格式状态，误点其他单元格也会被改格式；④ 整列选中后设置字体，会把表头和数据一起改掉。

## 二、数据有效性

### 1. 作用与入口

数据有效性（新版 Excel 中称"数据验证"）用于限定单元格能输入的内容范围，例如分数只能填 0~100 的整数、性别只能从下拉列表中选择。入口在「数据」→「有效性」，打开「数据有效性」对话框，含「设置」「输入信息」「出错警告」三张选项卡。

### 2. 设置选项卡

- 「允许」下拉：任何值、整数、小数、序列、日期、时间、文本长度、自定义。
- 选整数、小数、日期、时间、文本长度时，还需在「数据」下拉中选条件（介于、不介于、等于、大于、小于等），再填最小值与最大值。
- 选「序列」时，「来源」可以直接键入各项，**项与项之间用英文逗号分隔**，如 `男,女`；也可以点右侧折叠按钮后选取一个单元格区域，如 `=$H$1:$H$3`，这样选项随区域内容变化。
- 勾选「提供下拉箭头」，单元格右侧才会出现下拉按钮；勾选「忽略空值」则允许留空。

### 3. 输入信息与出错警告

- **输入信息**：选中该单元格时自动弹出的提示框，可填标题与提示内容，告诉录入者该填什么、范围多少。
- **出错警告**：输入不合规时弹出的对话框。「样式」有三种：「停止」最严格，直接拒绝并保留原内容；「警告」询问是否继续；「信息」仅提示，仍可继续输入。违规输入要彻底挡回去，必须选「停止」。

### 4. 修改、清除与复制

选中已设有效性的单元格，再点「数据」→「有效性」即可查看和修改；点「全部清除」取消限制。有效性随单元格复制粘贴而复制到目标区域，但**格式刷不能复制有效性**——这是考试中常见的陷阱。

**例 2.3-2** 成绩表中 C2:C41 为"性别"列，要求只能从"男""女"中选择；D2:D41 为"语文"分数列，要求只能输入 0~100 的整数，输入错误时提示并拒绝。

**解**

1. 选中 `C2:C41`，点「数据」→「有效性」，打开对话框。
2. 在「设置」选项卡中，「允许」选「序列」，「来源」输入 `男,女`（英文逗号），勾选「提供下拉箭头」。
3. 切到「输入信息」选项卡，标题填"性别"，输入信息填"请从下拉列表中选择男或女"，点「确定」。
4. 选中 `D2:D41`，再次打开「数据有效性」，「允许」选「整数」，「数据」选「介于」，「最小值」填 `0`，「最大值」填 `100`。
5. 在「出错警告」选项卡中，样式选「停止」，标题填"分数有误"，错误信息填"请输入 0 到 100 之间的整数"，点「确定」。
6. 在 `C2` 点开下拉箭头选"男"；在 `D2` 故意输入 120，应弹出错误提示并拒绝录入。

- **易错点**：① 序列来源中的逗号必须是英文半角，用中文逗号会把"男,女"整串当成一个选项；② 设置前必须先选中目标区域，只选一个单元格设置则只对该格生效；③ 「文本长度」限制的是字符个数，不是数值大小，与「整数」的 0~100 完全是两回事；④ 格式刷不能复制有效性，需复制单元格后粘贴，或逐区重新设置。

## 本节小结

1. `Ctrl+1` 打开「单元格格式」对话框，六张选项卡分别是数字、对齐、字体、边框、图案、保护。
2. 数字格式只改变显示方式，不改变实际存储值；设为文本后数字左对齐且不能参与求和。
3. 学号、身份证号等长数字必须先设为文本，或在输入时先打一个英文单引号。
4. 格式刷单击用一次、双击可连续使用，只复制格式，不复制内容与数据有效性。
5. 数据有效性在「数据」→「有效性」中设置，可限制整数、小数、序列、日期、时间、文本长度、自定义公式。
6. 序列来源各项之间用英文逗号分隔；出错警告样式选「停止」才能真正拒绝非法输入。

## 自测题

1.（单选）在 WPS 表格中打开「单元格格式」对话框的快捷键是（ ）。
A. `Ctrl+1`　B. `Ctrl+2`　C. `Ctrl+E`　D. `Ctrl+Shift+1`

2.（判断）用格式刷可以把源单元格的数据有效性设置一并复制到目标单元格。

3.（填空）要让输入的身份证号按文本处理，可在输入前先键入一个 ________ 符号。

4.（单选）设置数据有效性时，若要提供"男/女"下拉列表，「允许」中应选择（ ）。
A. 整数　B. 序列　C. 文本长度　D. 自定义

5.（判断）把单元格格式设为百分比后，输入 0.85 会显示为 85.00%。

6.（填空）「数据有效性」对话框的三张选项卡是设置、输入信息和 ________。

7.（单选）要取消某区域已设置的数据有效性，应执行（ ）。
A. 「数据」→「有效性」→「全部清除」
B. 选中区域后按 `Delete` 键
C. 「开始」→「清除」→「清除格式」
D. 「审阅」→「撤销工作表保护」

8.（多选）关于单元格格式与数据有效性，下列说法正确的有（ ）。
A. 设置数值格式保留两位小数，只是改变显示，单元格实际值不变
B. 序列来源中的多个选项要用英文逗号分隔
C. 双击格式刷可以连续对多个区域套用同一格式
D. 把单元格设为文本格式后，其中的数字仍能正常参与 `SUM` 求和

### 参考答案

1. **A**。`Ctrl+1` 打开「单元格格式」对话框；`Ctrl+E` 是智能填充。
2. **错误**。格式刷只复制字体、数字格式、对齐、边框、图案等格式，不复制数据有效性。
3. **英文单引号（`'`）**。也可先选中区域，在「单元格格式」→「数字」中选「文本」再输入。
4. **B**。选「序列」后，在「来源」中键入各项并用英文逗号分隔，或引用一个单元格区域。
5. **正确**。百分比格式把数值乘以 100 后加百分号显示，0.85 显示为 85.00%。
6. **出错警告**。另两张是「设置」与「输入信息」。
7. **A**。`Delete` 只清除内容，不影响有效性设置。
8. **ABC**。D 错：文本格式下的数字是字符串，`SUM` 会将其忽略，求和结果为 0，需先转回数值格式。
