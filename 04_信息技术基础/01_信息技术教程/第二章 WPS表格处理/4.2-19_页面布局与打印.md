# 2.10 页面布局与打印

> **考纲对应**：电子表格处理 第 11 条——掌握页面布局、打印预览和打印操作的相关设置（层次：掌握）
> **教材对应**：单元 2 · 任务 2.4 管理与分析公司数据

屏幕上排版整齐的表格，打印出来却常常"翻车"：最后一列被挤到第二页、第二页开始没有表头、四周大片空白。原因不在数据，而在页面布局没有设置好。本节按"先排版、再预览、后打印"的顺序，把纸张、边距、分页、打印区域和打印标题一次讲清。

## 一、页面布局的基本设置

"页面布局"选项卡集中了打印前的所有排版命令。

| 设置项 | 作用 |
| --- | --- |
| 页边距 | 普通、宽、窄三套预设，也可自定义上下左右边距与页眉页脚距离 |
| 纸张方向 | 纵向或横向，列数多时改横向 |
| 纸张大小 | A4、A3、B5、16 开等，须与打印机实际纸张一致 |
| 打印区域 | 指定只打印某块区域，可设置也可取消 |
| 打印标题 | 指定每页重复出现的顶端标题行或左端标题列 |
| 分页符 | 插入、删除、重置分页符 |
| 背景 | 为工作表添加背景图片 |

单击"页面布局"选项卡右下角的小箭头，打开"页面设置"对话框，包含四个选项卡：

1. **页面**：纸张方向、缩放比例、纸张大小、起始页码。
2. **页边距**：上下左右边距、页眉页脚距边界距离、居中方式（水平居中、垂直居中）。
3. **页眉/页脚**：添加页码、日期、文件名等，可设置奇偶页不同、首页不同。
4. **工作表**：打印区域、打印标题、打印网格线、打印行号列标、单色打印、错误单元格打印方式、打印顺序（先列后行或先行后列）。

页面布局中的纸张、边距、打印区域、打印标题等设置会随文件保存，下次打开仍然有效；而打印对话框中的份数、页码范围只对本次打印有效，不会写入文件。

"居中方式"常被忽略：表格宽度小于纸张时，勾选"水平居中"才能左右对称，否则整张表贴在左侧。页眉页脚中可插入页码、总页数、日期、文件名、工作表名等内容；需要双面装订时，可设置"奇偶页不同"，让左右页的页码位置相互对应。

## 二、分页控制

### 1. 分页预览

单击"视图 → 分页预览"，工作表进入分页视图：

- **蓝色虚线**是自动分页符，由纸张大小和缩放比例决定；
- **蓝色实线**是手动插入的分页符；
- 用鼠标拖动分页线，可以直接调整每页包含的行列，同时缩放比例会随之自动改变。

分页预览是查看"哪一页装哪些内容"最直观的方式。分页线之外的灰色区域不会参与打印；若某页只多出一两行，形成"孤行页"，可拖动分页线或适当调小行高、列宽，把它收回上一页。

### 2. 插入与删除分页符

- 插入水平分页符：选中将成为新页第一行的行号或该行 A 列单元格，"页面布局 → 分页符 → 插入分页符"。
- 插入垂直分页符：选中将成为新页第一列的列标或首行单元格。
- 删除：选中分页线下方的单元格，"分页符 → 删除分页符"；"重置所有分页符"可一次清除全部手动分页。

### 3. 缩放适配

"页面设置 → 页面"中的"缩放"有两种方式：按比例缩放（如 80%），或"调整为 1 页宽、若干页高"。后者常用于"列太多，最后一列总是溢出"的情况：把宽度设为 1 页，WPS 自动缩小比例，所有列挤进一页，代价是字号变小。若缩得太小影响阅读，应改横向纸张或精简列宽，而不是一味缩小。

## 三、打印区域与打印标题

### 1. 设置打印区域

选中要打印的区域，"页面布局 → 打印区域 → 设置打印区域"，区域外围出现虚线框。此后无论当前选中哪个单元格，打印都只输出该区域。取消时选"打印区域 → 取消打印区域"。

### 2. 设置打印标题

一张 300 行的表打印成十几页，第二页起若没有表头，读者就分不清每列含义。"页面布局 → 打印标题"打开页面设置对话框，在"顶端标题行"中框选第 1 行（显示为 `$1:$1`），确定后每页顶端都会重复该行。列数很多、需要每页重复左侧姓名列时，在"左端标题列"中设置，如 `$A:$A`。打印标题只在打印和预览时生效，不会在屏幕上重复显示。

## 四、打印预览与打印

按 `Ctrl+P` 或单击"文件 → 打印"，进入打印设置与预览界面：左侧是选项，右侧是实时预览。

- **打印机**：选择实际设备，可查看纸张与放置方向是否匹配。
- **份数**：设置打印份数，多份时可勾选"逐份打印"，避免一份未打完就叠另一份。
- **页码范围**：全部、指定页（如 1-3）、选定区域。
- **打印内容**：选定区域、活动工作表、整个工作簿。工作簿含多张表时，选"整个工作簿"可一次打全。选"选定区域"只输出当前选中的范围，且仅对本次打印生效；它与"打印区域"不同，后者会保存在文件中持续起作用。
- **单双面**：由打印机驱动支持情况决定。

预览中若发现内容溢出或留白过多，可返回"页面设置"调整，不必反复试打。正式打印前建议先打印一页核对字体与边框，尤其是缩放比例较小时，细边框可能打印不清。若使用黑白打印机，可在"工作表"选项卡勾选"单色打印"，避免彩色底纹被打印成一片深灰而盖住文字。

打印大表时可遵循固定的检查顺序：先定纸张方向与大小，再设缩放适配页宽，接着设置打印标题，然后到分页预览中确认分页位置，最后调整页边距与居中方式并预览。按这个顺序操作，可以避免"改了边距又溢出、改了缩放又断页"的反复。

**例 2.10-1** 一张 300 行的销售明细表共 8 列，要求用 A4 纸横向打印，每页顶端重复第一行表头，所有列压缩到一页宽，页脚显示页码。

**解**

1. 单击"页面布局 → 纸张方向 → 横向"，"纸张大小"选 A4。
2. 单击"页面布局 → 打印标题"，在"顶端标题行"中选中第 1 行，确定。
3. 打开"页面设置 → 页面"，缩放方式选"调整为"，宽度填 1 页、高度留空（表示自动）。
4. 切换到"页眉/页脚"选项卡，在页脚中选择"第 1 页，共 ? 页"样式，确定。
5. 按 `Ctrl+P` 预览：确认第 2 页起顶端仍有表头，右侧无列溢出，页码连续。
6. 若字太小，改回纵向并适当缩小列宽、精简不必要的列，再重新预览。

- **易错点**：① 只设了"顶端标题行"却未预览，第二页仍无表头，通常是标题行填错（如填了 `$2:$2`）；② 缩放宽度设为 1 页后又手动插入分页符，两者冲突导致列被切断；③ 纸张大小与打印机实际装入的纸张不一致，打印结果被裁切；④ 页脚页码为"第 1 页"却未设起始页码，续打时页码从头开始。

**例 2.10-2** 同一张表只需打印 A1:F20 的区域，要求水平居中、打印网格线，且不打印行号列标。

**解**

1. 选中 A1:F20，"页面布局 → 打印区域 → 设置打印区域"。
2. 打开"页面设置"，在"页边距"选项卡勾选"水平居中"。
3. 切换到"工作表"选项卡，勾选"网格线"，取消"行号列标"。
4. 确定后按 `Ctrl+P` 预览，确认只显示 A1:F20 且表格左右对称。
5. 打印内容保持"活动工作表"即可，因为打印区域已经限定了输出范围。
6. 打印完成后如需恢复整表打印，执行"打印区域 → 取消打印区域"。

- **易错点**：① 只选中区域就直接打印，未设打印区域，结果输出整张表；② 勾选"网格线"却未勾选"打印"栏中的网格线，屏幕上看到网格只是显示效果；③ 设置打印区域后又增删了行列，区域未随之更新，需重新设置；④ 打印内容误选"整个工作簿"，把其他工作表一并打印。

## 本节小结

1. 页面布局包含页边距、纸张方向与大小、打印区域、打印标题、分页符等设置，完整选项在"页面设置"对话框。
2. 缩放可选百分比或"调整为 1 页宽"，用于解决列溢出的问题，但会牺牲字号。
3. 分页预览中蓝色虚线为自动分页、实线为手动分页，可拖动调整；手动分页符可插入、删除、重置。
4. 打印区域限定输出范围；打印标题让长表每页重复表头行或左侧列，仅在打印时生效。
5. `Ctrl+P` 进入打印预览，可设置份数、页码范围、打印内容（选定区域、活动工作表、整个工作簿）。
6. 打印前先预览核对表头、分页、边距与缩放，避免反复试打浪费纸张。
