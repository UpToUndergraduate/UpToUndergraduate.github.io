# 2.11 工作簿保护、共享与主题

> **考纲对应**：电子表格处理 第 5 条——熟悉工作簿的保护、撤销保护和共享，工作表的保护、撤销保护，工作表的背景、样式、主题设定（层次：熟悉）
> **教材对应**：单元 2 · 任务 2.4 管理与分析公司数据

工资表、成绩表、报价单这类文件，既要防止别人误改公式，又要允许相关人员在指定区域录入数据，还常常需要多人共同维护。WPS 表格用"工作簿保护"管住文件结构，用"工作表保护"管住单元格，用"共享"支持多人协作；而背景、样式与主题负责统一外观。保护与撤销保护是一对操作，考试中往往成对出现。

## 一、工作簿的保护与撤销

工作簿层面的保护有两种，作用完全不同，不能混为一谈。

### 1. 文档加密

文档加密控制"能不能打开、能不能改"，密码随文件保存。

1. 单击"文件 → 文档加密 → 密码加密"。
2. 在"打开权限密码"中设置打开文件所需的密码；如需限制他人修改，再设置"编辑权限密码"。
3. 确定后**必须保存文件**，密码才生效；关闭再打开时会要求输入密码。
4. 撤销：再次进入"文档加密"，清空两个密码框，确定并保存。

打开权限密码遗失后无法恢复，只能放弃文件内容，设置前务必记录在安全位置。

### 2. 保护工作簿结构

结构保护不限制打开文件，而是防止他人增删、重命名、移动、隐藏工作表，也能锁定窗口位置。

1. 单击"审阅 → 保护工作簿"。
2. 勾选"结构"（需要锁定窗口排列时再勾选"窗口"），输入密码，确定。
3. 生效后，右键工作表标签，"插入""删除""重命名""移动或复制"等命令变为灰色不可用。
4. 撤销：单击"审阅 → 撤销工作簿保护"，输入原密码。

| 保护类型 | 入口 | 保护范围 | 是否影响打开文件 |
| --- | --- | --- | --- |
| 文档加密 | 文件 → 文档加密 → 密码加密 | 打开、编辑整个文件 | 影响，需输入密码 |
| 保护工作簿结构 | 审阅 → 保护工作簿 | 插入、删除、重命名、移动、隐藏工作表 | 不影响 |
| 保护工作表 | 审阅 → 保护工作表 | 单元格编辑、格式与行列操作 | 不影响 |

## 二、工作表的保护与撤销

### 1. 锁定与隐藏的准备工作

WPS 中所有单元格默认处于"锁定"状态，但**只有执行保护工作表之后，锁定才真正生效**。因此"允许部分区域编辑"的正确顺序是：先解除这些单元格的锁定，再保护工作表。

1. 选中允许用户编辑的区域（如 C2:C40）。
2. 右键选择"设置单元格格式"（快捷键 `Ctrl+1`），切换到"保护"选项卡。
3. 取消勾选"锁定"；若该区域含公式且不希望被看到，可勾选"隐藏"，确定。
4. 公式单元格的"隐藏"同样要在保护工作表后才起作用。

### 2. 保护工作表

1. 单击"审阅 → 保护工作表"。
2. 在"允许此工作表的所有用户进行"列表中勾选允许的操作，如选定锁定单元格、选定未锁定单元格、插入行、排序、使用自动筛选等。未勾选的操作一律被禁止。
3. 输入密码（可留空，但留空则任何人都能撤销保护），确定。
4. 生效后，编辑锁定单元格会提示该单元格受保护；未锁定区域可正常录入。

### 3. 撤销工作表保护

单击"审阅 → 撤销工作表保护"，输入密码即可解除。若忘记密码，常规操作无法撤销，只能借助第三方工具或重建文件，这也是设置密码前要慎重的原因。

需要注意，保护工作表不等于隐藏数据：未隐藏的单元格内容仍可查看、复制，保护只阻止修改。

## 三、工作簿的共享

### 1. 共享工作簿

在局域网环境中，可让多人同时编辑同一文件：

1. 单击"审阅 → 共享工作簿"，在"编辑"选项卡中勾选"允许多用户同时编辑，同时允许工作簿合并"。
2. 确定并保存文件，把文件放在共享文件夹中供他人打开。
3. 他人修改并保存后，修订记录会保留，可通过"修订"功能查看谁在何时改了什么。

共享状态会限制部分功能，例如不能合并单元格、不能删除工作表、不能插入或删除整块单元格区域。因此应先把表格结构整理好，再开启共享。取消共享时，需确保其他用户都已保存并关闭文件，再取消勾选，否则可能丢失他人未保存的修改。

### 2. 云端协作

把文件保存到 WPS 云文档后，通过"分享"生成链接并设置权限（可查看或可编辑），邀请他人打开。多人在线编辑时能实时看到彼此的光标与修改，系统自动保存并保留历史版本，可随时回溯。与局域网共享相比，云端协作不受地点限制，也不需要反复传文件。

## 四、工作表背景、样式与主题

### 1. 工作表背景

"页面布局 → 背景"，选择一张图片，图片会平铺在整张工作表的单元格下方，作为屏幕装饰。背景不会改变单元格的内容和数值，也不参与计算；删除时单击"页面布局 → 删除背景"即可。若背景颜色较深，应同时把字体调亮或给单元格填充浅色底纹，否则数据难以辨认。

### 2. 单元格样式

"开始 → 单元格样式"提供一批内置样式，如标题、强调文字、好、差、适中、计算、检查单元格等。使用样式的好处是格式统一、修改方便：

- 单击样式即可套用到选中单元格；
- 右键样式选择"修改"，可调整字体、边框、填充，所有使用该样式的单元格同步更新；
- 选择"新建单元格样式"，可保存自定义格式，供全工作簿复用；
- "套用表格格式"用于把数据区域转换为带筛选按钮和隔行底纹的表格。

### 3. 主题

主题是配色、字体与效果的整体方案，作用于**整个工作簿**。单击"页面布局 → 主题"，可从内置主题中选择；展开后还可单独调整"主题颜色""主题字体""主题效果"。

主题的价值在于"一处修改、全局统一"：标题、图表系列、单元格样式中引用主题颜色的元素，都会随主题切换而同步改变。但手工指定的固定颜色不会跟随主题变化，这也是同一工作簿切换主题后个别图表颜色不变的原因。

**例 2.11-1** 一份工资表需要设置打开密码，并禁止他人删除或重命名工作表，但允许正常查看内容。

**解**

1. 打开文件，单击"文件 → 文档加密 → 密码加密"。
2. 在"打开权限密码"中输入密码，确定；如需限制修改，再填"编辑权限密码"。
3. 保存文件并关闭，重新打开验证需要输入密码。
4. 单击"审阅 → 保护工作簿"，勾选"结构"，输入密码，确定。
5. 右键工作表标签，确认"删除""重命名"等命令为灰色；双击标签也无法改名。
6. 撤销时依次执行"审阅 → 撤销工作簿保护"和"文件 → 文档加密"清空密码，并保存。

- **易错点**：① 设置密码后未保存，关闭文件密码即失效；② 把"保护工作簿结构"当成打开密码，结果文件仍能被任何人打开；③ 同时设置打开密码与编辑密码却只记住一个，导致自己也无法修改；④ 用"保护工作表"代替"保护工作簿"，工作表仍可被删除。

**例 2.11-2** 一份成绩表要求：仅 C2:C40 可录入分数，其余单元格锁定；工作表加背景图片；最后把整个工作簿的主题改为"沉稳"。

**解**

1. 选中 C2:C40，按 `Ctrl+1` 打开"设置单元格格式"，在"保护"选项卡取消"锁定"，确定。
2. 单击"审阅 → 保护工作表"，勾选"选定锁定单元格""选定未锁定单元格"，输入密码，确定。
3. 验证：在 C2 可以输入分数；在 B2 输入时提示单元格受保护。
4. 单击"页面布局 → 背景"，选择图片插入；若文字看不清，给数据区填充浅色底纹。
5. 单击"页面布局 → 主题"，在列表中选择"沉稳"，观察图表与标题颜色是否统一变化。
6. 全部完成后保存；撤销保护执行"审阅 → 撤销工作表保护"并输入密码。

- **易错点**：① 先保护工作表再取消锁定，锁定已生效，C 列仍不能输入；② 只取消锁定却忘记保护工作表，任何人都能修改全表；③ 背景图片过深且未调整字体颜色，数据无法辨认；④ 误以为切换主题会改变数据内容，实际上只改变配色、字体与效果。

## 本节小结

1. 文档加密设置打开权限密码和编辑权限密码，控制文件能否打开与修改，必须保存后生效。
2. 保护工作簿结构可防止插入、删除、重命名、移动和隐藏工作表，撤销入口在"审阅"选项卡。
3. 单元格默认锁定，但只有保护工作表后才生效；允许编辑的区域要先取消锁定再保护。
4. 保护工作表可勾选允许的操作并设置密码，撤销时需输入原密码；保护不等于隐藏数据。
5. 共享工作簿支持多人同时编辑并记录修订，但会限制合并单元格等操作；云端协作通过链接邀请他人编辑。
6. 工作表背景平铺在数据下方、不影响内容；单元格样式统一格式；主题统一整个工作簿的配色、字体与效果。
