# 2.6 公式与常用函数

> **考纲对应**：电子表格处理 第 7 条——熟悉公式和函数的使用，掌握平均值、最大/最小值、求和、计数、条件等常见函数的使用（层次：熟悉、掌握）
> **教材对应**：单元 2 · 任务 2.2 统计与分析学生成绩

成绩表真正的价值不在于把分数录进去，而在于能算出总分、平均分、及格率和每个人的等级。这些工作都由公式与函数完成。本节先讲清公式的语法规则与运算顺序，再按"求和—平均—最值—计数—条件"的顺序逐个吃透高频函数，最后归纳常见错误值的含义，让报错不再是黑箱。

## 一、公式基础

### 1. 公式的组成

公式以英文等号 `=` 开头，由运算符、单元格引用、常量、函数四类元素组合而成。例如 `=SUM(B2:D2)/3` 中，`SUM` 是函数，`B2:D2` 是引用，`3` 是常量，`/` 是运算符。输入完成后按 `Enter` 确认，单元格显示计算结果，编辑栏显示公式本身。若单元格中直接显示出一串以 `=` 开头的文字，说明该单元格被设成了文本格式。

「开始」选项卡右端的「自动求和」按钮（图标为 `Σ`）是写公式最省事的入口：选中数据下方或右侧的空白单元格，点一下 `Σ`，程序会自动框选相邻的连续数值区域并生成 `=SUM(…)`，按 `Enter` 确认即可。点 `Σ` 旁的下拉箭头，还能直接插入「平均值」「计数」「最大值」「最小值」，不必逐字键入函数名。

### 2. 运算符

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+` `-` `*` `/` | 加、减、乘、除 | `=B2+C2` | 两数之和 |
| `^` | 乘方 | `=B2^2` | B2 的平方 |
| `%` | 百分号 | `=B2*10%` | B2 的十分之一 |
| `&` | 文本连接 | `=A2&"班"` | 把 A2 内容与"班"拼接 |
| `=` `>` `<` `>=` `<=` `<>` | 比较 | `=E2>=60` | 返回 `TRUE` 或 `FALSE` |

### 3. 运算顺序

引用运算符（冒号、逗号、空格）→ 负号 → 百分号 → 乘方 → 乘除 → 加减 → 文本连接符 `&` → 比较运算符。同级运算从左到右进行，有括号先算括号内。因此 `=B2+C2/2` 是先除后加，若要"先加后除"必须写成 `=(B2+C2)/2`，这类括号遗漏是计算题最常见的错误。式子层次一多，建议先在草稿上写出结构再输入；输入过程中编辑栏会把成对的括号以同色显示，可据此检查是否配对。

### 4. 公式的输入、编辑与复制

- 输入：选中单元格键入 `=`，或直接点编辑栏左侧的 `fx` 按钮插入函数。
- 编辑：双击单元格进入单元格内编辑，或选中后按 `F2`，也可直接点编辑栏修改。
- 复制：用控制句柄填充，或 `Ctrl+C`／`Ctrl+V`。复制时相对引用会随位置调整，规则见 2.5 节。
- 函数参数分隔符一律用英文逗号，中文逗号会导致公式无法识别。
- 输入函数名和左括号后，程序会弹出参数提示条，当前正在填写的参数以加粗显示；输入参数时用鼠标拖选区域，程序会自动补上区域地址，不必手写 `B2:D41`。

## 二、常用函数

### 1. 统计与计算类函数

| 函数 | 作用 | 示例 |
|---|---|---|
| `SUM` | 求和 | `=SUM(B2:D2)` |
| `AVERAGE` | 求算术平均值 | `=AVERAGE(B2:D2)` |
| `MAX` / `MIN` | 求最大值 / 最小值 | `=MAX(E2:E41)` |
| `COUNT` | 统计区域中数值的个数 | `=COUNT(B2:B41)` |
| `COUNTA` | 统计区域中非空单元格的个数 | `=COUNTA(A2:A41)` |
| `COUNTIF` | 按单个条件计数 | `=COUNTIF(D2:D41,">=60")` |
| `SUMIF` | 按单个条件求和 | `=SUMIF(A2:A41,"一班",E2:E41)` |
| `IF` | 条件判断 | `=IF(E2>=270,"优秀","合格")` |
| `ROUND` | 四舍五入到指定位数 | `=ROUND(E2/3,1)` |

使用要点：
- 函数写法统一为 `=函数名(参数1,参数2,…)`，参数可以是单元格、区域、常量或另一个函数。
- `COUNT` 只数数值，文本、空白都不算；`COUNTA` 数所有非空单元格。考勤统计缺人数用 `COUNT`，统计实际参加人数用 `COUNTA`。
- `AVERAGE` 忽略文本与空白，但 0 会参与计算。缺考若录 0 分，平均分会被拉低；若留空则不计入分母，两者结果不同，答题时要看清题意。
- `COUNTIF` 的条件是文本或带比较符时必须加英文双引号，如 `">=60"`、`"一班"`；条件是纯数字时可写 `60`。
- `COUNTIF` 与 `SUMIF` 支持通配符：`*` 代表任意多个字符，`?` 代表单个字符，如 `"张*"` 统计所有姓张的人数。
- `IF` 的三个参数依次是条件、条件成立时的值、条件不成立时的值；结果是文本时要加英文双引号。`IF` 可以嵌套，如 `=IF(E2>=270,"优秀",IF(E2>=180,"合格","不合格"))`。
- `ROUND` 只改变计算结果，与用「单元格格式」设小数位数不同，后者只改显示。
- 函数名不区分大小写，`sum` 与 `SUM` 效果相同，但书写时统一用大写更便于阅读和校对。
- 若求和区域中混入了行标题之类的文字，`SUM` 与 `AVERAGE` 会自动忽略这些文本，但 `COUNT` 的计数结果会小于选中区域的行数，看到"少算了几行"先检查区域里有没有文字。

### 2. 多条件统计与函数嵌套

实际工作中条件往往不止一个：既要统计"一班"的学生，又要限定"总分不低于 270"。这时要用带 S 的多条件函数：

- `COUNTIFS(区域1,条件1,区域2,条件2,…)`——统计同时满足全部条件的单元格个数，条件成对出现，最多可写多组。
- `SUMIFS(求和区域,条件区域1,条件1,条件区域2,条件2,…)`——注意**求和区域放在最前面**，与 `SUMIF` 把求和区域放在最后的参数顺序正好相反，这是考查中最常设的陷阱。

函数也可以层层嵌套，把一个函数的结果当作另一个函数的参数。例如 `=IF(AVERAGE(B2:D2)>=90,"优秀",IF(AVERAGE(B2:D2)>=60,"合格","不合格"))`，先算平均分，再按平均分判断等级。嵌套层数越多越容易漏写括号，写完后可用编辑栏检查括号是否成对，或者拆成辅助列分步计算，结果更易核对。

### 3. 常见错误值

| 错误值 | 含义与常见原因 |
|---|---|
| `#####` | 列宽不足，或日期、时间为负值；加大列宽即可 |
| `#DIV/0!` | 除数为 0 或引用了空单元格作除数 |
| `#VALUE!` | 参数类型不正确，如文本参与了算术运算 |
| `#NAME?` | 函数名拼写错误，或文本参数未加双引号 |
| `#REF!` | 引用的单元格或工作表已被删除 |
| `#N/A` | 查找类函数找不到匹配值 |
| `#NUM!` | 数值超出可计算范围，如对负数开平方 |

看到错误值不要急着重输公式，先按类型判断：整列**全部**显示 `#####`，几乎都是列宽不够，拉宽列即可；只有个别单元格出现 `#DIV/0!`，说明那一行的除数恰好为空或为 0；公式复制后突然冒出 `#REF!`，则是原来引用的行、列或工作表已被删除。判断清楚再动手，比盲目重写效率高得多。

**例 2.6-1** 成绩表 B、C、D 列为语文、数学、英语，数据在第 2 至 41 行。要求：在 E 列计算每人总分，在 F 列计算平均分（保留 1 位小数），在表尾统计全表最高总分、最低总分、参加考试人数与语文及格人数。

**解**

1. 单击 `E2`，输入 `=SUM(B2:D2)`，按 `Enter`，双击控制句柄填充到 `E41`。
2. 单击 `F2`，输入 `=ROUND(AVERAGE(B2:D2),1)`，按 `Enter` 后填充到 `F41`。用 `ROUND` 而非设格式，可让平均分本身就只有 1 位小数。
3. 在 `E43` 输入标签"最高分"，`F43` 输入 `=MAX(E2:E41)`。
4. 在 `E44` 输入"最低分"，`F44` 输入 `=MIN(E2:E41)`。
5. 在 `E45` 输入"参考人数"，`F45` 输入 `=COUNT(E2:E41)`，只统计有数值的单元格，缺考者自动排除。
6. 在 `E46` 输入"语文及格人数"，`F46` 输入 `=COUNTIF(B2:B41,">=60")`，注意条件要加英文双引号。
7. 检查 `F41` 是否显示为一位小数，`F46` 的数值是否与手工核对一致。

- **易错点**：① `SUM(B2:D2)` 中的冒号是区域运算符，写成 `SUM(B2,D2)` 只加两格；② 条件写成 `">=60 "`（多一个空格）会把文本"60 "与数值比较，结果偏小甚至为 0；③ `COUNT` 统计不到文本型数字，若分数被存成文本，计数会偏少；④ `ROUND` 与单元格格式的"小数位数"作用不同，前者改变值，后者只改显示。

**例 2.6-2** 继续上表，要求在 G 列按总分给出等级：270 分及以上为"优秀"，180 至 269 分为"合格"，其余为"不合格"；并统计"一班"（A 列记录班级）的总分合计与优秀人数。

**解**

1. 单击 `G2`，输入 `=IF(E2>=270,"优秀",IF(E2>=180,"合格","不合格"))`，按 `Enter`。
2. 双击控制句柄填充到 `G41`。判断顺序不可颠倒：先判 270，再判 180，否则 280 分也会被归入"合格"。
3. 在 `E48` 输入"一班总分"，`F48` 输入 `=SUMIF(A2:A41,"一班",E2:E41)`。
4. 在 `E49` 输入"一班优秀人数"，`F49` 输入 `=COUNTIFS(A2:A41,"一班",G2:G41,"优秀")`。
5. 若只需单条件统计优秀总人数，用 `=COUNTIF(G2:G41,"优秀")` 即可。
6. 逐个抽查两名学生，用计算器手算核对等级与合计是否正确。

- **易错点**：① `IF` 嵌套时区间必须从小到大或从大到小**单向排列**，顺序乱了会误判；② 文本结果不加双引号会显示 `#NAME?`；③ `SUMIF` 的求和区域与条件区域行数必须一致，否则结果错位；④ 多条件统计要用 `COUNTIFS`，`COUNTIF` 只能容纳一个条件。

## 本节小结

1. 公式以英文 `=` 开头，由运算符、引用、常量、函数组成；结果在单元格显示，公式本身在编辑栏显示。
2. 运算顺序为引用运算符、负号、百分号、乘方、乘除、加减、文本连接、比较，括号优先。
3. `SUM` 求和、`AVERAGE` 求平均、`MAX`/`MIN` 求最值、`COUNT`/`COUNTA` 计数，是最基础的五个统计函数。
4. `COUNTIF`、`SUMIF` 按条件计数与求和，文本或带比较符的条件必须加英文双引号。
5. `IF` 三参数依次为条件、成立值、不成立值，可嵌套但判断区间要单向排列。
6. `#####` 多为列宽不足，`#DIV/0!` 为除零，`#NAME?` 为函数名或引号错误，`#REF!` 为引用失效。

## 自测题

1.（单选）在单元格中输入公式时，必须以（ ）开头。
A. `+`　B. `=`　C. `#`　D. `@`

2.（判断）`=AVERAGE(B2:D2)` 与 `=SUM(B2:D2)/3` 在 B2:D2 三个单元格都有数值时结果相同。

3.（填空）统计 B2:B41 中不小于 60 的单元格个数，公式应写为 `=COUNTIF(B2:B41,________)`。

4.（单选）要统计 A2:A41 区域中非空单元格的个数，应使用（ ）。
A. `COUNT`　B. `COUNTA`　C. `COUNTIF`　D. `SUM`

5.（判断）单元格显示 `#DIV/0!`，说明公式中出现了除以 0 或除以空单元格的情况。

6.（填空）在 `C2` 输入 `=IF(B2>=60,"及格","不及格")`，若 B2 为 55，C2 显示 ________。

7.（单选）下列公式中，能正确统计"一班"学生总分合计的是（ ）。
A. `=COUNTIF(A2:A41,"一班")`
B. `=SUMIF(A2:A41,"一班",E2:E41)`
C. `=SUM(A2:A41,"一班")`
D. `=COUNTIFS(A2:A41,"一班",E2:E41)`

8.（多选）关于公式与函数，下列说法正确的有（ ）。
A. 函数参数之间应使用英文逗号分隔
B. `COUNT` 只统计数值单元格，文本和空白不计入
C. 单元格显示 `#NAME?`，可能是函数名拼写错误或文本参数未加双引号
D. `AVERAGE` 会把区域中的文本按 0 计算，从而拉低平均值

### 参考答案

1. **B**。公式必须以英文等号 `=` 开头，`+`、`#`、`@` 都不符合公式的语法要求。
2. **正确**。三个单元格都有数值时，平均值等于总和除以 3；但若存在空白，`AVERAGE` 的分母会变小，两者结果不同。
3. **`">=60"`**。含比较符的条件必须用英文双引号括起，否则公式报错。
4. **B**。`COUNTA` 统计非空单元格，`COUNT` 只统计数值。
5. **正确**。除数为 0 或引用了空单元格作除数都会产生该错误。
6. **不及格**。条件不成立，返回 `IF` 的第三个参数。
7. **B**。`SUMIF` 按条件求和，三个参数依次为条件区域、条件、求和区域；A 只计数，C 语法错误，D 是 `COUNTIFS` 却缺条件对。
8. **ABC**。D 错：`AVERAGE` 会忽略文本与空白单元格，只有 0 才会计入并拉低平均值。
