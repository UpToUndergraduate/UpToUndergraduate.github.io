# 6.1 新一代信息技术概述

> **考纲对应**：新一代信息技术概述 第 1~4 条——理解新一代信息技术及其主要代表技术的基本概念，了解各代表技术的技术特点与典型应用，了解与制造业等产业的融合发展方式（层次：理解 + 了解）
> **教材对应**：单元 5 · 新一代信息技术概述

新一代信息技术是扩展模块的"总纲"：后面各节展开的云计算、大数据、人工智能、机器人流程自动化，都是这里先画出的"代表技术"。考试很少停留在名词背诵，多以"概念辨析""技术—特点匹配""场景判断"的组合题出现，复习时要抓住两条线：各项技术"解决什么问题"，多项技术"如何协同"。

## 一、新一代信息技术的基本概念

### 1. 概念界定

新一代信息技术是相对于以计算机、互联网为核心的传统信息技术而言的，指以数据的采集、传输、存储、处理与应用为主线，由云计算、大数据、人工智能、物联网、移动互联网、区块链、第五代移动通信（5G）、数字媒体等构成的新兴技术群。

它有两点必须说清：第一，它是一个**技术族群**的统称，不是某一项技术的别名；第二，它的"新"不仅在新工具，更在**范式变化**——从"人操作机器"转向"机器感知环境、数据驱动决策、服务按需交付"。其本质特征是万物互联、数据驱动、智能处理、服务化交付。

### 2. 主要代表技术一览

| 代表技术 | 一句话概念 | 关键词 |
|---|---|---|
| 云计算 | 通过网络按需获取可弹性伸缩的计算与存储资源 | 资源池化、按需自助、按量计费 |
| 大数据 | 规模巨大、类型多样、增长快速，需新型架构处理的数据集合 | 4V 特征、价值密度低 |
| 人工智能 | 让机器模拟人类的感知、学习、推理与决策 | 机器学习、神经网络、大模型 |
| 物联网 | 通过传感设备把物品接入网络，实现识别、定位与管控 | 全面感知、可靠传递、智能处理 |
| 移动互联网 | 移动通信与互联网融合，终端随时随地接入 | 移动终端、无线接入 |
| 区块链 | 多方共同维护、按时间顺序链接的分布式账本 | 去中心、难篡改、可追溯 |
| 5G 通信 | 第五代移动通信，高速率、低时延、广连接 | 增强移动宽带、低时延高可靠、海量机器通信 |
| 数字媒体 | 以数字形式采集、处理、传播的文本、图形、音视频 | 数字化、交互性、多媒体融合 |

**例 6.1-1** 某市建设"城市大脑"：路口摄像头与地磁传感器实时采集车流，数据经 5G 网络回传至云端平台存储，算法据此预测拥堵并自动调整信号灯配时。请指出该工程依次体现了哪些新一代信息技术。

**解**

1. 采集环节：摄像头、地磁传感器属于感知设备，负责把物理世界的车流转化为数据，对应**物联网**。
2. 传输环节：5G 承担大带宽、低时延的回传，对应**第五代移动通信**。
3. 存储与算力环节：数据汇入云平台，按需分配存储与计算资源，对应**云计算**。
4. 分析与决策环节：用算法从海量通行数据中挖掘规律、预测拥堵，对应**大数据**与**人工智能**。
5. 结论：这是"物联网采集—5G 传输—云存储—大数据与人工智能分析"的技术协同，说明新一代信息技术以数据流为主线串联成技术群。

- **易错点**：①把"传感器采集"答成大数据，采集属于物联网感知层，大数据处理的是已经汇聚的数据；②把"云端存储"答成大数据，存储资源来自云计算；③忽略 5G，认为传输环节"不算技术"。

## 二、主要代表技术的技术特点

技术特点是命题人最爱"移花接木"的地方：把甲技术的特点写到乙技术名下，只记名词就会失分。下表按"特点—辨析要点"整理，建议横向对比记忆。

| 技术 | 主要技术特点 | 辨析要点 |
|---|---|---|
| 云计算 | 资源池化、按需自助服务、广泛网络访问、快速弹性伸缩、可计量计费 | 解决"算力和存储从哪里来、怎么付费" |
| 大数据 | 数据量大、类型多样、处理速度快、价值密度低而总价值高 | 解决"海量数据里怎么挖出价值" |
| 人工智能 | 自学习、自适应、能处理非结构化信息、可辅助或替代部分脑力劳动 | 解决"机器如何感知与决策" |
| 物联网 | 全面感知、可靠传输、智能处理，实现物与物、人与物的连接 | 解决"物理世界如何被数字化" |
| 区块链 | 去中心化、不可篡改、可追溯、集体维护、共识信任 | 解决"多方之间如何建立信任" |
| 5G | 高速率、低时延、大连接、高可靠 | 解决"数据如何高速可靠地流动" |

三组最易混淆的关系需要单独强调。

- **云计算与大数据**：前者是"资源供给方式"，后者是"数据处理方法"。二者互为支撑——大数据分析需要云计算提供弹性算力，云计算的重要负载之一就是大数据作业。题目问"高峰期自动扩容、按量付费"选云计算，问"从海量交易记录中发现消费规律"选大数据。
- **物联网与互联网**：互联网连接的是"人"和"信息"，物联网连接的是"物"，且强调对物理对象的感知与控制；物联网的数据要经网络传输，因此它依赖互联网与移动通信，但不能等同于互联网。
- **人工智能与自动化**：传统自动化按固定规则重复执行，遇到规则外的情形就失效；人工智能能从数据中学习规律，具备一定的泛化与适应能力。这一点也是理解机器人流程自动化与人工智能关系的关键。

**例 6.1-2** 某影视制作公司在渲染高峰期需要数百台服务器，平时只用十余台。若自建机房，高峰期不够用、平时大量闲置。最合理的技术方案是（　）。

A. 采用云计算按需租用算力，任务结束后释放资源
B. 用区块链记录渲染任务，保证不可篡改
C. 用物联网把渲染服务器连成网络
D. 用数字媒体技术压缩视频文件

**解**

1. 题干的核心矛盾是"资源需求波动大、自建成本高"，属于资源供给问题。
2. 云计算的弹性伸缩与按量计费正好匹配：高峰扩容、闲时释放，把固定投入变为可变成本。
3. 区块链解决信任与存证，物联网解决设备连接与感知，数字媒体解决内容形态，均不针对算力弹性。
4. 答案选 A。

- **易错点**：①看到"服务器""网络"就选物联网，忽略了需求是"算力弹性"；②把"按量付费"误认为是大数据的特点；③认为区块链因"分布式"就能提供算力，实际上区块链不承担通用计算资源租赁。

## 三、典型应用场景

新一代信息技术的应用可用"一条数据链"梳理：感知采集、网络传输、存储计算、分析决策、可信存证，每一环都有主导技术。下表按行业列出典型应用。

| 行业 | 典型应用 | 主要支撑技术 |
|---|---|---|
| 制造 | 智能工厂、设备预测性维护、柔性生产线 | 物联网 + 人工智能 + 云计算 |
| 交通 | 车路协同、自动驾驶、智慧信号灯 | 5G + 物联网 + 人工智能 |
| 医疗 | 医学影像辅助诊断、远程会诊、健康监测 | 人工智能 + 5G + 大数据 |
| 农业 | 精准灌溉、病虫害识别、农产品溯源 | 物联网 + 大数据 + 区块链 |
| 金融 | 智能风控、反欺诈、供应链金融 | 大数据 + 人工智能 + 区块链 |
| 政务 | 一网通办、城市运行监测、电子证照 | 云计算 + 大数据 + 区块链 |
| 教育 | 在线课堂、个性化推荐、虚拟仿真实验 | 云计算 + 人工智能 + 数字媒体 |

**例 6.1-3** 某茶叶企业宣传"扫码即可看到这罐茶从采摘、加工到运输的全过程，且记录无法被企业单方面改动"。该功能主要依托的技术组合是（　）。

A. 区块链 + 物联网　B. 数字媒体 + 云计算　C. 5G + 人工智能　D. 大数据 + 移动互联网

**解**

1. "全过程可见"要求各环节数据被采集并上传，种植、加工、运输环节的采集依赖物联网感知设备。
2. "无法被企业单方面改动"是可信存证需求，对应区块链的分布式记账与不可篡改特性。
3. 数字媒体只解决内容呈现，5G 解决传输，人工智能解决识别与预测，都不能保证记录不被篡改。
4. 答案选 A。此类题的技巧是找出题干中"最硬"的那个约束条件，再匹配唯一具备该特性的技术。

- **易错点**：①只看到"扫码看视频"就选数字媒体，忽略了"不可篡改"这一核心约束；②把"全流程记录"直接等同于大数据，大数据擅长分析而不负责防篡改；③误认为区块链能自动采集数据，采集仍需物联网完成。

## 四、与制造业等产业的融合发展

考纲第 4 条要求了解融合发展方式，这部分是近年命题的新增长点。融合不是技术的简单叠加，而是用数据把研发、生产、管理、服务各环节打通。

### 1. 与制造业融合的三种形态

- **智能制造**：把物联网、人工智能、云计算嵌入车间，使设备具备自感知、自决策、自执行能力，典型形态是数字化车间、智能工厂与柔性生产线。柔性生产的关键在于"同一产线快速切换不同型号"，靠的是数据驱动的排产与设备协同。
- **工业互联网**：把设备、产线、工厂、供应商、产品与客户连接成网，通过平台汇聚工业数据，支撑远程运维、协同制造与供应链优化。它可理解为"制造业 + 互联网 + 大数据"的融合基础设施。
- **数字孪生**：在虚拟空间为物理设备或产线建立实时映射的模型，用实时数据驱动仿真，实现状态监控、工艺优化与预测性维护，同时依赖物联网、大数据、人工智能与高性能计算。

### 2. 与其他产业的融合

融合的通用路径是"行业知识 + 数据 + 算法"：先由行业专家定义问题与规则，再用感知设备获取数据，最后用算法把经验固化为可复用的模型。农业精准种植、医疗影像诊断、金融智能风控走的都是这条路径。

- **易错点**：①把数字孪生理解为"三维动画"，其核心是实时数据驱动的映射与仿真；②把工业互联网等同于"工厂上网"，其价值在数据汇聚后的分析优化；③认为融合只发生在制造业，忽视农业、医疗、金融、政务等领域的广泛融合。

## 本节小结

1. 新一代信息技术是云计算、大数据、人工智能、物联网、移动互联网、区块链、5G、数字媒体等新兴技术的统称，本质特征是万物互联、数据驱动、智能处理、服务化交付。
2. 各项技术回答不同问题：云计算供资源、大数据挖价值、人工智能做决策、物联网连万物、区块链建信任、5G 保传输。
3. 云计算与大数据互为支撑但不可混同；物联网连接"物"而非"人"；人工智能相较传统自动化具备学习与泛化能力。
4. 典型应用可按"感知—传输—存储计算—分析决策—可信存证"的数据链定位主导技术，这是场景题的通法。
5. 与制造业融合形成智能制造、工业互联网、数字孪生三种典型形态，与其他产业融合遵循"行业知识 + 数据 + 算法"的通用路径。
6. 判断题常设"技术等同""技术万能"陷阱，见到"就是""只用于"等绝对表述要警惕。

B. 工业互联网平台
C. 数字孪生
D. 用纸质台账手工登记设备维修记录

### 参考答案

1. **B**。新一代信息技术是技术族群的统称；A 错在以偏概全，C 错在它既含硬件也含软件与服务，D 错在二者在技术形态与范式上差异明显。
2. **C**。弹性伸缩与按量计费是云计算的标志性特征；物联网重感知，区块链重信任，大数据重分析。
3. **A**。从海量、多类型记录中发现偏好属于价值挖掘；其余选项与"分析出偏好"无直接对应。
4. **B**。实时映射加仿真预测是数字孪生的定义；柔性制造指产线切换能力，与虚拟映射无关。
5. **C**。物联网连接的核心对象是"物"，虽依托网络传输，但不能说连接对象仍是人。
6. **B**。防篡改、可追溯是区块链的核心特性；数字媒体只负责呈现，云计算提供资源，移动互联网负责接入。
7. **A**。柔性生产强调多品种、小批量的快速切换；批量生产追求单一品种的规模效率，二者相反。
8. **ABC**。D 错：纸质台账手工登记属于传统管理方式，既未联网也未产生数据驱动的优化，与融合形态无关。
