# 4.5 表达式、运算符与输入输出

> **考纲对应**：Python 程序设计基础 第 6 条——掌握 Python 程序设计语言的基本语法与表达式（层次：掌握）
> **教材对应**：Python 二级教程 · 第 3 章 基本数据类型

有了数据，就要对它们做运算；程序要与外界交互，就要读入和输出。表达式、运算符、input 与 print 四件事连起来，才构成一个"活的"程序。本节先系统梳理各类运算符及其优先级，再讲透 input() 的返回值陷阱和 print() 的三种格式化方式。这部分内容是上机题的高频操作，写不对就会在格式分上丢分。

## 一、表达式与运算符

### 1. 什么是表达式

**表达式**是由数据（常量、变量）和运算符组成的、能求出一个值的式子，例如 `3 + 5`、`a * b - 1`、`x > 0 and y > 0`。表达式本身可以只是一个常量或变量，`"hello"` 和 `n` 都是合法表达式。把表达式算出一个具体结果的过程叫**求值**。

表达式与语句的区别常被混淆：表达式一定有值，可以放在 `print()` 里或赋给变量；语句是执行某个动作的完整指令，如 `print(a)`、`import math`、`if x > 0:`，本身不一定有值。`a = 3` 整句是赋值语句，其中等号右边的 `3` 才是表达式。做题时看到"下列哪个是表达式"，就找那个能算出结果的内容。

Python 的运算符按功能分为六大类：算术运算符、比较运算符、逻辑运算符、赋值运算符、成员运算符和身份运算符。下面逐一说明。

### 2. 比较、逻辑、成员与身份运算符

**比较运算符**用于比较两个值，结果一定是布尔值：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| == | 等于 | 3 == 3 | True |
| != | 不等于 | 3 != 4 | True |
| > | 大于 | 3 > 4 | False |
| < | 小于 | 3 < 4 | True |
| >= | 大于等于 | 3 >= 3 | True |
| <= | 小于等于 | 3 <= 2 | False |

注意 `==` 是比较是否相等，`=` 是赋值，两者绝不能混用。Python 还支持**链式比较**，`0 < x < 10` 等价于 `0 < x and x < 10`，写法更贴近数学。

**逻辑运算符**有三个：`and`（与）、`or`（或）、`not`（非）。它们遵循**短路求值**规则：`A and B` 中若 A 为假，就不再计算 B，直接返回 A；`A or B` 中若 A 为真，就不再计算 B，直接返回 A。这使得逻辑运算的结果不一定是布尔值，而是参与运算的某个对象本身：

```python
print(0 and 5)
print(3 or 0)
print(not 0)
```

输出依次为 `0`、`3`、`True`。理解短路特性，才能看懂 `name or "匿名"` 这类"默认值"写法。短路还有一个实用副作用：`if b != 0 and a / b > 1:` 中，当 b 为 0 时第一个条件为假，后面的除法根本不会执行，从而避免除零错误。可见逻辑运算符的左右操作数顺序并非随意，把"容易为假且能挡住危险操作"的条件放在左边，是一种常见技巧。

**成员运算符** `in` 与 `not in` 判断某个元素是否存在于序列或集合中，如 `"a" in "abc"` 为 True。**身份运算符** `is` 与 `is not` 判断两个名字是否指向同一个对象，与 `==` 判断值是否相等不同。小整数和短字符串存在缓存，`a is b` 有时为 True 有时为 False，因此比较值一律用 `==`，`is` 只用于和 `None` 比较。

### 3. 赋值运算符

除最基本的 `=`，Python 还提供一组**复合赋值运算符**，把运算和赋值合并，写法更紧凑：

| 运算符 | 等价写法 | 示例（初始 a=10） | 结果 |
|--------|----------|-------------------|------|
| += | a = a + b | a += 5 | 15 |
| -= | a = a - b | a -= 5 | 5 |
| *= | a = a * b | a *= 2 | 20 |
| /= | a = a / b | a /= 4 | 2.5 |
| //= | a = a // b | a //= 3 | 3 |
| %= | a = a % b | a %= 3 | 1 |
| **= | a = a ** b | a **= 2 | 100 |

复合赋值看起来是"简写"，但并非完全等价：对可变对象（如列表）执行 `+=` 是原地修改，而 `a = a + b` 会创建新对象。初学阶段记住"复合赋值先算右边再存回左边"即可，遇到列表时再留意这一差异。

### 4. 运算符优先级

一个表达式里有多个运算符时，按优先级从高到低计算，同级从左到右（赋值和幂运算除外）。常用优先级如下表，从上到下依次降低：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1 | ** | 幂运算，右结合 |
| 2 | +x、-x、~x | 正负号、按位取反 |
| 3 | *、/、//、% | 乘除、整除、取余 |
| 4 | +、- | 加减 |
| 5 | <<、>> | 移位 |
| 6 | & | 按位与 |
| 7 | ^、\| | 按位异或、按位或 |
| 8 | <、<=、>、>=、==、!= | 比较 |
| 9 | not | 逻辑非 |
| 10 | and | 逻辑与 |
| 11 | or | 逻辑或 |
| 12 | =、+=、-= 等 | 赋值，右结合 |

记不住全表没关系，关键记住三条：**幂运算最高**，`2 ** 3 ** 2` 从右往左算得 512；**算术高于比较，比较高于逻辑**，所以 `1 + 2 > 2 and 3 < 4` 先算加法再比较；**not 高于 and 高于 or**。拿不准时加圆括号，既保证正确又提高可读性，括号永远是最稳妥的选择。

## 二、输入：input() 函数

### 1. 基本用法与返回值

`input(prompt)` 在屏幕上显示提示语，等待用户输入一行内容，按回车后把输入**作为字符串返回**。这个"永远返回字符串"的特性是所有输入错误的根源：

```python
age = input("年龄:")
print(type(age))
```

若输入 18，`type(age)` 显示 `<class 'str'>`，说明拿到的是字符串 `"18"` 而不是整数。要参与算术运算，必须转换类型：

```python
age = int(input("年龄:"))
```

若用户输入的不是合法整数，`int()` 会抛出 `ValueError`，程序中断。健壮的写法是配合异常处理（后续章节讲解）或先做合法性判断。另外要注意，`input()` 会把用户输入的回车之前的内容原样接收，不会自动去掉首尾空格，需要时用 `strip()` 处理，否则 `int(" 18 ")` 虽然能成功（int 会自动忽略空白），但用字符串比较时就容易出问题。

### 2. 一次读入多个值

考试中常需要在一行内输入多个数，用空格分隔。标准写法是 `split()` 拆分后用 `map()` 批量转换：

```python
a, b = map(int, input("输入两个整数:").split())
print(a + b)
```

`input()` 得到 `"3 5"`，`split()` 按空白拆成 `["3", "5"]`，`map(int, ...)` 把每个元素转成整数，最后解包给 a 和 b。若分隔符是逗号，写成 `split(",")` 即可。

这里有两个高频陷阱。其一，`input("a, b:")` 只是提示语里写了逗号，并不会真的按逗号拆分，用户输入 `3,5` 时得到的是字符串 `"3,5"`，必须写成 `split(",")`。其二，`a, b = input().split()` 得到的是两个字符串，虽然能解包成功，但 `a + b` 会变成字符串拼接，`"3" + "5"` 输出 `"35"` 而不是 `8`，一定要用 `map(int, ...)` 转换。

## 三、输出：print() 函数

### 1. 基本用法与 sep、end 参数

`print()` 可以一次输出多个对象，默认用**空格**分隔、末尾**换行**。两个关键字参数可以改变这一行为：`sep` 指定分隔符，`end` 指定结束符。

```python
print("2026", "11", "28", sep="-")
print("加载中", end="...")
print("完成")
```

第一行输出 `2026-11-28`；第二行因为 `end="..."` 不换行，第三行紧接其后，最终显示 `加载中...完成`。不写 `end` 时默认 `end="\n"`，这就是每条 print 独占一行的原因。

`print()` 可以混合输出不同类型的数据，它会自动调用各对象的 `str()` 转成字符串，因此 `print("总分", 253)` 不会报类型错误。这一点与字符串拼接不同：`"总分" + 253` 会直接报 TypeError，必须先 `str(253)`。初学时混淆这两种写法，是输出报错的常见原因。

### 2. 三种格式化方式

把变量嵌入一段文字中，Python 提供了三种主流写法，效果相同但推荐程度不同：

| 方式 | 写法示例 | 输出 | 特点 |
|------|----------|------|------|
| % 格式化 | `"%s 今年 %d 岁" % (name, age)` | 张三 今年 18 岁 | 源自 C 语言，较老旧 |
| format 方法 | `"{} 今年 {} 岁".format(name, age)` | 张三 今年 18 岁 | 功能强，写法略长 |
| f-string | `f"{name} 今年 {age} 岁"` | 张三 今年 18 岁 | 最简洁，Python 3.6+ 推荐 |

f-string 在字符串前加 `f`，花括号内可直接写变量甚至表达式，还支持格式说明符。例如 `f"{pi:.2f}"` 表示保留两位小数，`f"{score:>6}"` 表示右对齐占 6 位，`f"{rate:.1%}"` 表示按百分比显示。考试若未限定版本，优先用 f-string，代码最短也最不容易出错。

格式说明符的通用形式是 `[填充][对齐][宽度][.精度][类型]`。对齐符号中 `<` 左对齐、`>` 右对齐、`^` 居中，类型符号中 `f` 表示浮点、`d` 表示整数、`%` 表示百分比。下面这段代码演示对齐效果：

```python
for name, score in [("张三", 92), ("李四", 7)]:
    print(f"{name:<4}{score:>5.1f}")
```

输出两行，姓名左对齐占 4 个字符宽度，分数右对齐保留一位小数，即使 7 和 92 位数不同，小数点也能对齐。这种对齐技巧在输出表格类结果时非常实用。

需要注意的是，格式说明符里的宽度只是"最少占几位"，内容超出时不会被截断，而是原样输出。若要把浮点数固定为两位小数，必须写 `.2f` 而不是 `2f`，后者只是要求总宽度至少为 2。百分号格式虽然老旧，但二级考试的选择题仍会出现，三种写法至少要能读懂。

**例 4.5-1** 读入圆的半径，输出面积，要求保留两位小数，并用三种格式化方式各写一遍。

**解**

1. 用 `float()` 读入半径，π 取 3.14159。
2. 面积公式为 π × r²，用 `**` 求平方。
3. 分别用 %、format、f-string 输出，格式说明符统一为 `.2f`。

```python
r = float(input("r="))
area = 3.14159 * r ** 2
print("面积: %.2f" % area)
print("面积: {:.2f}".format(area))
print(f"面积: {area:.2f}")
```

若输入 2，三行都输出 `面积: 12.57`。注意 `%.2f` 中的 2 表示小数位数，f 表示浮点数；写成 `%.2d` 是整数补零，含义完全不同。

**例 4.5-2** 读入三门课的成绩（整数，空格分隔），输出总分和平均分，平均分保留一位小数。

**解**

1. 用 `map(int, input().split())` 一次读入三个整数。
2. 总分用 `+` 相加，平均分用 `/` 计算，结果自动为 float。
3. 用 f-string 的 `.1f` 保留一位小数。

```python
a, b, c = map(int, input("三门成绩:").split())
total = a + b + c
avg = total / 3
print(f"总分: {total}, 平均分: {avg:.1f}")
```

若输入 `85 90 78`，输出 `总分: 253, 平均分: 84.3`。这里若写成 `avg = total // 3`，会得到 84 而不是 84.3，整除与真除法的区别在此体现得非常直接。

- **易错点**：①把 `==` 写成 `=`，条件判断变成赋值；②`input()` 忘记类型转换，字符串相加变成拼接（`"1" + "2"` 得 `"12"`）；③`print(a, b)` 默认输出带空格，考试要求无空格时需用 `sep=""`；④`%.2f` 与 `{:.2f}` 的小数位混淆，`%2f` 表示总宽度而非两位小数；⑤f-string 前漏写 `f`，花括号被原样输出。

## 本节小结

1. 表达式由数据和运算符组成并能求出一个值；运算符分算术、比较、逻辑、赋值、成员、身份六类。
2. `==` 判断相等、`=` 赋值；比较运算结果为布尔值，支持 `0 < x < 10` 链式比较。
3. `and`、`or` 具有**短路求值**特性，结果可能是参与运算的对象本身；`is` 判断身份，只建议用于 `None`。
4. 优先级从高到低为：幂 → 正负号 → 乘除 → 加减 → 比较 → not → and → or → 赋值；拿不准就加括号。
5. `input()` **永远返回字符串**，参与算术前必须 `int()` 或 `float()`；多值输入用 `split()` 配合 `map()`。
6. `print()` 默认空格分隔、末尾换行，可用 `sep`、`end` 修改；格式化推荐 f-string，`:.2f` 保留两位小数。

## 自测题

1.（单选）`input()` 函数返回值的类型是（　）。
A. int　B. float　C. str　D. 由输入内容自动决定

2.（单选）表达式 `2 ** 3 ** 2` 的值是（　）。
A. 64　B. 512　C. 12　D. 36

3.（单选）执行 `print("a", "b", sep="-")` 的输出是（　）。
A. a b　B. a-b　C. ab　D. a,b

4.（单选）下列表达式中，结果为 True 的是（　）。
A. `3 != 3`　B. `not 0`　C. `"3" == 3`　D. `0 and 1`

5.（判断）`print()` 的 `end` 参数默认为换行符 `\n`。（　）

6.（填空）表达式 `7 % 3` 的值是________。

7.（填空）要读入一行以空格分隔的两个整数并分别赋给 a、b，应写成 `a, b = map(int, input().________())`。

8.（多选）下列关于输入输出的说法，正确的有（　）。
A. `input()` 返回的字符串可以直接与整数相加
B. `print()` 可以用 `sep` 参数指定多个输出项之间的分隔符
C. f-string 需要在字符串前加字母 f
D. `"%.2f" % 3.14159` 的结果是 "3.14"

### 参考答案

1. **C**。`input()` 不管用户输入什么，一律以字符串形式返回，类型转换需自己做。
2. **B**。幂运算右结合，先算 `3 ** 2 = 9`，再算 `2 ** 9 = 512`。
3. **B**。`sep="-"` 把多个输出项之间的默认空格替换为连字符。
4. **B**。`not 0` 为 True；`3 != 3` 为 False；字符串与整数类型不同，`"3" == 3` 为 False；`0 and 1` 因短路返回 0，也不是 True。
5. **对**。`print()` 默认 `end="\n"`，所以每次输出后自动换行。
6. **1**。
7. **split**。`input().split()` 按空白拆分，再经 `map(int, ...)` 转为整数。
8. **BCD**。A 错：`input()` 返回字符串，直接与整数相加会报 TypeError，必须先转换类型；B、C、D 均正确。
