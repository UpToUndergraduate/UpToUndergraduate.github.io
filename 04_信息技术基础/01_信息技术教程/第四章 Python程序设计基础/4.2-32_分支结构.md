# 4.6 分支结构

> **考纲对应**：Python 程序设计基础 第 6 条——掌握 Python 程序设计的流程控制（层次：掌握）
> **教材对应**：Python 二级教程 · 第 4 章 程序的控制结构

到目前为止，我们写的程序都是"一条道走到黑"的顺序结构。可现实中的决策几乎都带条件：成绩及格才发证书、余额足够才允许扣款、年份满足规则才是闰年。分支结构让程序学会"看情况办事"，是流程控制的第一块拼图。本节按单分支、双分支、多分支、嵌套的顺序展开，最后集中清理条件书写中的常见陷阱。

## 一、单分支结构

### 1. 语法格式

单分支是最简单的选择结构，语法为：

```text
if 条件表达式:
    语句块
```

执行逻辑是：先求条件表达式的值，若为 `True` 就执行缩进的语句块，若为 `False` 就跳过整个块，继续执行后面的语句。三个语法细节必须记牢：`if` 后必须有**条件表达式**，行末必须有**英文冒号**，下一行的语句块必须**缩进**。缺任何一项都会报 `SyntaxError` 或 `IndentationError`。

```python
score = 85
if score >= 60:
    print("及格")
print("程序结束")
```

这段代码先判断 85 是否大于等于 60，条件成立，输出"及格"，然后无条件输出"程序结束"。注意最后一行没有缩进，它不属于 if 的语句块，无论条件是否成立都会执行——缩进决定了语句的归属，这是读代码时首先要看清的地方。

单分支适合"满足条件时才做某事，不满足就什么都不做"的场景，比如余额充足时才扣款、文件存在时才读取。它的语句块可以有多行，只要这些行的缩进量完全相同，就同属一个块；一旦某行缩进减少，就表示该块结束。

### 2. 条件的写法

条件表达式可以是任何能得出真假的式子，常见形式有比较运算、逻辑运算、成员运算，以及直接放一个变量：

- `if score >= 60:` 比较运算，最常用。
- `if 0 < x < 100:` 链式比较，等价于两个条件同时成立。
- `if name:` 判断变量是否非空，非空即真。
- `if not flag:` 对布尔值取反。
- `if ch in "aeiou":` 成员运算，判断字符是否为元音。

要注意 `if x = 5:` 是语法错误，条件里只能用 `==`；`if x == 5` 后面忘了冒号同样是语法错误。条件表达式的结果不要求一定是布尔值，Python 会按"零、空、None 为假"的规则自动转换。

## 二、双分支结构

### 1. if-else

当条件成立做一件事、不成立做另一件事时，用双分支：

```text
if 条件表达式:
    语句块 1
else:
    语句块 2
```

两个分支**必有一个且只有一个**会被执行。`else` 后面直接跟冒号，不写条件。

```python
n = int(input("n="))
if n % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

输入 7 时，`7 % 2` 得 1，条件为假，执行 else 分支，输出"奇数"。`else` 不能单独使用，必须与 `if` 配对，且两者必须对齐在同一缩进层级。

双分支的价值在于"把两种情况都交代清楚"，程序不会出现既没输出、又没提示的空档。写双分支时，语句块 1 和语句块 2 各自可以包含多条语句，但两个块的缩进必须一致，不能一个 4 个空格、一个 8 个空格，否则第二块会被误认为嵌套在里面。

### 2. 条件表达式

对于"二选一赋值"这种简单场景，Python 提供了更紧凑的**条件表达式**（也叫三元表达式）：

```python
# 语法: 值1 if 条件 else 值2
```

条件为真取"值1"，为假取"值2"。例如求两数较大值可以写成一行：

```python
a, b = 3, 8
max_value = a if a > b else b
print(max_value)
```

输出 8。条件表达式适合逻辑简单、能一眼看懂的场合；如果两个分支各自要做多件事，还是老老实实写 if-else，可读性更重要。

## 三、多分支结构

### 1. if-elif-else

当情况超过两种时，用 `elif`（else if 的缩写）串联多个条件：

```text
if 条件 1:
    语句块 1
elif 条件 2:
    语句块 2
elif 条件 3:
    语句块 3
else:
    语句块 4
```

执行时**自上而下依次判断**，一旦某个条件成立，就执行对应语句块，然后跳出整个结构，后面的条件不再判断。因此条件的**书写顺序至关重要**：如果把宽松的条件写在前面，后面更精确的条件就永远轮不到。

`else` 可以省略，但省略后若所有条件都不成立，就什么也不做。`elif` 可以有任意多个，且必须与 `if` 对齐。实际编码时建议总是保留 else 兜底，便于发现未预料到的输入。

### 2. 多分支与多个 if 的区别

初学者常把 `if-elif` 写成三个独立的 `if`，两者含义完全不同：

| 写法 | 判断方式 | 可能执行的块数 | 适用场景 |
|------|----------|----------------|----------|
| if-elif-else | 自上而下，命中即跳出 | 至多 1 个 | 多种情况互斥，如成绩等级 |
| 多个独立 if | 每个条件都判断 | 0 到多个 | 多个独立条件，如同时检查多项规则 |

例如判断一个数"是正数、是偶数、是 3 的倍数"，这三件事并不互斥，6 同时满足后两条，就应该用三个独立的 if；而成绩等级 A、B、C、D 互斥，必须用 if-elif。判断口诀很简单：条件之间会"抢"同一个结果就用 if-elif，不会抢就用多个 if。

### 3. 分支的嵌套

一个分支的语句块里再写一个完整的 if 结构，就是**嵌套**。嵌套用来表达"先满足大前提，再细分小情况"的逻辑，例如"先判断是否登录，登录后再判断是否为管理员"：

```python
logged = True
is_admin = False
if logged:
    if is_admin:
        print("进入管理后台")
    else:
        print("进入个人中心")
else:
    print("请先登录")
```

书写嵌套时，**每一层都要比外层多缩进 4 个空格**，层级越深越难读。通常嵌套不超过三层，超过就应考虑拆分函数或改用逻辑运算符合并条件。

嵌套最容易出的错是**悬垂 else**：当 if 与 else 数量不匹配时，Python 规定 `else` 与**离它最近、尚未配对**的 `if` 结合，而不是看缩进"看起来像谁"。因此写嵌套时务必让内外层的缩进清晰可辨，必要时用注释标出配对关系。

### 4. 条件书写的要点

- **避免用 `==` 比较浮点数**：`0.1 + 0.2 == 0.3` 为 False，应写成 `abs((0.1 + 0.2) - 0.3) < 1e-9`。
- **优先用真值判断**：判断列表非空写 `if items:`，比 `if len(items) > 0:` 更简洁。
- **注意 `and` 与 `or` 的优先级**：`and` 高于 `or`，混合使用时加括号能避免歧义。
- **条件要覆盖所有情况**：多分支务必让 else 兜底，或确认所有可能取值都已被某个条件覆盖，否则会出现"什么都不做"的漏洞。

**例 4.6-1** 读入百分制成绩（0 到 100 的整数），按下列规则输出等级：90 分及以上为 A，80 到 89 为 B，70 到 79 为 C，60 到 69 为 D，60 以下为 E。

**解**

1. 用 `int()` 读入成绩。
2. 用 if-elif-else 从高到低判断，先判 `>= 90`，再判 `>= 80`，依次递减。
3. 因为命中即跳出，后面的条件无需再写上限，`>= 80` 隐含了"小于 90"。

```python
score = int(input("成绩:"))
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "E"
print("等级:", grade)
```

输入 85 时依次判断：`85 >= 90` 为假，`85 >= 80` 为真，grade 赋值为 B，随后跳出，输出 `等级: B`。若把条件顺序写反，先判 `>= 60`，则 85 会直接命中 D，这就是"顺序决定结果"的典型例子。

**例 4.6-2** 读入一个年份，判断它是否为闰年。规则是：能被 4 整除但不能被 100 整除，或者能被 400 整除。

**解**

1. 闰年的两个条件是"或"的关系，任一成立即是闰年。
2. 第一个条件用 `year % 4 == 0 and year % 100 != 0` 表示。
3. 第二个条件用 `year % 400 == 0` 表示，两者用 `or` 连接。
4. 注意 `and` 的优先级高于 `or`，即使不加括号结果也正确，但加括号更清晰。

```python
year = int(input("year="))
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print(year, "是闰年")
else:
    print(year, "不是闰年")
```

输入 2000，`2000 % 400 == 0` 成立，输出"2000 是闰年"；输入 1900，既不能被 400 整除，又能被 100 整除，两个条件都不成立，输出"1900 不是闰年"；输入 2024，满足第一个条件，是闰年。这三组数据正好覆盖了规则的每个分支，测试时应当都跑一遍。

**例 4.6-3** 读入三个整数，输出其中的最大值（不使用内置函数 max）。

**解**

1. 先假设第一个数为最大值，存入变量 `m`。
2. 依次与第二个、第三个数比较，遇到更大的就更新 `m`。
3. 这种"打擂台"思路可以推广到任意多个数。

```python
a, b, c = map(int, input("三个数:").split())
m = a
if b > m:
    m = b
if c > m:
    m = c
print("最大值:", m)
```

输入 `3 9 5`，m 先为 3，9 比 3 大更新为 9，5 不比 9 大保持不变，输出 `最大值: 9`。这里用的是两个**独立的 if** 而不是 if-elif，因为两次比较都要执行，不能命中一次就跳出。

- **易错点**：①`if`、`elif`、`else` 行末漏写英文冒号；②用中文全角冒号"："导致 SyntaxError；③多分支条件顺序颠倒，宽松条件写在前面使精确条件失效；④把互斥的多分支误写成多个独立 if，导致多次输出；⑤`else` 与错误的 `if` 对齐，形成"悬垂 else"；⑥直接用 `==` 比较两个浮点数是否相等。

## 本节小结

1. 单分支 `if 条件:` 在条件为真时执行缩进块，条件为假则跳过；冒号和缩进是硬性语法要求。
2. 双分支 `if-else` 两个分支必执行其一；`else` 不带条件，必须与 `if` 对齐。
3. 条件表达式 `值1 if 条件 else 值2` 适合简单的二选一赋值，复杂逻辑仍用 if-else。
4. 多分支 `if-elif-else` **自上而下判断、命中即跳出**，条件顺序直接决定结果，应从严格到宽松排列。
5. 互斥情况用 if-elif，多个独立条件用多个 if，二者不可混用。
6. 常用条件写法包括链式比较、逻辑运算、成员运算和真值判断；浮点数比较应判断差值而非直接用 `==`。

```python
x = 75
if x >= 60:

```
A. D　B. C　C. B　D. 无输出

D. `year % 100 == 0 and year % 400 == 0`

5.（判断）在 if-elif-else 结构中，若多个条件同时成立，则所有成立分支的语句块都会执行。（　）

6.（填空）在双分支结构中，条件不成立时执行的子句关键字是________。

B. else 子句可以省略

### 参考答案

1. **B**。if 行末必须写英文冒号；条件不必是布尔值，非布尔值会按真值规则转换；语句块必须缩进；else 后不跟条件。
2. **A**。条件自上而下判断，75 >= 60 首先成立，输出 D 后跳出，后续 elif 不再判断。这正是条件顺序写反的典型后果。
3. **A**。3 > 2 为真，条件表达式取前面的值 5。
4. **B**。闰年规则是"能被 4 整除且不能被 100 整除"或"能被 400 整除"，A 用 or 连接会把 1900 也判成闰年，C、D 均遗漏条件。
5. **错**。if-elif 是互斥判断，命中第一个成立的条件后立即跳出，后面的分支不会执行。
6. **else**。
7. **奇数**。n 为 7 时条件为假，取 else 后面的值。
8. **ABD**。C 错：多个独立 if 会逐个判断所有条件，可能执行多个块；if-elif 命中即跳出，至多执行一个块，二者只有在条件互斥时才结果相同；A、B、D 均正确。
