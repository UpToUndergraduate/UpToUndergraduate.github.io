# 4.4 基本数据类型

> **考纲对应**：Python 程序设计基础 第 6 条——掌握 Python 程序设计语言的数据类型（层次：掌握）
> **教材对应**：Python 二级教程 · 第 3 章 基本数据类型

数据是程序的原料，类型决定了这份原料能做什么运算、占用多少空间、如何显示。Python 把数据分为数字、字符串、布尔值等几大基本类型，每种类型都有自己的规则和陷阱。本节先讲数字类型及其运算，再讲类型转换，然后进入字符串与布尔值。把这些类型吃透，后面的表达式、分支、循环才有坚实的落脚点。

## 一、数字类型

### 1. 整数、浮点数与复数

Python 的数字类型主要有三种，另有布尔类型作为整数的特殊分支：

| 类型 | 关键字 | 示例 | 说明 |
|------|--------|------|------|
| 整数 | int | 0、-7、1000000 | 任意精度，不会溢出 |
| 浮点数 | float | 3.14、-0.5、1.5e3 | 带小数或科学计数法，遵循 IEEE 754 |
| 复数 | complex | 1+2j、3j | 实部与虚部，工程计算用 |
| 布尔值 | bool | True、False | int 的子类，True 为 1，False 为 0 |

整数类型最值得称道的是**任意精度**：C 语言的 int 超过 21 亿就会溢出，而 Python 的整数可以表示任意大的数，`2 ** 1000` 也能精确算出。浮点数则遵循 IEEE 754 双精度标准，大约保留 15 到 17 位有效数字，超出部分会被舍入，这也埋下了精度误差的伏笔。

整数可以用不同进制书写：`0b1010` 是二进制 10，`0o17` 是八进制 15，`0x1F` 是十六进制 31。`bin()`、`oct()`、`hex()` 三个函数可以把整数转换成对应进制的字符串。

实际编程中，`type()` 是最常用的"探针"，把变量传进去就能知道它到底是什么类型：

```python
print(type(10))
print(type(10.0))
print(type(True))
```

输出依次是 `<class 'int'>`、`<class 'float'>`、`<class 'bool'>`。记住这个写法，遇到"这个值到底是什么类型"的疑惑时，打印一下比猜要可靠得多。类型之所以重要，是因为它决定了数据能参与哪些运算：整数和浮点数可以相乘，字符串只能和字符串相加，布尔值又能当整数参与算术，这些规则都由类型系统在背后把关。

不同数字类型适用的场景也不同：计数、编号、循环次数用 int；测量值、比例、科学计算用 float；交流电分析、信号处理等工程领域才会用到 complex；而 bool 主要用于条件判断，虽然它本质上是 int，但把它当数字做算术只会让代码难以理解。

### 2. 浮点数的精度问题

初学者常被这个结果吓到：

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
```

第一行输出 `0.30000000000000004`，第二行输出 `False`。原因在于 0.1 和 0.2 在二进制下都是无限循环小数，存储时已被截断，相加后的误差被放大。这不是 Python 的缺陷，而是所有采用 IEEE 754 的语言共有的现象。

处理办法是不要直接用 `==` 比较两个浮点数，而是判断差值是否足够小：

```python
print(abs((0.1 + 0.2) - 0.3) < 1e-9)
```

这段代码输出 `True`。若业务要求精确的小数运算（如金额），可以使用 `decimal` 模块，而不是 float。

```python
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))
```

输出正是 `0.3`。`Decimal` 以字符串形式接收数值，按十进制规则精确计算，代价是速度比 float 慢，因此只在必须精确的场合使用。另一种思路是先把小数放大成整数再运算，算完再缩小，比如金额都换算成"分"。

考试一般不深究 `decimal` 的用法，但"浮点数不能直接用等号比较"这条结论必须牢记，选择题和判断题都爱考。

## 二、数值运算与类型转换

### 1. 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| + | 加 | 7 + 2 | 9 |
| - | 减 | 7 - 2 | 5 |
| * | 乘 | 7 * 2 | 14 |
| / | 真除法 | 7 / 2 | 3.5 |
| // | 整除（向下取整） | 7 // 2 | 3 |
| % | 取余 | 7 % 2 | 1 |
| ** | 幂运算 | 7 ** 2 | 49 |

两个易错点必须记牢：**`/` 的结果永远是 float**，即使 `4 / 2` 也得到 `2.0`；**`//` 是向下取整而非截断**，`-7 // 2` 的结果是 `-4` 而不是 `-3`，因为 -4 比 -3 更小。取余 `%` 的结果符号跟随除数，`-7 % 2` 得 `1`，`7 % -2` 得 `-1`。

`divmod(a, b)` 可以一次得到商和余数，返回一个元组，常用于进制转换和分组问题。

当 int 与 float 混合运算时，结果会自动"升级"为 float，例如 `3 + 0.5` 得 `3.5`，`10 / 2` 得 `5.0`。这种隐式类型提升让表达式写起来很方便，但也容易让人误以为整数除法还能得到整数。若确实需要整数结果，应显式使用 `//` 或 `int()` 转换。布尔值参与算术时会被当作 1 或 0，`True + True` 的结果是 `2`，了解即可，实际项目中不建议这样写。

### 2. 类型转换

Python 提供四个常用的类型转换函数，转换规则如下：

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| int(x) | 转为整数 | int(3.9)、int("12") | 3、12 |
| float(x) | 转为浮点数 | float("3.5")、float(2) | 3.5、2.0 |
| str(x) | 转为字符串 | str(3.14) | "3.14" |
| bool(x) | 转为布尔值 | bool(0)、bool("a") | False、True |

关键细节：`int()` 对浮点数是**截断小数部分**，不是四舍五入，`int(-3.9)` 得到 `-3`；`int("3.5")` 会直接报 `ValueError`，字符串转整数时内容必须形如整数，想转小数要先 `float("3.5")` 再 `int()`。`str()` 几乎能把任何对象转成字符串，是拼接输出时的常用手段。

判断一个值是否属于某个类型，可以用 `isinstance()`，它比 `type()` 更适合处理继承关系：

```python
print(isinstance(3, int))
print(isinstance(True, int))
```

两行都输出 `True`，因为 bool 继承自 int。这个例子再次说明理解类型的继承关系对读懂代码很有帮助。

### 3. 布尔值与"假值"

布尔类型只有 `True` 和 `False` 两个值，注意首字母大写。`bool()` 转换遵循一条简单规则：**零、空、None 为假，其余为真**。具体来说，下列值转成布尔值都是 `False`：

- 数字 `0`、`0.0`、`0j`
- 空字符串 `""`
- 空列表 `[]`、空元组 `()`、空字典 `{}`、空集合 `set()`
- `None` 和 `False` 本身

除上述之外的一切值都是 `True`，包括字符串 `"0"` 和 `"False"`——它们非空，所以为真。这一点在条件判断中经常被用来简化代码，例如 `if name:` 表示"name 非空"。

还要注意 `True == 1` 与 `False == 0` 都成立，因为布尔值本质上是整数；但 `"True"` 只是字符串，和布尔值 `True` 毫无关系，二者比较结果为假。判断空值时优先写 `if not x:`，比 `if x == "":` 更通用也更简洁。

## 三、字符串类型

### 1. 字符串的表示

字符串是字符的有序序列，用一对引号包裹。Python 允许单引号、双引号、三引号三种写法，单双引号完全等价，三引号可以跨行书写：

```python
s1 = 'hello'
s2 = "world"
s3 = """第一行
第二行"""
```

当字符串内部本身含有引号时，外层换一种引号即可避免转义，如 `"He said 'hi'"`。空字符串写成 `""` 或 `''`，它的长度为 0，在条件判断中为假，常用来表示"还没有输入内容"的初始状态。

Python 3 的字符串以 Unicode 存储，`len("中文")` 的结果是 2，一个汉字算一个字符，这一点比 C 语言按字节计数方便得多，处理中文文本时不必担心半个汉字被截断的问题。

### 2. 转义字符

反斜杠 `\` 用来表示无法直接输入的特殊字符，常用转义序列如下：

| 转义字符 | 含义 | 转义字符 | 含义 |
|----------|------|----------|------|
| \n | 换行 | \\\\ | 一个反斜杠 |
| \t | 制表符 | \\' | 单引号 |
| \r | 回车 | \\" | 双引号 |

若希望反斜杠就是普通字符（如写 Windows 路径 `C:\new`），可以在字符串前加 `r` 构成**原始字符串**：`r"C:\new"`，此时 `\n` 不再被解释为换行。原始字符串常用于正则表达式和文件路径，但它不能以奇数个反斜杠结尾，因为末尾的反斜杠会把自己的结束引号转义掉。

初学者常把转义符号写反，例如把 `\n` 写成 `/n`，结果屏幕上原样输出 `/n` 而不是换行。转义字符一定用**反斜杠**，并注意大小写敏感：`\N` 会被解析为另一种 Unicode 转义形式，并不是换行，写错时甚至直接报语法错误。

### 3. 字符串的基本操作

字符串支持 `+` 拼接和 `*` 重复，`len()` 返回字符个数：

```python
print("Py" + "thon")
print("ab" * 3)
print(len("Python"))
```

输出分别为 `Python`、`ababab`、`6`。要注意字符串与数字不能直接相加，`"年龄" + 18` 会报 `TypeError`，必须先 `str(18)`。字符串是**不可变**对象，任何"修改"操作实际上都返回一个新字符串，原字符串保持不变。

### 4. 字符串的常用方法

字符串自带大量方法，调用时不会改变原字符串，而是返回处理后的新字符串。下表列出最常用的几个：

| 方法 | 作用 | 示例 | 结果 |
|------|------|------|------|
| upper() | 转大写 | "ab".upper() | "AB" |
| lower() | 转小写 | "AB".lower() | "ab" |
| strip() | 去除首尾空白 | " a ".strip() | "a" |
| replace(a, b) | 替换子串 | "aXa".replace("X", "b") | "aba" |
| split(sep) | 按分隔符切分 | "a,b".split(",") | ["a", "b"] |
| find(s) | 查找子串位置 | "abc".find("b") | 1 |
| count(s) | 统计子串次数 | "aba".count("a") | 2 |

`split()` 返回的是列表，`find()` 找不到时返回 `-1` 而不是报错，这两个细节常出现在选择题中。字符串还支持用下标访问单个字符、用切片取出连续片段，例如 `s[0]` 取首字符、`s[1:3]` 取第 2 到第 3 个字符，下标从 0 开始，这部分内容在后续组合数据类型一节中还会系统展开。

**例 4.4-1** 读入两个整数，输出它们的和、差、积、商（商保留两位小数），并说明类型转换的必要性。

**解**

1. 用 `input()` 读入的是字符串，必须用 `int()` 转为整数才能做算术运算。
2. 和、差、积用 `+`、`-`、`*`；商用 `/`，结果自动为 float。
3. 用 `round()` 保留两位小数，或使用格式化输出。

```python
a = int(input("a="))
b = int(input("b="))
print("和:", a + b)
print("差:", a - b)
print("积:", a * b)
print("商:", round(a / b, 2))
```

若输入 a=7、b=2，输出和为 9、差为 5、积为 14、商为 3.5。若把 `int` 换成 `float`，输入 7.5 和 2 也能正常工作，区别在于是否接受小数输入。

**例 4.4-2** 读入一个三位正整数，输出它的百位、十位、个位数字之和。

**解**

1. 用 `int()` 读入整数 n。
2. 百位 = `n // 100`，十位 = `n // 10 % 10`，个位 = `n % 10`。
3. 三者相加输出。整除和取余配合，是拆分数字的通用手法。

```python
n = int(input("n="))
hundreds = n // 100
tens = n // 10 % 10
units = n % 10
print(hundreds, tens, units)
print("各位数字之和:", hundreds + tens + units)
```

若输入 352，输出 `3 5 2` 与 `各位数字之和: 10`。注意 `input()` 读到的 `"352"` 若不转换，`"352" // 100` 会直接报错。

- **易错点**：①误以为 `int(3.9)` 是四舍五入，实际是截断；②用 `==` 直接比较浮点数，被精度误差坑到；③把 `-7 // 2` 算成 `-3`，忽略向下取整；④`int("3.5")` 直接转换报 ValueError，应先转 float；⑤字符串与数字相加忘记 `str()` 转换。

## 本节小结

1. 基本数字类型有 **int、float、complex、bool**；int 为任意精度，float 遵循 IEEE 754，bool 是 int 的子类。
2. `/` 的结果总是 float，`//` 是**向下取整**，`%` 的结果符号跟随除数，`**` 表示幂运算。
3. 浮点数存在精度误差，`0.1 + 0.2 != 0.3`，比较时应判断差值绝对值是否足够小。
4. `int()` 对浮点数是**截断**而非四舍五入，`int("3.5")` 会报错，需先转 float。
5. 字符串可用单、双、三引号表示，`\n`、`\t` 等是转义字符，`r""` 构成原始字符串，`+` 拼接、`*` 重复、`len()` 求长度。
6. 布尔值只有 True 和 False；**零、空、None 为假，其余为真**，注意字符串 `"0"` 为真。

5. **错**。0.1 与 0.2 的二进制表示都有误差，相加得 0.30000000000000004，与 0.3 不相等。
6. **8**。
