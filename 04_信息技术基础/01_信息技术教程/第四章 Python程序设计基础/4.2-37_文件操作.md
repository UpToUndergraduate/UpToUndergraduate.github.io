# 4.11 文件操作

> **考纲对应**：Python 程序设计基础 第 6 条——掌握文件的打开、读写与关闭，能对文本文件进行基本的数据处理（层次：掌握）
> **教材对应**：Python 二级教程 · 第 7 章 文件和数据格式化

程序运行结束后，变量中的数据随之消失；要让数据"留下来"，就必须写入文件。文件操作是程序与外部世界交换数据的基本通道：读配置、存日志、导出报表、处理 CSV 数据，都离不开它。本节按照"打开—读写—关闭"的生命周期展开，重点掌握 `open()` 的模式参数、三种读取方法的区别、写入与追加的差异，以及用 `with` 语句确保文件被正确关闭。

## 一、文件的打开与关闭

### 1. 文本文件与二进制文件

按数据的组织方式，文件分为两类：**文本文件**由字符组成，按某种编码（如 UTF-8）存储，可用记事本直接阅读；**二进制文件**由字节组成，如图片、音频、可执行文件，必须用专门的软件解析。Python 处理文本文件时会在字符与字节之间自动编解码，处理二进制文件时则原样读写字节，需要在模式中加 `b`。

选择模式时还要注意读写方向与文件类型的组合：`"rb"` 用于读图片、压缩包，`"wb"` 用于写二进制数据；`"r+"` 适合"读出来、改一处、再写回"的场景，但改写的长度必须与原内容一致，否则会覆盖后续字节，因此实务中更常见的做法是读入内存、整体重写。

### 2. open() 函数与模式参数

打开文件的语法为 `open(文件路径, 模式, encoding=编码)`，返回一个文件对象：

```python
f = open("demo.txt", "r", encoding="utf-8")
content = f.read()
f.close()
```

第二个参数决定操作方式，是最常考的知识点：

| 模式 | 含义 | 文件存在 | 文件不存在 |
|---|---|---|---|
| `"r"` | 只读（默认） | 从头读 | 抛 `FileNotFoundError` |
| `"w"` | 只写 | **清空原内容**再写 | 新建文件 |
| `"a"` | 追加写 | 在末尾追加 | 新建文件 |
| `"x"` | 独占创建 | 报错 | 新建文件 |
| `"r+"` | 读写 | 可读可写，不清空 | 报错 |
| `"rb"` / `"wb"` | 二进制读 / 写 | 按字节处理 | 视模式而定 |

必须牢记：`"w"` 是"覆盖式"打开，只要执行 `open(..., "w")`，即使不写任何内容，原文件也会被清空。因此修改文件内容时，通常先读入内存、处理完再整体写回，而不是边读边写同一个文件。

### 3. 关闭文件与 with 语句

文件使用完毕必须关闭，`close()` 的作用是把缓冲区中的数据真正写入磁盘并释放系统资源。若程序异常退出而没有关闭，数据可能丢失。更稳妥的写法是 `with` 语句：

```python
with open("demo.txt", "r", encoding="utf-8") as f:
    print(f.read())
```

`with` 块结束时自动调用 `close()`，即使块内发生异常也能保证关闭，因此是官方推荐的写法。`with` 块内可以写多行，但文件对象 `f` 只在块内有效，块外再访问会得到已关闭的文件对象。

- **易错点**：① 忘记 `encoding="utf-8"` 时，Windows 默认用 GBK 打开，读取含中文的文件会抛 `UnicodeDecodeError`；② 用 `"w"` 打开已有文件会立即清空内容，误操作将无法恢复；③ 路径中的反斜杠要写成 `\\` 或使用原始字符串 `r"C:\data\a.txt"`，也可直接使用正斜杠 `"C:/data/a.txt"`。

## 二、文件的读写方法

### 1. 三种读取方式

| 方法 | 返回类型 | 特点 |
|---|---|---|
| `read()` | 字符串 | 一次读完全部内容，可指定字节/字符数 |
| `readline()` | 字符串 | 每次读一行，含行末换行符 |
| `readlines()` | 列表 | 一次读完，每行作为列表的一个元素 |

```python
with open("demo.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
print(len(lines), lines[0].strip())
```

文件对象本身是**可迭代**的，因此 `for line in f:` 是最省内存的逐行读取方式：它每次只把一行载入内存，适合处理大文件。`read()` 与 `readlines()` 会把整个文件读入内存，文件很大时可能耗尽资源。

文件对象内部维护一个**读写指针**，所有读写都从指针当前位置开始。`tell()` 返回指针位置，`seek(偏移量, 起点)` 移动指针，起点 0 表示文件开头、1 表示当前位置、2 表示文件末尾。读完一遍后指针停在末尾，此时再 `read()` 只能得到空串，想重读就必须先 `seek(0)`。读取时还可以给 `read(n)` 传入字符数，分块读取大文件正是靠它实现的。

### 2. 写入与追加

`write(s)` 把字符串写入文件，返回写入的字符数；`writelines(seq)` 把字符串序列依次写入，但**不会自动添加换行符**，需要自己在每个元素末尾写 `\n`。写入的内容必须是字符串，数字要先 `str()` 转换，否则抛 `TypeError`。

```python
with open("demo.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.writelines(["第二行\n", "第三行\n"])
```

用 `"a"` 模式打开时，新内容追加在末尾，原内容保留，这是写日志的标准做法。写入的数据先进入缓冲区，缓冲区满或文件关闭时才真正落盘，因此程序异常退出可能丢失最后一段内容；若需要立即写盘，可调用 `f.flush()`。

文本写入还涉及换行符差异：Windows 下换行是 `\r\n`，Linux 下是 `\n`。用文本模式写入时 Python 会自动把 `\n` 转换为平台默认换行，读回时又会自动还原，因此跨平台处理文本通常不必手动干预，只有写 CSV 时需要 `newline=""` 关闭这一转换。

**例 4.11-1**

先向 `demo.txt` 写入三行文本，再逐行读出并加上行号打印。

**解**

1. 用 `"w"` 模式创建文件并写入三行，每行末尾显式加 `\n`。
2. 换用 `"r"` 模式重新打开，用 `enumerate(f, 1)` 让行号从 1 开始。
3. 用 `strip()` 去掉行末换行符，避免输出出现空行。

```python
with open("demo.txt", "w", encoding="utf-8") as f:
    f.write("Python 文件操作\n")
    f.writelines(["读取与写入\n", "关闭与异常\n"])

with open("demo.txt", "r", encoding="utf-8") as f:
    for number, line in enumerate(f, 1):
        print(number, line.strip())
```

运行结果（运行前需保证当前工作目录可写，文件会创建在脚本所在目录）：

```
1 Python 文件操作
2 读取与写入
3 关闭与异常
```

**分析**：第一次 `with` 结束后文件已关闭并落盘，第二次才能读到完整内容。若把读写放在同一个 `with` 块且用 `"w"` 模式，文件已被清空，读到的是空串。`strip()` 去掉的是行末的 `\n`，若文件本身有缩进，不应使用 `strip()` 而应用 `rstrip("\n")`。

- **易错点**：① `writelines` 不补换行，三行内容会连成一行；② `readline()` 返回的字符串带 `\n`，比较内容前要 `strip()`；③ 文件读完后指针停在末尾，再调用 `read()` 返回空串，需要 `seek(0)` 回到开头。

## 三、文件的典型应用

### 1. 统计文本信息

最常见的任务是统计行数、字符数与词频。逐行遍历文件，累加 `len(line)` 得到字符数，用 `line.split()` 拆出单词后用字典计数，即可完成一份简易的文本分析。

词频统计的骨架与前面字符统计类似，只是累计对象换成了单词：

```python
counts = {}
with open("demo.txt", "r", encoding="utf-8") as f:
    for line in f:
        for word in line.split():
            counts[word] = counts.get(word, 0) + 1

for word, n in sorted(counts.items(), key=lambda x: x[1], reverse=True):
    print(word, n)
```

这段代码同时用到了文件迭代、`split()` 拆词、字典计数与按值排序，是文件与组合数据类型两章知识的综合运用，建议作为上机练习反复默写。

**例 4.11-2**

统计 `demo.txt` 的总行数、非空行数与总字符数（不含换行符）。

**解**

1. 用三个计数器分别记录总行数、非空行数和字符数。
2. 逐行遍历，用 `len(line.rstrip("\n"))` 累计字符数。
3. 用 `line.strip()` 判断该行是否为空。

```python
total_lines = nonempty_lines = total_chars = 0

with open("demo.txt", "r", encoding="utf-8") as f:
    for line in f:
        total_lines += 1
        total_chars += len(line.rstrip("\n"))
        if line.strip():
            nonempty_lines += 1

print("总行数：", total_lines)
print("非空行数：", nonempty_lines)
print("总字符数：", total_chars)
```

以例 4.11-1 生成的文件为例，运行结果为：

```
总行数： 3
非空行数： 3
总字符数： 21
```

**分析**：`rstrip("\n")` 只去掉行末换行符，保留行首缩进，统计更准确；若用 `strip()`，行首尾的空格也会被去掉，导致字符数偏小。判断空行时用 `line.strip()` 是因为某些行可能只含空格或制表符，肉眼看似空白，实际不为空串。

### 2. CSV 文件的读写

CSV（逗号分隔值）是最通用的表格交换格式，每行一条记录，字段之间用逗号分隔。虽可用 `split(",")` 手工解析，但字段内含逗号或引号时会出错，标准做法是使用标准库 `csv`：

```python
import csv

rows = [["姓名", "成绩"], ["张三", "88"], ["李四", "95"]]
with open("score.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows(rows)

total = count = 0
with open("score.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    next(reader)                   # 跳过表头
    for row in reader:
        total += int(row[1])
        count += 1
print("平均分：%.1f" % (total / count))
```

运行结果为 `平均分：91.5`。写 CSV 时务必加 `newline=""`，否则 Windows 下每行之间会多出空行；读出的每个字段都是字符串，做算术前要转换类型。若要按表头取值，可用 `csv.DictReader`，它把每行读成字典，字段名即键名。

另一种常见的格式是 JSON，它支持嵌套结构，适合保存字典与列表。标准库 `json` 提供四个函数：`dump()` 把对象写入文件、`load()` 从文件读出对象、`dumps()` 与 `loads()` 在字符串与对象之间转换。写入时加参数 `ensure_ascii=False`，中文才不会被转成 `\uXXXX` 形式的转义序列。

- **易错点**：① 读出的数字是字符串，`sum()` 前必须 `int()` 或 `float()` 转换；② CSV 用 Excel 打开出现乱码，通常是编码不一致，可加 `encoding="utf-8-sig"`；③ 用 `"w"` 写文件前要确认不是要保留的原文件，否则数据会被覆盖。

## 本节小结

1. 文件操作遵循"打开—读写—关闭"流程，`open()` 返回文件对象，`close()` 负责落盘与释放资源。
2. 模式 `"r"` 只读、`"w"` 覆盖写、`"a"` 追加写、`"x"` 独占创建，加 `b` 表示二进制、加 `+` 表示可读可写。
3. 推荐使用 `with open(...) as f:`，块结束自动关闭，异常时也不遗漏。
4. `read()` 返回整串、`readline()` 返回一行、`readlines()` 返回列表，逐行迭代最省内存。
5. `write()` 只接受字符串，`writelines()` 不自动加换行；写入数字前须先转换类型。
6. CSV 读写用 `csv` 模块，写时加 `newline=""`，读出的字段需按需转换类型。

7.（编程）编写程序统计 `demo.txt` 中的行数，并输出最长一行的长度。

8.（多选）关于文件操作，下列说法正确的是（　）。
A. `"r+"` 模式打开的文件既可读也可写
B. 二进制模式需要在模式字符串中加 `b`
C. 用 `"w"` 模式打开不存在的文件会抛出 `FileNotFoundError`
D. `writelines()` 会自动在每段内容后添加换行符

### 参考答案

1. **B**。`"a"` 为追加模式，指针定位到文件末尾，原内容保留。
2. **C**。`readlines()` 返回列表，每个元素是一行；`read()`、`readline()` 返回字符串。
3. **A**。`with` 语句在代码块结束时自动关闭文件，无需手写 `close()`；块外 `f` 已关闭。
4. **B**。`write()` 只接受字符串，必须先 `str()` 转换，否则抛 `TypeError`。
5. `encoding="utf-8"`；`f.close()`。编码参数决定字符与字节的转换规则，缺少时 Windows 默认 GBK。
6. **错误**。`"w"` 模式在打开瞬间就截断文件，原内容立即被清空，与是否写入无关。
7. 参考代码：

```python
count = 0
longest = 0
with open("demo.txt", "r", encoding="utf-8") as f:
    for line in f:
        count += 1
        longest = max(longest, len(line.rstrip("\n")))
print("行数：", count, "最长行长度：", longest)
```

逐行迭代避免一次性读入大文件，`rstrip("\n")` 保证长度不含换行符。

8. **AB**。C 错：`"w"` 模式在文件不存在时会新建文件，只有 `"r"` 模式才抛 `FileNotFoundError`；D 错：`writelines()` 只是按顺序写入，不会自动补换行符。
