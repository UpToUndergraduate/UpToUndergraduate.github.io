要让 Python 跑起来，必须先有"解释器"和"写代码的工具"，这两件事合起来就是开发环境。本节从解释器的下载安装讲起，对比几种主流的编程工具，再动手写出并运行第一个程序，最后集中排查初学者最常遇到的报错。安装和运行看似琐碎，却是考纲第 5 条明确要求"掌握"的内容，上机题的第一步往往就卡在这里。

## 一、Python 解释器与版本

### 1. 解释器是什么

Python 源代码本身只是文本，必须由**解释器**读取并执行。官方提供的解释器用 C 语言实现，称为 **CPython**，也是考试和大纲默认所指的 Python。除此之外还有用 Java 实现的 Jython、用 .NET 实现的 IronPython、以及追求运行速度的 PyPy，初学者和考试一律以 CPython 为准。

解释器内部的工作过程大致是：读取源码 → 检查语法并编译为字节码 → 由 Python 虚拟机逐条执行字节码 → 输出结果。正因为有"逐条执行"这一层，Python 才被归为解释型语言。

### 2. 下载与安装

官方下载地址是 `https://www.python.org`，进入 Downloads 页面选择对应操作系统的最新稳定版。安装时有两个关键点：

- **勾选 "Add Python to PATH"**：把 Python 安装目录写入系统环境变量 PATH，之后才能在命令行任意位置直接输入 `python` 调用。
- **选择安装位置**：默认装在用户目录下即可，路径尽量避免中文和空格，减少后续莫名其妙的报错。

安装向导里还有一个 "Install launcher for all users" 选项，它安装的是 `py` 启动器，可以在同一台电脑上并存多个 Python 版本，并用 `py -3.10` 这样的形式指定版本。对二级考试而言，装一个稳定的 3.x 版本就足够了，不必追求最新。

安装完成后打开命令行，输入下面的命令验证：

```
python --version
```

若显示 `Python 3.12.4` 一类的信息，说明解释器可用。若提示"不是内部或外部命令"，说明 PATH 没有配置好，可以重新运行安装程序选择 Modify 补勾 PATH，或手动把安装目录及其下的 `Scripts` 目录加入系统环境变量。注意 Windows 商店版可能把 `python` 指向应用商店占位程序，此时改用 `py --version` 或检查 PATH 配置。环境变量配置好后，通常需要重新打开命令行窗口才会生效，这一点常被忽略。

### 3. 版本选择

Python 3 与 Python 2 语法不兼容，Python 2 已于 2020 年停止维护，如今学习、考试和开发都使用 **Python 3**。本书代码统一按 Python 3.8 及以上版本编写，涉及海象运算符、类型注解等新特性时会单独说明。

## 二、常用开发工具

写 Python 代码既可以只用记事本，也可以用功能强大的集成开发环境（IDE）。下表对比几种常见工具，考试常以"下列哪个是 Python 的集成开发环境"的形式出现。

| 工具 | 类型 | 主要特点 | 适用场景 |
|------|------|----------|----------|
| IDLE | 官方自带轻量环境 | 安装即用，支持交互式与脚本编辑，按 F5 运行 | 入门学习、二级考试上机 |
| PyCharm | 专业 IDE | 代码补全、调试、版本控制齐全，占用资源较多 | 工程开发 |
| VS Code | 通用编辑器 + 插件 | 轻量、插件丰富，装 Python 扩展后即可调试 | 日常开发、多语言混用 |
| Jupyter Notebook | 交互式笔记本 | 代码、文字、图表混排，按单元格运行 | 数据分析、教学演示 |
| Anaconda | 发行版 | 自带 Python 与大量科学计算库，用 conda 管理环境 | 数据科学、机器学习 |

对二级考试而言，**IDLE** 是最需要熟悉的工具，因为它随官方安装包提供，界面简单，交互模式和脚本模式都支持。IDLE 的菜单栏中，File 菜单用于新建、打开和保存文件，Run 菜单中的 Run Module（或直接按 F5）用于运行当前脚本，Shell 窗口则显示运行结果和报错信息。初学阶段不必急着上重型 IDE，先用 IDLE 把语法练熟，等代码量大了再换 PyCharm 或 VS Code，学习曲线反而更平缓。

选择工具时应遵循"够用就好"的原则：只写几十行练习代码，IDLE 完全足够；需要断点调试和代码跳转时，再考虑专业 IDE；做数据分析则 Jupyter 更方便展示。工具只是载体，程序能否正确运行最终取决于代码本身。

## 三、第一个 Python 程序

### 1. 交互式模式

在命令行输入 `python` 进入交互式环境，会出现 `>>>` 提示符。此时输入一条语句，解释器立即执行并显示结果：

```
>>> print("Hello, Python!")
Hello, Python!
>>> 2 + 3 * 4
14
```

交互模式适合做小实验、验证某个表达式的结果，但关闭窗口后代码不会保存，因此不适合编写完整程序。

### 2. 脚本模式

把代码写进扩展名为 `.py` 的文件，再用解释器运行，这就是脚本模式，也是实际开发的主要方式。例如新建文件 `hello.py`，写入：

```python
# 第一个 Python 程序
print("Hello, Python!")
print("这是我的第一个程序")
```

在命令行进入文件所在目录，执行：

```
python hello.py
```

屏幕会依次输出两行文字。若在 IDLE 中打开该文件，按 **F5** 即可运行，效果相同。两种模式的差别可以归纳为下表：

| 对比项 | 交互式模式 | 脚本模式 |
|--------|------------|----------|
| 入口 | 命令行输入 python 或打开 IDLE Shell | 新建 `.py` 文件后运行 |
| 执行方式 | 输入一行立即执行一行 | 从头到尾按顺序执行整个文件 |
| 是否保存代码 | 不保存，关闭即丢失 | 以文件形式永久保存 |
| 适合场景 | 验证表达式、做小实验 | 编写完整程序、反复运行 |

两种模式共用同一个解释器，语法完全一致，区别只在于代码是否落盘、是否一次性执行。

### 3. 程序的基本组成

一个最小的 Python 程序通常包含注释、导入语句和可执行语句。下面这个稍完整的例子演示了输入、计算、输出三个环节：

**例 4.2-1** 编写程序：从键盘读入姓名和出生年份，输出"某某，你今年大约 N 岁"（按当前年份 2026 计算）。

**解**

1. 用 `input()` 读入姓名，得到的是字符串，直接保存。
2. 用 `input()` 读入出生年份，必须用 `int()` 转成整数，否则无法参与减法。
3. 用 2026 减去出生年份得到年龄，用 `print()` 输出。
4. 运行程序时依次输入 `张三`、`2005`（每输入一项按一次回车）。

```python
name = input("请输入姓名:")
year = int(input("请输入出生年份:"))
age = 2026 - year
print(name + ", 你今年大约", age, "岁")
```

若输入姓名为 `张三`、年份为 `2005`，输出为 `张三, 你今年大约 21 岁`。注意 `print()` 用逗号分隔多个参数时，输出会自动在各项之间插入一个空格。

**例 4.2-2** 下面这段程序有三处错误，请指出并改正，使其能正确输出矩形面积。

```text
length = input("长:")
width = input("宽:")
area = length * width
Print("面积:", area)
```

**解**

1. 第一处：`input()` 返回字符串，两个字符串相乘会报 `TypeError`，必须转成数值，改为 `float(input("长:"))`。
2. 第二处：`width` 同样要转成 `float`。
3. 第三处：`Print` 的首字母误写成大写，Python 区分大小写，应改为小写的 `print`，否则报 `NameError: name 'Print' is not defined`。
4. 改正后的完整代码：

```python
length = float(input("长:"))
width = float(input("宽:"))
area = length * width
print("面积:", area)
```

若输入 3 和 4，输出 `面积: 12.0`。

- **易错点**：①安装时忘记勾选 Add Python to PATH，导致命令行找不到 python；②把中文标点（，："）写进代码，报 SyntaxError 却看不出原因；③`input()` 忘了类型转换，直接参与算术运算报 TypeError；④脚本文件名取成 `random.py`、`turtle.py` 等，与标准库同名，导致导入时把自己当成了库。

## 四、pip 与开发环境配置

### 1. 用 pip 管理第三方库

`pip` 是 Python 自带的包管理工具，用来安装、升级和卸载第三方库。常用命令如下：

```
pip install requests        # 安装
pip install requests==2.31.0  # 安装指定版本
pip list                    # 查看已安装的库
pip uninstall requests      # 卸载
```

国内网络下载较慢时，可以指定镜像源加速，例如 `pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple`。若命令行提示 pip 不是内部或外部命令，通常是 `Scripts` 目录没有加入 PATH，找到 Python 安装目录下的 Scripts 文件夹补进环境变量即可。

安装完成后可以用 `import` 语句验证库是否可用：能正常导入且不报 `ModuleNotFoundError`，说明安装成功。卸载时不要把标准库一起删掉，只卸载自己安装的第三方库即可。

### 2. 虚拟环境

不同项目可能依赖同一个库的不同版本，直接装在全局环境里会互相冲突。**虚拟环境**为每个项目建立独立的库目录，互不干扰。创建与激活的命令是：

```
python -m venv myenv
myenv\Scripts\activate      # Windows
source myenv/bin/activate   # Linux 或 macOS
```

激活后命令提示符前会出现环境名，此时用 pip 安装的库只属于该环境。考试中一般只考概念，知道"虚拟环境用于隔离项目依赖"即可。

## 本节小结

1. Python 源代码由**解释器**执行，官方 C 语言实现称为 **CPython**，是考试默认口径。
2. 安装时务必勾选 **Add Python to PATH**，用 `python --version` 验证安装；学习和考试使用 **Python 3**。
3. 常用工具中，**IDLE** 是官方自带、考试最常使用的环境；PyCharm、VS Code、Jupyter、Anaconda 各有侧重。
4. Python 有**交互式**（`>>>` 即时执行、不保存）和**脚本式**（`.py` 文件、可反复运行）两种使用方式。
5. `pip` 用于安装管理第三方库，**虚拟环境**用于隔离不同项目的依赖。
6. 常见错误包括中文标点导致的 SyntaxError、忘记类型转换导致的 TypeError、缩进不一致导致的 IndentationError 等，读报错信息要看清**错误类型和行号**。

8.（多选）下列关于 Python 开发环境的说法，正确的有（　）。

### 参考答案

1. **C**。CPython 是官方用 C 实现的解释器；Jython 基于 Java，IronPython 基于 .NET，PyPy 追求执行速度。
2. **B**。PATH 是系统查找可执行文件的目录列表，加入后才能在任意路径下直接输入 `python` 调用。
3. **C**。IDLE 中按 F5 运行当前编辑窗口的脚本。
4. **A**。Python 源程序扩展名为 `.py`；`.pyc` 是编译后的字节码，`.pyd` 是 Windows 下的扩展模块。
5. **错**。交互式模式是"即输即执行"，代码保存在内存中，关闭窗口即丢失，需要保存必须写成 `.py` 脚本文件。
6. **pip**。
7. **字符串（str）**。
8. **ACD**。B 错：pip 的正是用来安装第三方库的工具，标准库随解释器一起安装，无需 pip；A、C、D 均正确。
