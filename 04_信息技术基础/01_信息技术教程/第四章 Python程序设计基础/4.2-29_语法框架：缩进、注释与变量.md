# 4.3 语法框架：缩进、注释与变量

> **考纲对应**：Python 程序设计基础 第 6 条——掌握 Python 程序设计语言的基本语法（层次：掌握）
> **教材对应**：Python 二级教程 · 第 3 章 基本数据类型

任何语言都有一套"规矩"：哪些字符能组成名字、代码块靠什么划分、注释怎么写、数据存在哪里。Python 的这套规矩特别鲜明——用缩进而不是花括号划分代码块，用 `#` 写注释，变量无需声明即可使用。这些规则看似细枝末节，却是读懂一切代码的前提，也是上机时最先踩坑的地方。本节把书写规则、注释、变量三块内容讲透，为后面的数据类型和控制结构铺路。

## 一、Python 程序的基本书写规则

### 1. 缩进决定代码块

在 C、Java 中，代码块由一对花括号 `{}` 界定；Python 则用**缩进**表示代码块，缩进相同的连续语句属于同一个块。这是 Python 最具辨识度的语法特征，也是初学者最容易出错的地方。

缩进规则有三条硬性要求：

- 通常用 **4 个空格** 作为一级缩进，这是 PEP 8 推荐的风格。
- **同一个代码块内缩进量必须完全一致**，多一个少一个空格都会被解释器视为不同层级。
- 不要混用 Tab 和空格。编辑器里看起来对齐，实际字符不同，会抛出 `TabError` 或 `IndentationError`。

缩进错误主要分三类，对照下表可以快速定位问题：

| 错误情形 | 典型报错信息 | 修改方法 |
|----------|--------------|----------|
| 该缩进却没缩进 | IndentationError: expected an indented block | 在冒号后的下一行补 4 个空格 |
| 不该缩进却缩进了 | IndentationError: unexpected indent | 删除行首多余空格 |
| 同块内缩进不一致 | IndentationError: unindent does not match any outer indentation level | 统一为 4 个空格的整数倍 |
| Tab 与空格混用 | TabError: inconsistent use of tabs and spaces | 全部改为空格 |

读懂这三种报错，调试效率会明显提高。建议在编辑器里打开"显示空白字符"，让 Tab 和空格无处遁形。

### 2. 语句、换行与续行

Python 默认**一条语句占一行**，行末不需要分号。若一行写多条语句，可以用英文分号隔开，如 `a = 1; b = 2`，但这种写法可读性差，不推荐，考试中也很少采用。

当一条语句太长需要折行时，有两种合法方式：

- 用圆括号、方括号或花括号把内容包起来，括号内的换行被视为语句的延续，无需任何符号。
- 用反斜杠 `\` 显式续行，注意反斜杠后不能有任何字符，包括空格。

```python
total = (1 + 2 + 3 +
         4 + 5 + 6)
text = "hello " \
       "world"
```

### 3. 大小写敏感与编码

Python **区分大小写**，`Name`、`name`、`NAME` 是三个不同的标识符，这一点与 C 语言一致，与 SQL 等不区分大小写的语言不同。写代码时一个大小写字母之差就可能引发 NameError，复制粘贴代码后尤其要检查。源文件默认采用 UTF-8 编码，Python 3 可以直接在字符串中写中文；若在旧环境中出现中文乱码，可在文件首行加编码声明 `# -*- coding: utf-8 -*-`。

## 二、注释

### 1. 单行注释

以 `#` 开头，从 `#` 到本行末尾的内容都会被解释器忽略。注释可以单独占一行，也可以放在语句右侧做行内说明：

```python
# 计算圆的面积
r = 3
area = 3.14159 * r * r   # 半径的平方乘以圆周率
```

### 2. 多行注释

Python 没有专门的多行注释语法，习惯上用**一对三引号**包裹一段文字来充当多行注释：

```python
"""
本程序用于演示多行注释
作者: 张三
版本: 1.0
"""
```

需要特别注意：三引号本质上定义的是**字符串**，只有不被赋值、单独出现在语句位置时，才被当作注释"忽略"。如果把它赋给变量或放在函数体第一句，它就是字符串或文档字符串（docstring），而不是注释。考试常在此设陷阱。

### 3. 注释的作用

注释不参与执行，却直接影响程序的可维护性。好的注释解释"为什么这么做"，而不是重复"这行做了什么"。调试时也常用注释临时屏蔽某段代码，快速定位问题所在。写注释要适度：关键算法、特殊处理、参数含义必须写清楚，一眼就能看懂的赋值语句则不必逐行注释，否则满屏废话反而干扰阅读。

## 三、变量与赋值

### 1. 变量是对象的引用

Python 中的变量不需要声明类型，第一次赋值时就地创建。更准确地说，**变量名只是贴在对象上的标签**，赋值语句 `a = 10` 的实际过程是：先在内存中创建整数对象 `10`，再让名字 `a` 指向它。

可以用两个内置函数观察这个过程：`type(x)` 返回对象的数据类型，`id(x)` 返回对象的内存地址标识。对同一个变量重新赋不同类型的值，`type()` 的结果会随之改变，这正是"**动态类型**"的含义：

```python
a = 10
print(type(a), id(a))
a = "hello"
print(type(a), id(a))
```

### 2. 赋值的形式

Python 的赋值非常灵活，常见形式有以下几种：

| 形式 | 写法示例 | 说明 |
|------|----------|------|
| 基本赋值 | `x = 5` | 名字指向对象 |
| 链式赋值 | `a = b = c = 0` | 三个名字指向同一个对象 |
| 平行赋值 | `a, b = 1, 2` | 按位置一一对应 |
| 交换变量 | `a, b = b, a` | 右侧先求值成元组再解包，无需临时变量 |
| 增量赋值 | `a += 1` | 等价于 `a = a + 1` |

平行赋值要求两侧数量一致，否则报 `ValueError: too many values to unpack` 一类的错误。交换变量时 `a, b = b, a` 能一步完成，是因为等号右边先被打包成一个元组，再依次解包给左边，这是 Python 的经典写法。

### 3. 变量名与关键字

变量名、函数名等统称**标识符**，命名必须遵守以下规则：

- 只能由字母、数字、下划线和中文组成，**不能以数字开头**。
- 区分大小写，不能包含空格和标点符号。
- 不能使用 Python 的**关键字**（如 `if`、`for`、`class`）和内置函数名（如 `print`、`list`）作为变量名。

Python 3 的关键字共 35 个，考试常考其中几个易混的：

| 类别 | 关键字 |
|------|--------|
| 逻辑值 | True、False、None |
| 逻辑运算 | and、or、not、is、in |
| 分支循环 | if、elif、else、for、while、break、continue |
| 函数类 | def、return、lambda、yield、global、nonlocal |
| 异常 | try、except、finally、raise、assert |
| 其他 | import、from、as、class、with、del、pass、async、await |

命名风格上，PEP 8 建议变量和函数用小写字母加下划线（如 `student_name`），类名用大驼峰（如 `StudentInfo`），常量用全大写（如 `MAX_SIZE`）。这些不是语法强制，但写上规范的名字能让代码一眼看懂。

需要提醒的是，虽然 Python 3 允许用中文作变量名（如 `年龄 = 18`），但实际开发和考试中应避免这样做：中文输入需要切换输入法，容易误输入全角字符，也会降低代码在不同环境下的兼容性。同样，不要用 `list`、`dict`、`sum`、`max` 这些内置函数名作变量名，一旦覆盖，原来的函数就再也调不到了，排查起来非常隐蔽。

### 4. 常量与 None

Python 没有真正意义上的常量语法，通常用**全大写变量名**表示"约定俗成不修改"的常量，如 `PI = 3.14159`、`MAX_COUNT = 100`。这只是程序员之间的约定，解释器并不会阻止你修改它。

`None` 是 Python 中一个特殊的值，表示"空"或"没有值"，类型为 `NoneType`。函数没有返回值时默认返回 `None`，变量也可以先赋值为 `None` 占位，等后续再赋真实数据。注意 `None` 的首字母必须大写，写成 `none` 会被当作普通变量名而报 `NameError`。

**例 4.3-1** 读入身高（米）和体重（千克），计算身体质量指数 BMI，公式为 BMI = 体重 ÷ 身高²，输出保留两位小数，并说明变量命名与注释的作用。

**解**

1. 用 `float()` 读入身高和体重，变量命名为 `height`、`weight`，见名知意。
2. 先算身高平方 `height ** 2`，再算 BMI，避免表达式过长出错。
3. 用 `round()` 保留两位小数输出，并加注释说明公式来源。

```python
# 计算 BMI: 体重(kg) / 身高(m) 的平方
height = float(input("身高(m):"))
weight = float(input("体重(kg):"))
bmi = weight / (height ** 2)
print("BMI =", round(bmi, 2))
```

若输入身高 1.75、体重 70，输出 `BMI = 22.86`。变量名用英文单词而非 `a`、`b`，看代码就能知道含义，这就是命名规范的价值。

**例 4.3-2** 下列代码存在三处语法层面的问题，请指出并改正。

```text
1name = "Python"
if 1name == "Python":
print("正确")
```

**解**

1. 第一处：变量名 `1name` 以数字开头，违反标识符规则，会报 `SyntaxError`，应改为 `name` 或 `lang`。
2. 第二处：`if` 后面的语句块必须缩进，`print` 前应缩进 4 个空格，否则报 `IndentationError: expected an indented block`。
3. 第三处：`if` 语句末尾缺少英文冒号 `:`，这是 Python 复合语句的固定格式。
4. 改正后：

```python
lang = "Python"
if lang == "Python":
    print("正确")
```

运行输出 `正确`。注意条件中的 `==` 是比较运算符，与赋值的 `=` 不同，这也是常见混淆点。

- **易错点**：①同一代码块混用 Tab 和空格，肉眼对齐却报 TabError；②`if`、`for`、`def` 等复合语句末尾漏写冒号；③把三引号字符串误认为"注释"，赋值给变量后仍以为不参与执行；④用关键字（如 `class`、`True`）或内置函数名（如 `print`）作变量名，导致后续调用失败。

## 本节小结

1. Python 用**缩进**划分代码块，通常一级缩进 4 个空格，同一块内缩进必须一致，不能混用 Tab 与空格。
2. 一条语句占一行，行末不加分号；长语句可用括号或反斜杠续行；Python **区分大小写**。
3. 注释用 `#` 写单行，用一对三引号写多行；三引号本质是字符串，只有不参与运算时才起注释作用。
4. 变量是**对象的引用**，赋值即创建，无需声明类型，类型由所指对象决定，体现**动态类型**特征。
5. 赋值形式包括基本赋值、链式赋值、平行赋值、交换赋值和增量赋值，`a, b = b, a` 可一步交换。
6. 标识符只能由字母、数字、下划线组成且不以数字开头，不能使用关键字和内置函数名；PEP 8 建议变量用小写下划线风格。
