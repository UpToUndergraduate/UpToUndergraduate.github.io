# 4.9 组合数据类型

> **考纲对应**：Python 程序设计基础 第 6 条——掌握列表、元组、字典、集合等组合数据类型的创建、访问与常用操作（层次：掌握）
> **教材对应**：Python 二级教程 · 第 6 章 组合数据类型

单个变量只能保存一个值，而现实中的数据处理对象往往是"一批"数据：一个班级的成绩、一本书的词频、一张表的字段。Python 用列表、元组、字典和集合四类组合数据类型来组织这些数据，它们都是**容器**，但在可变性、有序性和元素唯一性上各不相同。本节按"序列（列表、元组）—映射（字典）—集合"的顺序展开，重点掌握索引切片、常用方法与遍历方式。考试中这一部分多以"给出代码判断输出"和"辨析方法返回值"两种形式命题，务必动手验证。

## 一、列表与元组

### 1. 列表的创建与索引

列表用方括号 `[]` 定义，元素之间用逗号分隔，元素类型可以不同，长度可变：

```python
scores = [85, 92, 78, 60]
mixed = [1, "Python", 3.14, True]
empty = []
```

列表是**有序序列**，用下标访问，下标从 0 开始，负数表示从末尾倒数（`-1` 为最后一个元素）。下标越界会抛出 `IndexError`。用 `len()` 取长度，用 `in` 判断元素是否存在。

列表的元素本身也可以是列表，形成**嵌套列表**，常用来表示二维表格：

```python
matrix = [[1, 2, 3], [4, 5, 6]]
print(matrix[0][2])      # 3，第 1 行第 3 列
print(len(matrix))       # 2，行数
```

访问嵌套列表需要连续两次下标：第一个下标定位子列表，第二个下标定位元素。要注意 `[[0] * 3] * 2` 这种写法创建的是"两个指向同一子列表的引用"，修改一行会影响另一行，正确写法是 `[[0] * 3 for _ in range(2)]`。

### 2. 切片与常用方法

切片语法为 `列表[起点:终点:步长]`，取"左闭右开"区间，三个部分都可省略：

```python
a = [10, 20, 30, 40, 50, 60]
print(a[1:4])      # [20, 30, 40]
print(a[:3])       # [10, 20, 30]
print(a[::2])      # [10, 30, 50]
print(a[::-1])     # [60, 50, 40, 30, 20, 10]
```

常用方法及其是否改变原列表，是选择题的高频考点：

| 方法 | 作用 | 是否原地修改 | 返回值 |
|---|---|---|---|
| `append(x)` | 末尾追加一个元素 | 是 | `None` |
| `extend(seq)` | 末尾追加多个元素 | 是 | `None` |
| `insert(i, x)` | 在下标 i 处插入 | 是 | `None` |
| `pop(i)` | 删除并返回下标 i 的元素 | 是 | 被删元素 |
| `remove(x)` | 删除第一个值为 x 的元素 | 是 | `None` |
| `sort()` | 升序排序 | 是 | `None` |
| `reverse()` | 逆序 | 是 | `None` |
| `index(x)` / `count(x)` | 查找下标 / 计数 | 否 | 整数 |

注意：`sort()`、`append()` 等原地方法返回 `None`，写成 `a = a.sort()` 会让 `a` 变成 `None`，这是最典型的失分点。若不想改动原列表，用内置函数 `sorted(a)`，它返回新列表。

### 3. 列表推导式

列表推导式用一个表达式从可迭代对象生成列表，形式为 `[表达式 for 变量 in 可迭代对象 if 条件]`：

```python
nums = [1, 2, 3, 4, 5, 6]
squares = [x * x for x in nums]
evens = [x for x in nums if x % 2 == 0]
print(squares)   # [1, 4, 9, 16, 25, 36]
print(evens)     # [2, 4, 6]
```

它等价于"建空表 + 循环 + `append`"，但更简洁，执行效率也略高。推导式还可以嵌套条件表达式，如 `["偶" if x % 2 == 0 else "奇" for x in range(4)]`，但层数不宜过多，否则可读性急剧下降。

排序时若规则不是"自然大小"，可用 `key` 参数指定排序依据。例如按字符串长度排序写成 `sorted(words, key=len)`，按绝对值排序写成 `sorted(nums, key=abs)`，降序再加 `reverse=True`。`key` 接收的是一个函数，对每个元素调用一次，用其返回值参与比较，这比手写比较函数更简洁。

### 4. 元组：不可变序列

元组用圆括号定义，一旦创建就不能增删改元素，因此可以作为字典的键、集合的元素。单元素元组必须写成 `(5,)`，只写 `(5)` 会被当作整数。

```python
point = (3, 5)
x, y = point            # 解包
print(x + y)            # 8
print(point[0])         # 3
```

元组适合表示"一条不可更改的记录"，如坐标、日期、函数返回的多值。元组与列表可以互转：`list(t)` 把元组转成列表，`tuple(lst)` 把列表转成元组，转换后得到的是新对象，修改互不影响。由于元组不可变，它没有 `append`、`sort` 等方法，也不能对元素赋值，`t[0] = 9` 会直接报 `TypeError`。列表与元组的对比：

| 比较项 | 列表 list | 元组 tuple |
|---|---|---|
| 定界符 | `[]` | `()` |
| 可变性 | 可变，可增删改 | 不可变 |
| 能否作字典键 | 不能 | 能（元素均不可变时） |
| 方法数量 | 多（增删改查排序） | 少（`count`、`index`） |
| 典型用途 | 动态数据集 | 固定记录、多返回值 |

**例 4.9-1**

给定成绩列表，去掉一个最高分和一个最低分后求平均分（去掉一个最高分、一个最低分），输出结果保留两位小数。

**解**

1. 先把列表复制一份，避免修改原始数据。
2. 用 `remove()` 分别删除一个最高分和一个最低分。
3. 用 `sum()/len()` 求平均并格式化输出。

```python
scores = [88, 95, 76, 92, 81, 95]
data = scores[:]                 # 切片复制，等价于 scores.copy()
data.remove(max(data))
data.remove(min(data))
average = sum(data) / len(data)
print("原始成绩：", scores)
print("去掉最高最低后：", data)
print("平均分：%.2f" % average)
```

运行结果：

```
原始成绩： [88, 95, 76, 92, 81, 95]
去掉最高最低后： [88, 92, 81, 95]
平均分： 89.00
```

**分析**：`data.remove(max(data))` 只删除第一个最大值，若存在并列最高分，另一个仍保留，符合"去掉一个"的题意。若直接写 `data = scores`，两个名字指向同一个列表，`remove` 会改动原数据，这是引用赋值与复制的本质区别。

- **易错点**：① `a = b` 只是让两个名字指向同一对象，复制要用 `b[:]`、`b.copy()` 或 `list(b)`；② `remove` 按值删除、`pop` 按下标删除，二者不可混用；③ 遍历列表时删除元素会导致下标错位，应改为遍历副本 `for x in a[:]`。

## 二、字典

### 1. 创建与访问

字典用花括号定义，元素是"键:值"对，键必须唯一且不可变（字符串、数字、元组），值可以是任意对象。字典是**无序**的（3.7 起按插入顺序遍历，但不应依赖顺序做题）。

```python
student = {"name": "张三", "age": 19, "score": 88}
print(student["name"])            # 张三
print(student.get("city"))        # None，键不存在不报错
print(student.get("city", "未知"))  # 未知
```

用 `[]` 访问不存在的键会抛出 `KeyError`，用 `get()` 则返回 `None` 或指定默认值，这是编写健壮代码的常用手法。

### 2. 增、删、改、查与遍历

```python
student["city"] = "南京"      # 键不存在则新增，存在则修改
student["score"] = 92         # 修改
del student["age"]            # 删除指定键
print(student)

for key in student:                     # 遍历键
    print(key, student[key])
for key, value in student.items():      # 遍历键值对
    print(key, "=", value)
```

`keys()`、`values()`、`items()` 分别返回键、值、键值对的视图，常与 `list()` 配合转成列表。`in` 运算符判断的是**键**是否存在，而不是值。

### 3. 字典的典型应用：计数与映射

字典最典型的用途是"按关键字累计"，例如统计词频、按班级汇总成绩。思路是：以数据项为键，先判断键是否存在，不存在则置 0，存在则加 1；也可以用 `get(key, 0) + 1` 一行完成。

**例 4.9-2**

统计字符串 `"to be or not to be that is the question"` 中每个单词出现的次数，并按次数从高到低输出前三个。

**解**

1. 用 `split()` 按空白切分为单词列表。
2. 遍历列表，用字典累计次数。
3. 用 `sorted()` 对 `items()` 按值降序排序，取前三个。

```python
text = "to be or not to be that is the question"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1

result = sorted(counts.items(), key=lambda item: item[1], reverse=True)
for word, n in result[:3]:
    print(word, n)
```

运行结果：

```
to 2
be 2
or 1
```

**分析**：`counts.get(word, 0)` 在键不存在时返回 0，省去了 `if word not in counts` 的判断。`sorted` 的 `key` 参数指定按元组的第 2 项（次数）排序，`reverse=True` 表示降序。`lambda item: item[1]` 是匿名函数，等价于"取元组的第二个元素"。

- **易错点**：① 字典的键不能是列表，因为列表可变、不可哈希；② `sorted(d)` 只排键，要排键值对须用 `sorted(d.items())`；③ 遍历字典的同时增删键会抛出 `RuntimeError: dictionary changed size during iteration`。

### 4. 字典的合并与推导式

字典的值也可以是字典，从而表示"多条结构相同的记录"，例如 `students = {"001": {"name": "张三", "score": 88}}`，访问时写 `students["001"]["score"]`。合并两个字典可用 `d1.update(d2)`（原地修改）或 `{**d1, **d2}`（生成新字典）；若键重复，后者用右值覆盖左值。

与列表推导式类似，字典也有推导式，语法为 `{键表达式: 值表达式 for 变量 in 可迭代对象}`：

```python
words = ["apple", "banana", "cherry"]
length = {w: len(w) for w in words}
print(length)     # {'apple': 5, 'banana': 6, 'cherry': 6}
```

必须用花括号加冒号，若只写 `{w for w in words}` 得到的是集合而不是字典，这是常见混淆点。

## 三、集合

### 1. 创建与特性

集合用花括号 `{}` 定义，元素唯一且无序，因此**不能下标访问**。空集合必须写成 `set()`，`{}` 是空字典。集合的底层是哈希表，查找元素时按哈希值定位，数据量越大，`in` 判断相对列表的优势越明显，因此在"查重""判重"的场景中应优先考虑集合。

```python
s = {1, 2, 2, 3, 3, 3}
print(s)              # {1, 2, 3}，自动去重
print(len(s))         # 3
```

### 2. 集合运算

| 运算 | 运算符 | 方法 | 含义 |
|---|---|---|---|
| 交集 | `A & B` | `A.intersection(B)` | 同时属于 A 和 B |
| 并集 | `A \| B` | `A.union(B)` | 属于 A 或 B |
| 差集 | `A - B` | `A.difference(B)` | 属于 A 但不属于 B |
| 对称差 | `A ^ B` | `A.symmetric_difference(B)` | 只属于其中一个 |

集合最常见的实战用途是**去重**和**成员判断**（`in` 的平均时间复杂度为 O(1)，远快于列表）。注意 `s.add(x)` 添加单个元素，`s.update(seq)` 添加多个元素。

集合也有推导式，写法与列表推导式只差外层括号，如 `{x % 5 for x in range(12)}` 得到 `{0, 1, 2, 3, 4}`。由于结果自动去重且无序，集合推导式适合"筛选并去重"的场景，不适合需要保留下标的场景。

**例 4.9-3**

有两门选修课的学生名单，求两门都选的学生、只选了一门的学生人数。

**解**

1. 把两个名单转为集合，自动去重。
2. 交集得到"都选"，对称差得到"只选一门"。
3. 输出排序后的结果，便于阅读。

```python
python_class = {"张三", "李四", "王五", "赵六"}
web_class = {"王五", "赵六", "孙七"}

both = python_class & web_class
only_one = python_class ^ web_class
print("两门都选：", sorted(both))
print("只选一门的人数：", len(only_one))
```

运行结果：

```
两门都选： ['王五', '赵六']
只选一门的人数： 3
```

- **易错点**：① 集合元素必须可哈希，不能放列表和字典；② `{}` 创建的是字典不是集合；③ 集合无序，不能写 `s[0]`，需要下标时先 `sorted(s)` 转列表。

## 本节小结

1. 列表有序可变、元组有序不可变、字典是键值映射、集合无序且元素唯一，四者用途不同。
2. 序列下标从 0 开始，支持负数下标与"左闭右开"的切片；切片始终返回新对象。
3. `append`、`sort`、`remove` 等原地方法返回 `None`，不要用赋值接收；需要新列表时用 `sorted()`、`a[:]`。
4. 字典用 `get(key, 默认值)` 安全访问，用 `items()` 遍历键值对，键必须是不可变对象。
5. 集合擅长去重、交并差运算和快速成员判断，空集合写作 `set()`。
6. 列表推导式 `[表达式 for x in 序列 if 条件]` 是构造列表的简洁写法，等价于循环加 `append`。

8.（多选）关于组合数据类型，下列说法正确的是（　）。
A. 元组可以作为字典的键
B. 列表推导式可以带 `if` 过滤条件
C. 集合可以用下标访问其中的元素
D. 对列表执行 `a = a.append(1)` 后，`a` 仍然是一个列表

### 参考答案

1. **B**。`sort()` 是原地排序，返回值为 `None`，因此 `b` 为 `None`；与此同时 `a` 已被排成 `[1, 2, 3]`。要保留原列表并得到排序结果，应写 `b = sorted(a)`。
2. **A**。切片左闭右开，取下标 1、2、3 三个元素。
3. **C**。键必须不可变，故 A 错；字典不按值排序，B 错；`[]` 访问不存在的键抛 `KeyError`，D 错。
4. **B**。集合自动去重，重复的 2 只保留一个，共 3 个元素。
5. `{2, 3}`；`{1, 2, 3, 4}`。`&` 求交集，`|` 求并集。
6. **正确**。切片遵循同一规则，返回与源对象同类型的序列。
7. 参考代码：

```python
nums = [5, 3, 8, 3, 9, 5, 1]
result = []
for x in nums:
    if x not in result:
        result.append(x)
print(result)
```

输出 `[5, 3, 8, 9, 1]`。若只需去重而不管顺序，可用 `list(set(nums))`，但集合无序，结果顺序不确定。

8. **AB**。C 错：集合无序，不支持下标访问，需先转为有序序列；D 错：`append` 返回 `None`，赋值后 `a` 变为 `None`，不再是列表。
