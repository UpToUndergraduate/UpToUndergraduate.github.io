# 4.12 模块与标准库

> **考纲对应**：Python 程序设计基础 第 6 条——掌握模块的导入与使用，了解 Python 标准库与第三方库的生态（层次：掌握导入方法，了解常用库）
> **教材对应**：Python 二级教程 · 第 8 章 Python 计算生态

Python 之所以"开箱即用"，靠的是庞大的模块生态：求平方根不必自己写牛顿迭代，生成随机数不必自己设计算法，处理中文分词也不必从零训练模型，导入相应模块即可调用。模块把一组相关的函数、类和变量组织在一个文件里，既避免了命名冲突，也让程序可以按需加载。本节讲解模块的四种导入方式、常用标准库的典型函数、第三方库的安装与生态概貌，最后给出一个自定义模块的完整示例。

## 一、模块的概念与导入

### 1. 模块、包与库

**模块（module）**是一个以 `.py` 结尾的源文件，文件名即模块名；**包（package）**是含 `__init__.py` 的目录，用于组织多个模块；**库（library）**是若干模块或包的集合，是对外提供功能的整体。按来源分为三类：

- **内置模块**：随解释器发布，无需安装，如 `sys`、`math`、`random`、`time`。
- **第三方库**：需用 `pip` 安装，如 `jieba`、`numpy`、`requests`。
- **自定义模块**：用户自己编写的 `.py` 文件。

### 2. 四种导入方式

| 写法 | 调用方式 | 特点 |
|---|---|---|
| `import math` | `math.sqrt(9)` | 最清晰，需写模块名前缀 |
| `import numpy as np` | `np.array([1,2])` | 起别名，简化长模块名 |
| `from math import sqrt` | `sqrt(9)` | 只导入指定成员，无需前缀 |
| `from math import *` | `sqrt(9)` | 导入全部公开成员，易污染命名空间 |

推荐优先使用前两种：带模块名前缀虽然多敲几个字符，但能一眼看出函数来自哪里，避免与自定义函数重名。`from ... import *` 在考试题中常见，但在工程代码中应避免。

```python
import math
from random import randint as ri

print(math.sqrt(16))     # 4.0
print(ri(1, 6))          # 1~6 之间的随机整数
```

### 3. 模块的搜索路径与 `__main__`

导入模块时，Python 依次在"当前目录 → 环境变量 PYTHONPATH → 标准库目录 → 第三方库目录"中查找，找不到就抛 `ModuleNotFoundError`。`sys.path` 是保存这些路径的列表，可临时追加。

每个模块都有内置变量 `__name__`：当文件被直接运行时，其值为 `"__main__"`；当被其他文件导入时，其值为模块名。因此常用下面的结构区分"独立运行"与"被导入"，这也是编写可复用脚本的基本范式：

```python
def average(nums):
    return sum(nums) / len(nums)

if __name__ == "__main__":
    print("自测：", average([1, 2, 3]))
```

被导入时，这段自测代码不会执行，避免产生副作用。

这个写法的实际意义在于：一个既能独立运行、又能被复用的模块，往往自带演示代码或测试代码。若不加以隔离，别人 `import` 你的模块时，屏幕上会莫名其妙地打印出测试信息。考试中若出现"某模块被导入后没有任何输出"的选项，通常就是因为这段代码被 `__main__` 判断挡住了。

- **易错点**：① `import math` 后直接写 `sqrt(4)` 会报 `NameError`，必须加 `math.` 前缀；② `from math import *` 会覆盖同名变量，且不易排查；③ 自定义模块名不要与标准库同名（如 `random.py`），否则导入的是自己写的文件，引发诡异错误。

## 二、常用标准库

### 1. math：数学函数

| 函数 | 功能 | 示例结果 |
|---|---|---|
| `sqrt(x)` | 平方根 | `sqrt(16)` → 4.0 |
| `pow(x, y)` | 幂运算（返回浮点） | `pow(2, 10)` → 1024.0 |
| `ceil(x)` / `floor(x)` | 向上 / 向下取整 | `ceil(1.2)` → 2 |
| `fabs(x)` | 绝对值（浮点） | `fabs(-3)` → 3.0 |
| `gcd(a, b)` | 最大公约数 | `gcd(12, 18)` → 6 |
| `factorial(n)` | 阶乘 | `factorial(5)` → 120 |

此外还有常量 `math.pi`、`math.e`，以及 `sin`、`cos`、`log`、`log10` 等函数。注意 `math` 中的三角函数以**弧度**为单位，传入角度需先转换。

### 2. random：随机数

| 函数 | 功能 |
|---|---|
| `random()` | 生成 `[0.0, 1.0)` 之间的浮点数 |
| `randint(a, b)` | 生成 `[a, b]` 之间的整数，含两端 |
| `randrange(a, b, step)` | 在 `range(a, b, step)` 中随机取一个 |
| `uniform(a, b)` | 生成 `[a, b]` 之间的浮点数 |
| `choice(seq)` | 从序列中随机取一个元素 |
| `shuffle(lst)` | 原地打乱列表，返回 `None` |
| `seed(n)` | 设置随机种子，使结果可复现 |

`randint` 包含右端点，`randrange` 不包含，这是最易混淆的一对。`shuffle` 原地修改、无返回值，写成 `lst = random.shuffle(lst)` 会让列表变成 `None`。

`seed()` 用于固定随机序列：设置相同的种子后，每次运行得到相同的"随机"结果，便于复现实验与排查错误。例如 `random.seed(2025)` 之后的 `randint(1, 100)` 每次都一样。考试若要求"输出可复现"，必须在第一次取随机数之前调用 `seed()`；若题目说"每次运行结果不同"，则说明没有设种子。

### 3. time 与 datetime

`time.time()` 返回从 1970 年 1 月 1 日至今的秒数（时间戳），常用于计时；`time.sleep(n)` 让程序暂停 n 秒。`datetime` 模块的 `datetime.now()` 返回当前日期时间对象，可用 `strftime("%Y-%m-%d")` 格式化输出，`strptime` 则把字符串解析为日期对象。

```python
import time
from datetime import datetime

start = time.time()
time.sleep(0.5)
print("耗时：%.2f 秒" % (time.time() - start))
print(datetime.now().strftime("%Y-%m-%d %H:%M"))
```

计时是性能分析的常用手段：在代码段前后各取一次时间戳，相减即得耗时。`strftime` 中的格式符区分大小写，`%Y` 是四位年份、`%m` 是两位月份、`%H` 是 24 小时制小时，写错大小写会得到意外结果。

### 4. os 与 sys

`os` 面向操作系统：`os.getcwd()` 取当前工作目录，`os.listdir(p)` 列出目录内容，`os.path.exists(p)` 判断路径是否存在，`os.path.join(a, b)` 拼接路径（自动适配分隔符）。`sys` 面向解释器：`sys.argv` 是命令行参数列表，`sys.path` 是模块搜索路径，`sys.exit()` 退出程序。写跨平台脚本时，路径拼接一律用 `os.path.join`，不要手写斜杠。

两个模块的分工可以这样记：`os` 管"文件和目录"，`sys` 管"解释器和运行环境"。相对路径是相对"当前工作目录"而非脚本所在目录解析的，这也是双击运行脚本时常常找不到文件的根本原因，必要时可用 `os.chdir()` 切换，或把路径改为基于 `__file__` 计算。

**例 4.12-1**

用 `random` 生成一个由数字和小写字母组成的 6 位验证码。

**解**

1. 把所有候选字符拼成一个字符串。
2. 用 `random.choice` 每次取一个字符。
3. 用生成器表达式配合 `join` 拼接 6 次的结果。

```python
import random

chars = "0123456789abcdefghijklmnopqrstuvwxyz"
code = "".join(random.choice(chars) for _ in range(6))
print("验证码：", code)
```

示例输出（每次运行不同）：

```
验证码： k7p2x9
```

**分析**：下划线 `_` 表示"循环变量用不到"，是惯用写法。若要保证六位中至少含一个数字，可先生成一位数字，再从全部字符中取五位，最后打乱顺序——这类"约束随机"在考试中常作为提高题出现。

**例 4.12-2**

计算半径为 2 的圆面积（保留两位小数），并输出 16 的平方根、5 的阶乘、12 与 18 的最大公约数。

**解**

1. 导入 `math`，用 `math.pi` 取圆周率。
2. 面积公式为 πr²，用 `round()` 保留两位小数。
3. 依次调用 `sqrt`、`factorial`、`gcd`。

```python
import math

r = 2.0
area = math.pi * r ** 2
print("圆面积：", round(area, 2))
print("平方根：", math.sqrt(16))
print("阶乘：", math.factorial(5))
print("最大公约数：", math.gcd(12, 18))
```

运行结果：

```
圆面积： 12.57
平方根： 4.0
阶乘： 120
最大公约数： 6
```

- **易错点**：① `round(2.675, 2)` 可能得到 `2.67`，这是二进制浮点表示所致，需要精确小数时用 `decimal` 模块；② `random.shuffle` 返回 `None`，不要赋值接收；③ `time.sleep(1)` 的参数单位是秒，写 1000 会真的等待一千秒。

## 三、第三方库与计算生态

### 1. 安装与导入

第三方库用包管理工具 `pip` 安装，在命令行执行 `pip install 库名`，国内网络可加镜像源参数加速。安装完成后，导入方式与标准库完全相同。若在集成开发环境中提示"模块不存在"，多半是装到了另一个解释器环境，应检查解释器路径。

安装命令还有几个常用变体：`pip install 库名==版本号` 指定版本，`pip uninstall 库名` 卸载，`pip list` 查看已安装列表，`pip install -i 镜像地址 库名` 临时换源。命令要在命令行（终端）中执行，而不是在 Python 交互环境里输入，这是初学者最常见的操作错误。

### 2. 二级考试涉及的常用库

| 库名 | 用途 | 典型调用 |
|---|---|---|
| `jieba` | 中文分词 | `jieba.lcut("我爱Python")` |
| `wordcloud` | 词云生成 | `WordCloud().generate(text)` |
| `numpy` | 数值计算、数组 | `np.array([1, 2, 3])` |
| `pandas` | 表格数据分析 | `pd.read_csv("a.csv")` |
| `matplotlib` | 数据可视化 | `plt.plot(x, y)` |
| `requests` | 网络请求 | `requests.get(url)` |
| `PyInstaller` | 打包成可执行文件 | `pyinstaller -F a.py` |

考试对这些库的要求以"知道它属于哪一类、能做什么"为主，具体 API 只需记住最典型的一两个。需要特别注意：`jieba`、`wordcloud`、`numpy` 都是第三方库，不在标准库之列；`turtle`、`random`、`math`、`time`、`os`、`csv`、`json` 则属于标准库，无需安装。

选择库时可以按任务类型对号入座：要分词找 `jieba`，要词云找 `wordcloud`，要数组运算与矩阵计算找 `numpy`，要表格清洗与统计分析找 `pandas`，要画图找 `matplotlib`，要抓取网页找 `requests`，要打包成 exe 用 `PyInstaller`。这套分工构成了二级考试所说的"Python 计算生态"，它的价值不在于某个库多强大，而在于各层库可以组合使用，把复杂任务拆成几行调用。

**例 4.12-3**

编写自定义模块 `mytool.py`，提供求平均值的函数，并在另一个文件中导入使用。

**解**

1. 新建 `mytool.py`，定义 `average(nums)`。
2. 用 `if __name__ == "__main__":` 包裹自测代码。
3. 新建 `main.py`，与之放在同一目录，导入并调用。

```python
# mytool.py
def average(nums):
    if not nums:
        return 0
    return sum(nums) / len(nums)

if __name__ == "__main__":
    print("模块自测：", average([1, 2, 3]))
```

```python
# main.py，需与 mytool.py 位于同一目录
import mytool

print("平均分：", mytool.average([80, 90, 100]))
```

运行 `python main.py` 输出：

```
平均分： 90.0
```

**分析**：运行 `main.py` 时，`mytool` 被导入，其 `__name__` 为 `"mytool"`，自测语句不执行，因此只看到一行输出；若直接运行 `python mytool.py`，则 `__name__` 为 `"__main__"`，输出"模块自测： 2.0"。

- **易错点**：① 模块文件名不能与要导入的库同名；② 跨目录导入需要包结构或修改 `sys.path`，不是把文件复制到任意位置就行；③ 修改了自定义模块后要重启解释器，已导入的模块不会自动重新加载。

## 本节小结

1. 模块是 `.py` 文件，包是含 `__init__.py` 的目录，库是模块与包的集合。
2. 四种导入方式中，`import x` 与 `import x as y` 需要前缀，`from x import y` 不需要，`import *` 应少用。
3. 模块导入失败时依次检查：名称拼写、当前目录、是否安装、解释器环境。
4. `__name__ == "__main__"` 用于区分直接运行与被导入，避免自测代码产生副作用。
5. 标准库重点掌握 `math`、`random`、`time`、`os`；`randint` 含右端点，`shuffle` 原地打乱且返回 `None`。
6. `jieba`、`numpy`、`pandas`、`matplotlib`、`requests` 属于第三方库，需用 `pip` 安装。

## 自测题

1.（单选）执行 `import math` 后，求 9 的平方根的正确写法是（　）。
A. `sqrt(9)`　B. `math.sqrt(9)`　C. `math->sqrt(9)`　D. `math(sqrt, 9)`

2.（单选）下列库中，不属于 Python 标准库的是（　）。
A. `random`　B. `math`　C. `jieba`　D. `csv`

3.（单选）`random.randint(1, 10)` 可能返回的值是（　）。
A. 0　B. 10　C. 10.5　D. 11

4.（单选）执行 `import numpy as np` 后，`np` 是（　）。
A. 一个函数　B. `numpy` 模块的别名　C. 一个变量　D. 一个新的模块文件

5.（填空）安装第三方库 `requests` 的命令是________；查看模块 `math` 中有哪些成员可用________函数。

6.（判断）执行 `from math import *` 后，可以直接写 `sqrt(16)` 而无需模块名前缀。（　）

7.（编程）模拟掷一枚骰子 100 次，统计 1 到 6 点各出现多少次，并输出结果。

8.（多选）关于模块与库，下列说法正确的是（　）。
A. 标准库随解释器一起安装，无需 `pip` 安装
B. `from math import sqrt` 之后可以直接调用 `sqrt(16)`
C. `pip` 只能安装标准库，不能安装第三方库
D. `import matplotlib.pyplot as plt` 给模块起了别名 `plt`

### 参考答案

1. **B**。`import math` 只导入模块名，调用成员必须带 `math.` 前缀。
2. **C**。`jieba` 是第三方中文分词库，需单独安装；其余三个都是标准库。
3. **B**。`randint(a, b)` 生成 `[a, b]` 的整数并包含两端，故 1 和 10 都可能出现，但不会出现 0 或 11，也不会返回小数。
4. **B**。`as` 为模块指定别名，`np` 指向同一个模块对象，用于简化书写。
5. `pip install requests`；`dir()`（也可用 `help(math)` 查看文档）。`dir()` 返回模块成员名称列表。
6. **正确**。`import *` 把模块的公开成员直接导入当前命名空间，因此无需前缀，但存在重名覆盖风险。
7. 参考代码：

```python
import random

counts = {i: 0 for i in range(1, 7)}
for _ in range(100):
    counts[random.randint(1, 6)] += 1

for point in range(1, 7):
    print(point, "点：", counts[point], "次")
```

用字典推导式初始化六个计数器，循环 100 次累加。由于是随机模拟，各点数次数之和必为 100，但单个点数不固定。

8. **ABD**。C 错：`pip` 是第三方库的安装工具，标准库随解释器发布，不需要也不能通过 `pip` 安装。
