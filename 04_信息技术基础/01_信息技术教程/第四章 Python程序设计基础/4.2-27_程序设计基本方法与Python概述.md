程序是什么？人又是怎样把"做一件事的方法"讲给计算机听的？这两个问题看似抽象，却是整章的地基。本节先建立程序、算法、IPO 三个核心概念，再梳理程序设计语言从机器语言到高级语言的演进，最后落到 Python 这门语言本身的特点与适用边界。把这节的概念吃透，后面所有语法都只是"用 Python 把方法表达出来"的具体手段。

## 一、程序与程序设计的基本概念

### 1. 程序、指令与算法

**程序（Program）** 是为完成特定任务而编写的一组**指令序列**，计算机按顺序逐条执行，最终得到预期结果。可以把它比作一份菜谱：原料是数据，步骤是指令，厨师是处理器。

**指令（Instruction）** 是计算机能够识别并执行的最小操作单位，一般由操作码（做什么）和操作数（对谁做）两部分构成。一条指令只完成一个极小的动作，成千上万条指令按逻辑组合起来才成为程序。

**算法（Algorithm）** 是解决问题的明确步骤和有限规则。判断一段描述是不是算法，要看它是否同时满足五个特征：

- **有穷性**：必须在执行有限步骤后结束，不能永远循环下去。
- **确定性**：每一步的含义唯一，不允许"可能这样也可能那样"的歧义。
- **输入**：有零个或多个输入，即算法处理的数据来源。
- **输出**：有一个或多个输出，没有输出的算法没有意义。
- **可行性**：每一步都能通过有限次基本运算真正实现，不能提出计算机做不到的操作。

> 计算机科学家沃思（Niklaus Wirth）提出著名公式：**程序 = 算法 + 数据结构**。算法回答"怎么做"，数据结构回答"数据怎么组织存放"，二者结合并用某种语言书写，才成为可运行的程序。这是选择题与填空题的高频考点。

### 2. 程序设计的一般流程

**程序设计**不是单纯"敲代码"，而是从问题到可运行程序的完整过程，通常包含五个阶段：

1. **分析问题**：明确已知条件、求解目标与约束，弄清输入输出分别是什么。
2. **抽象建模**：去掉与目标无关的细节，提炼出关键变量及其关系。
3. **设计算法**：用自然语言、流程图或伪代码描述处理步骤，确定用顺序、分支还是循环。
4. **编写程序**：按选定语言的语法规则，把算法翻译成源代码。
5. **调试测试**：运行程序，发现并排除语法错误与逻辑错误，用多组数据验证结果是否正确。

这五个阶段并非一次走完，实际开发中常常需要回到前面的步骤反复修改，这种"分析—设计—编码—测试"的循环正是程序设计的常态。

### 3. 三种基本结构

任何复杂算法都可以由三种基本控制结构组合而成，这一结论是结构化程序设计的理论基石：

- **顺序结构**：语句自上而下依次执行，每条语句恰好执行一次。
- **分支结构**：根据条件是否成立，选择执行不同的语句块。
- **循环结构**：在条件满足时重复执行同一段语句，直到条件不再成立。

结构化程序设计还要求每个程序块**只有一个入口和一个出口**，避免随意跳转，从而使程序层次清晰、易于阅读和验证。第 4.6 节讲分支、第 4.7 节讲循环，正是对这三种结构的展开。

## 二、程序设计语言的发展历程

### 1. 从机器语言到高级语言

程序设计语言经历了由"面向机器"向"面向人"的演进，理解这条主线就能应对发展史类选择题。

| 阶段 | 代表形式 | 主要特点 | 优点 | 缺点 |
|------|----------|----------|------|------|
| 机器语言 | 二进制 0、1 组成的指令 | 计算机唯一能直接执行的语言 | 执行效率最高 | 难写、难读、难改、不可移植 |
| 汇编语言 | MOV、ADD 等助记符 | 用英文缩写代替二进制操作码 | 比机器语言易记易改 | 仍依赖具体 CPU，可移植性差 |
| 高级语言 | C、Java、Python 等 | 接近自然语言与数学表达 | 易学易用、可移植、开发效率高 | 必须先翻译成机器指令才能执行 |

高级语言按思维方式又可分为**面向过程**（如 C）、**面向对象**（如 Java、C++）和**函数式**（如 Haskell）等范式。Python 是一门支持多种范式的高级语言，既可以按面向过程的方式顺序编写脚本，也可以用类和对象组织大型程序。

### 2. 编译与解释

高级语言写的源程序计算机无法直接执行，必须经过"翻译"。翻译方式分为编译和解释两种，这是本节最重要的对比考点。

| 对比项 | 编译方式 | 解释方式 |
|--------|----------|----------|
| 翻译时机 | 一次性把整个源程序翻译成目标程序 | 逐句翻译、逐句执行 |
| 是否生成目标程序 | 生成独立的可执行文件 | 不生成独立的目标程序 |
| 执行效率 | 高，直接运行机器码 | 较低，每次运行都要翻译 |
| 可移植性 | 差，换平台往往要重新编译 | 好，有解释器即可运行 |
| 调试便利性 | 修改后必须重新编译 | 修改后立即生效，便于调试 |
| 代表语言 | C、C++、Go | Python、JavaScript、BASIC |

> 易错提醒：Python 属于**解释型**语言，但 CPython 的执行并非纯粹"说一句译一句"，它会先把源代码编译成字节码，再由虚拟机逐条执行。考试口径统一按"解释型"掌握即可。另外 Java 采用"先编译成字节码、再由 JVM 解释执行"的混合方式，不要简单归为纯编译型。

### 3. 未来的发展趋势

了解趋势对应考纲第 2 条，多以判断题形式出现，抓住几个关键词即可：

- **高级化**：抽象层次不断提高，开发者更多关注"做什么"而非"怎么做"。
- **脚本化与胶水化**：Python 擅长把不同组件拼接起来，被称为"胶水语言"。
- **智能化**：AI 辅助编程、低代码与无代码平台降低了编程门槛。
- **生态化**：语言之间的竞争越来越体现为库和社区生态的竞争。
- **并行化与云端化**：多核处理器与云计算要求语言更好地支持并发和分布式计算。

## 三、Python 语言的特点与适用场景

### 1. Python 的诞生与语言特点

Python 由荷兰人吉多·范罗苏姆（Guido van Rossum）于 1989 年圣诞节前后开始设计，1991 年公开发布第一个版本。语言名称取自他喜爱的喜剧团体"蒙提·派森"，与爬行动物无关。Python 的主要特点可以概括如下：

- **简洁易读**：用缩进表示代码块，语法接近自然语言，同样功能代码量通常只有 C 的几分之一。
- **解释执行**：无需编译即可运行，跨平台性好，写好的程序在 Windows、Linux、macOS 上基本可直接运行。
- **动态类型**：变量不需要事先声明类型，赋值时自动确定，使用灵活。
- **开源免费**：源代码开放，拥有全球庞大的社区和第三方库。
- **胶水语言**：能方便地调用 C、C++ 编写的扩展模块，也能被其他语言嵌入调用。
- **生态丰富**：标准库覆盖文件、网络、图形界面等常见需求，第三方库覆盖数据科学、人工智能、Web 开发等几乎所有领域。

### 2. 适用场景

| 应用领域 | 典型任务 | 常用库或工具 |
|----------|----------|--------------|
| 数据分析 | 清洗、统计、可视化 | pandas、NumPy、Matplotlib |
| 人工智能 | 机器学习、深度学习 | scikit-learn、PyTorch、TensorFlow |
| Web 开发 | 网站后端、接口服务 | Django、Flask |
| 自动化运维 | 批量处理、定时脚本 | os、sys、shutil |
| 网络爬虫 | 网页抓取与信息提取 | requests、BeautifulSoup |
| 教学科研 | 算法演示、快速原型 | 标准库为主 |

Python 也有明显短板：对执行效率要求极高的底层系统、实时嵌入式设备和原生移动应用通常不用 Python，而选择 C、C++、Rust 或 Swift。考试常问"下列哪项最适合用 Python 完成"，抓住**数据处理、人工智能、自动化、Web 后端、教学**这几个关键词即可。

**例 4.1-1** 用 IPO 方法分析并编写程序：输入圆的半径，输出该圆的周长和面积（π 取 3.14159）。

**解**

1. **输入（Input）**：从键盘读入半径 r，可能是小数，用 `float()` 转换。
2. **处理（Process）**：周长 c = 2 × π × r，面积 s = π × r × r。
3. **输出（Output）**：依次打印周长和面积，保留两位小数便于阅读。

```python
pi = 3.14159
r = float(input("r="))
c = 2 * pi * r
s = pi * r * r
print("周长:", round(c, 2))
print("面积:", round(s, 2))
```

若输入 `r=2`，程序输出周长为 12.57、面积为 12.57（此处 12.56636 四舍五入为 12.57），说明顺序结构按书写次序逐条执行，每条语句只执行一次。

**例 4.1-2** 某商品单价 25.5 元，购买 4 件，商家规定总价满 100 元打九折。请指出这段处理的 IPO 三要素，并写出程序验证输入 4 件时的实付金额。

**解**

1. **输入**：单价 price = 25.5、数量 count = 4（也可由键盘读入）。
2. **处理**：先算原价 total = price × count，再判断是否满 100，满则乘 0.9。
3. **输出**：打印原价与实付金额。
4. 注意这里出现了"判断"，严格来说已经超出纯顺序结构，属于分支结构，第 4.6 节会系统讲解，此处先用条件表达式示范。

```python
price = 25.5
count = 4
total = price * count
pay = total * 0.9 if total >= 100 else total
print("原价:", total)
print("实付:", pay)
```

原价为 102.0 元，满 100 打九折，实付 91.8 元。

- **易错点**：①把"程序 = 算法 + 数据结构"误记成"程序 = 算法 + 程序"；②认为算法可以有无限循环，忽略有穷性；③把 Python 说成编译型语言，或认为解释型语言也生成独立可执行文件；④把 π 写成 3.14 导致精度不足，题目给了 3.14159 就应按给定值计算。

## 本节小结

1. 程序是为完成任务编写的**指令序列**；沃思公式为**程序 = 算法 + 数据结构**。
2. 算法具有**有穷性、确定性、输入、输出、可行性**五个特征，缺一不可。
3. 程序设计流程为：分析问题 → 抽象建模 → 设计算法 → 编写程序 → 调试测试，且常常反复迭代。
4. 三种基本结构是**顺序、分支、循环**，结构化程序要求单入口单出口。
5. 语言由机器语言、汇编语言发展到高级语言；**编译**一次性生成目标程序、效率高但移植差，**解释**逐句执行、不生成目标程序、易调试，Python 属解释型。
6. Python 由吉多·范罗苏姆创制，特点是简洁、解释型、动态类型、开源、胶水语言、生态丰富，适用于数据分析、AI、Web、自动化与教学。

A. 编译方式逐句翻译、逐句执行
B. 解释方式会生成独立的目标程序

A. 程序（Program）　B. 打印（Print）　C. 处理（Process）　D. 参数（Parameter）

4.（单选）下列不属于算法基本特征的是（　）。
A. 有穷性　B. 确定性　C. 可移植性　D. 可行性

5.（判断）算法允许没有输出，只要过程正确即可。（　）

6.（填空）程序设计语言的发展经历了机器语言、________和高级语言三个阶段。

7.（填空）结构化程序的三种基本控制结构是顺序、________和循环。

8.（多选）下列属于 Python 语言特点的有（　）。
A. 解释执行、跨平台性好
B. 变量使用前必须显式声明类型
C. 语法简洁、代码可读性强
D. 拥有丰富的第三方库生态

### 参考答案

1. **B**。沃思提出的公式是程序 = 算法 + 数据结构，A、C、D 均为杜撰。
2. **C**。编译是一次性翻译并生成目标程序，解释逐句执行且不生成目标程序，因此 A、B 错误；编译型语言换平台常需重新编译，可移植性较差，D 错误。
3. **C**。IPO 指 Input 输入、Process 处理、Output 输出。
4. **C**。算法的五个特征是：有穷性、确定性、输入、输出、可行性；可移植性是语言或程序的属性，不是算法的特征。
5. **错**。算法必须有输出，没有输出的算法没有实际意义。
6. **汇编语言**。
7. **分支（选择）**。
8. **ACD**。B 错：Python 是动态类型语言，变量赋值即创建，无需事先声明类型；A、C、D 均符合 Python 的实际情况。
