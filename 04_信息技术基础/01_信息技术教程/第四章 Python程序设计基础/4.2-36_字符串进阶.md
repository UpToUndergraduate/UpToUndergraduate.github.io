# 4.10 字符串进阶

> **考纲对应**：Python 程序设计基础 第 6 条——掌握字符串的索引、切片、常用方法与格式化输出（层次：掌握）
> **教材对应**：Python 二级教程 · 第 3 章 基本数据类型

字符串是程序中出现频率最高的数据类型：输入的内容是字符串，输出的结果也是字符串，读文件读到的仍是字符串。上一节我们把字符串当作序列看待，本节进一步讨论它的不可变性、切片技巧、常用方法与格式化输出。掌握这些内容，才能完成"统计字符""清洗数据""按格式打印报表"这类真实任务，这也是二级考试上机题的高频场景。

## 一、字符串的表示与索引切片

### 1. 三种引号与转义字符

Python 用单引号、双引号、三引号表示字符串，单双引号完全等价，三引号可跨行书写：

```python
a = 'Python'
b = "Python"
c = """第一行
第二行"""
```

字符串内需要出现引号时，可用另一种引号包裹，或用反斜杠转义：`'It\'s ok'`。常见转义字符有 `\n`（换行）、`\t`（制表符）、`\\`（反斜杠本身）。若希望反斜杠不被当作转义符，在引号前加 `r`，如 `r"C:\temp\new"` 表示原始字符串，这在写文件路径时非常实用。

三引号除了能跨行，还常用于两类场景：一是书写多行说明文字，二是作为函数、模块的文档字符串。由于三引号内的换行会被原样保留，输出多行内容时无需逐个添加 `\n`，例如 `print("""第一行\n第二行""")` 与直接写两行等价，后者更易读。需要注意的是，三引号字符串本身仍是普通字符串，同样不可变、同样支持切片。

### 2. 索引与切片

字符串是字符的序列，支持下标与切片，规则与列表一致：下标从 0 开始，负数从末尾计数；切片为 `s[起点:终点:步长]`，左闭右开，步长为负时从右向左取。

```python
s = "Python"
print(s[0], s[-1])       # P n
print(s[1:4])            # yth
print(s[:3])             # Pyt
print(s[::2])            # Pto
print(s[::-1])           # nohtyP
```

切片不会因为下标越界而报错，超出范围的部分自动截断，这一点与单下标访问不同。

### 3. 字符串的不可变性

字符串是**不可变对象**：一旦创建，其中的字符不能修改。`s[0] = "J"` 会抛出 `TypeError`。所有"看起来在修改"的方法，实际上都返回一个新字符串，原字符串保持不变：

```python
s = "python"
t = s.upper()
print(s)     # python
print(t)     # PYTHON
```

理解这一点是判断"方法是否改变原串"的关键，也是与列表操作最重要的区别。若确实要修改某一位，只能拼接生成新串，如 `s = s[:1] + "J" + s[2:]`。由此也带来一个性能提示：在循环中反复执行 `s += ch` 会不断创建新对象，拼接上百次后开销明显，正确做法是先把片段存入列表，最后用 `"".join(parts)` 一次合并。

**例 4.10-1**

从身份证号（18 位字符串）中提取出生日期，并按"年-月-日"格式输出。

**解**

1. 身份证号第 7 至 14 位为出生日期，对应下标 6 到 13。
2. 用切片 `id[6:14]` 取出 8 位数字。
3. 再用三次切片分别取年、月、日并拼接。

```python
id_card = "320102200503158888"
birth = id_card[6:14]
year = birth[0:4]
month = birth[4:6]
day = birth[6:8]
print("出生日期：%s-%s-%s" % (year, month, day))
```

运行结果：

```
出生日期：2005-03-15
```

**分析**：切片下标以 0 计，第 7 位字符的下标是 6，故取 `[6:14]` 恰好 8 个字符。若写成 `[7:14]`，会少取一位且整体错位。这类"数位对齐"的错误在上机题中极常见，答题时应先写出下标表再动笔。

- **易错点**：① 切片终点是"取不到"的，`s[0:3]` 取 3 个字符而不是 4 个；② 步长为负时，起点应大于终点，`s[5:1:-1]` 才有意义；③ 试图用下标给字符串赋值会报 `TypeError`，必须生成新串。

## 二、常用方法与格式化

### 1. 方法与函数的区别

方法是"绑定在对象上"的函数，用 `对象.方法(参数)` 调用，如 `s.upper()`；函数是独立的，用 `函数名(参数)` 调用，如 `len(s)`。字符串方法数量众多，考试重点集中在下面几类，掌握"输入什么、返回什么、是否改变原串"三点即可应对绝大多数题目。

| 方法 | 功能 | 返回示例 |
|---|---|---|
| `len(s)` | 求长度（函数） | `len("abc")` → 3 |
| `upper()` / `lower()` | 转大写 / 小写 | `"Ab".lower()` → `"ab"` |
| `strip()` | 去掉两端空白（或指定字符） | `"  hi ".strip()` → `"hi"` |
| `split(sep)` | 按分隔符拆成列表 | `"a,b".split(",")` → `['a','b']` |
| `join(seq)` | 用当前串连接序列 | `"-".join(['a','b'])` → `"a-b"` |
| `replace(old, new)` | 替换全部子串 | `"aa".replace("a","b")` → `"bb"` |
| `find(sub)` | 返回首次出现的下标，找不到为 -1 | `"abc".find("c")` → 2 |
| `count(sub)` | 统计子串出现次数 | `"aba".count("a")` → 2 |
| `startswith(p)` / `endswith(p)` | 判断前缀 / 后缀 | 返回布尔值 |

需要注意：`find()` 找不到时返回 `-1`，而 `index()` 找不到时抛 `ValueError`；`split()` 不传参数时按任意空白字符拆分，并自动忽略连续空白；`join()` 的调用者是**分隔符**，参数是要连接的可迭代对象，顺序不能颠倒。

由于每个方法都返回字符串，多个方法可以首尾相接形成**链式调用**，例如 `s.strip().lower().replace(" ", "")`：先去两端空白，再转小写，最后删除全部空格。链式调用从左到右依次执行，前一步的结果作为后一步的调用者。它能让清洗逻辑一行写完，但链条过长会降低可读性，调试时也不易定位是哪一步出错，建议不超过三步。

### 2. 大小写、去空白与判断类方法

`strip()` 只去掉两端字符，不去中间；配套的 `lstrip()`、`rstrip()` 分别处理左端与右端。判断类方法返回布尔值，常用于输入校验：`isdigit()` 判断是否全为数字，`isalpha()` 判断是否全为字母，`isspace()` 判断是否全为空白，`isalnum()` 判断是否只含字母和数字。这些方法对空字符串一律返回 `False`。

### 3. 格式化输出的三种方式

```python
name, score = "张三", 92.5

print("姓名：%s，成绩：%.1f" % (name, score))          # ① % 格式化
print("姓名：{}，成绩：{:.1f}".format(name, score))     # ② format 方法
print(f"姓名：{name}，成绩：{score:.1f}")               # ③ f-string
```

三者输出相同。f-string 在字符串前加 `f`，直接把变量名写进花括号，最简洁，也是 Python 3.6 之后推荐的方式。格式说明符写在冒号后，常用形式为 `{值:填充符对齐方式宽度.精度类型}`：`{name:<6}` 表示左对齐占 6 列，`{score:>8.2f}` 表示右对齐、保留两位小数。

**例 4.10-2**

按表格形式输出三名学生的姓名与成绩，姓名左对齐占 8 列，成绩右对齐占 6 列并保留一位小数。

**解**

1. 用列表存放"姓名-成绩"元组，遍历时解包。
2. 用 f-string 的 `<`、`>` 控制对齐方向，数字写在列宽之后。
3. 先输出表头，再输出数据行，列宽保持一致。

```python
students = [("张三", 88), ("李四", 95.5), ("王五", 76)]

print(f"{'姓名':<8}{'成绩':>6}")
print("-" * 14)
for name, score in students:
    print(f"{name:<8}{score:>6.1f}")
```

运行结果：

```
姓名        成绩
--------------
张三        88.0
李四        95.5
王五        76.0
```

**分析**：`<` 表示左对齐、`>` 表示右对齐，默认是右对齐（数字）或左对齐（字符串）。列宽不足时不会截断，而是整体撑开，导致表格错位，因此中文姓名一般留 4 到 8 列。用 `"-" * 14` 生成分隔线，体现字符串乘法这一常用技巧。

- **易错点**：① `"1,2".split()` 不传分隔符只按空白拆，得到 `['1,2']`，必须写 `split(",")`；② `join` 的参数必须是字符串序列，含数字时需先用 `map(str, ...)` 转换；③ f-string 中花括号要输出字面量时写成 `{{` 和 `}}`。

## 三、字符串处理的应用

### 1. 遍历与分类统计

字符串可直接用于 `for` 循环，每次取出一个字符。结合判断类方法，就能完成"统计字母、数字、空格、其他字符各多少个"这类经典题目。若还需要位置信息，可用 `enumerate(s)` 同时取得下标和字符。统计之前应先明确"字符"的口径：Python 3 中一个汉字也算一个字符，若题目要求统计英文字母，就必须把范围限定在 ASCII 区间内。

### 2. 字符与编码

内置函数 `ord(ch)` 返回字符的 Unicode 码位，`chr(n)` 由码位还原字符：

```python
print(ord("A"), ord("中"))    # 65 20013
print(chr(97))                # a
```

利用这一点可以完成大小写转换、凯撒密码等练习：小写字母 `ord(ch) - 32` 即对应大写字母的码位。例如把句子中每个字母后移一位：

```python
text = "abc xyz"
secret = "".join(chr((ord(ch) - 97 + 1) % 26 + 97) if ch.islower() else ch
                 for ch in text)
print(secret)     # bcd yza
```

其中 `(ord(ch) - 97 + 1) % 26` 把字母映射到 0~25 的序号再循环移位，最后加 97 还原为码位。字符串的 `encode()` 与 `decode()` 用于在字符与字节之间转换，读二进制文件时才需要，日常文本处理不必深究。

### 3. 输入清洗的常见套路

从键盘或文件读入的文本往往带有多余空白、空行或全角符号。标准流程是：先 `strip()` 去两端空白，再判断是否为空串，然后用 `split()` 拆分，最后对每段做类型转换。若转换可能失败，应配合 `try-except` 或 `isdigit()` 先行校验，避免程序因一个脏数据整体崩溃。

以"读入一行逗号分隔的成绩"为例，`line = input().strip()` 之后，若 `line` 为空应提示重新输入，否则执行 `parts = line.split(",")`，再用列表推导式 `[float(x) for x in parts]` 统一转成数值。这三步几乎覆盖了所有文本解析类上机题的开头部分。

**例 4.10-3**

统计字符串 `"Hello, Python 3.10"` 中字母、数字、空格和其他字符的个数。

**解**

1. 初始化四个计数器。
2. 遍历每个字符，按优先级用 `isalpha()`、`isdigit()`、`isspace()` 判断。
3. 三类都不满足的计入"其他"，最后格式化输出。

```python
s = "Hello, Python 3.10"
letters = digits = spaces = others = 0
for ch in s:
    if ch.isalpha():
        letters += 1
    elif ch.isdigit():
        digits += 1
    elif ch.isspace():
        spaces += 1
    else:
        others += 1

print("字母：%d，数字：%d，空格：%d，其他：%d" % (letters, digits, spaces, others))
```

运行结果：

```
字母：11，数字：3，空格：2，其他：2
```

- **易错点**：① 判断顺序影响结果，例如先判断 `isalnum()` 会把字母和数字混为一类；② 中文也算"字母"（`isalpha()` 返回 `True`），统计英文时需限定 `"a" <= ch <= "z"`；③ 用 `in` 判断子串与用 `==` 判断整串含义不同，`"a" in "abc"` 为 `True`。

## 本节小结

1. 字符串可用单、双、三引号表示，`r` 前缀生成原始字符串，`\n`、`\t` 等为常用转义字符。
2. 字符串支持下标与切片，规则为左闭右开，步长为负可逆序；切片越界不报错。
3. 字符串不可变，`upper`、`replace`、`strip` 等方法都返回新串，原串不变。
4. `split` 拆分得到列表，`join` 用分隔符连接序列，二者的方向相反，参数类型不同。
5. `find` 找不到返回 `-1`，`index` 找不到抛异常；判断类方法对空串返回 `False`。
6. 格式化优先用 f-string，格式说明符 `{值:填充对齐宽度.精度}` 可控制对齐与小数位。

## 自测题

1.（单选）已知 `s = "Python"`，则 `s[1:4]` 的值是（　）。
A. `"yth"`　B. `"ytho"`　C. `"Pyt"`　D. `"tho"`

2.（单选）下列代码执行后，输出结果是（　）。
```python
s = "abc"
t = s.upper()
print(s, t)
```
A. `ABC ABC`　B. `abc abc`　C. `abc ABC`　D. 报错

3.（单选）`"2025-11-28".split("-")` 的结果是（　）。
A. `"2025 11 28"`　B. `['2025', '11', '28']`　C. `('2025', '11', '28')`　D. `['2025-11-28']`

4.（单选）`"hello".find("x")` 的返回值是（　）。
A. `0`　B. `None`　C. `-1`　D. 抛出异常

5.（填空）表达式 `"-".join(["a", "b", "c"])` 的值是________；表达式 `"%s-%d" % ("A", 3)` 的值是________。

6.（判断）执行 `s = "abc"` 后，语句 `s[0] = "A"` 可以把首字母改为大写 A。（　）

7.（编程）判断一个字符串是否为回文（正读与反读相同），忽略大小写，输出 `True` 或 `False`。

8.（多选）关于字符串操作，下列说法正确的是（　）。
A. `strip()` 只会去掉字符串两端的空白字符
B. `replace()` 返回一个新字符串，原字符串保持不变
C. `split()` 的返回值是一个字符串
D. `join()` 的作用是把字符串按位置拆分成列表

### 参考答案

1. **A**。切片取下标 1、2、3 三个字符，即 `y`、`t`、`h`。
2. **C**。`upper()` 返回新串赋给 `t`，原串 `s` 不变，故输出 `abc ABC`。
3. **B**。`split` 按分隔符拆分并返回列表，元素为字符串。
4. **C**。`find` 找不到子串时返回 `-1`，不抛异常；`index` 才会抛 `ValueError`。
5. `"a-b-c"`；`"A-3"`。`join` 用调用者作分隔符连接序列，`%` 格式化按顺序替换占位符。
6. **错误**。字符串不可变，下标赋值会抛出 `TypeError`，只能通过切片拼接生成新串。
7. 参考代码：

```python
s = input("请输入字符串：").lower()
print(s == s[::-1])
```

`s[::-1]` 得到逆序串，与自身比较即可。若要求忽略空格，可先写 `s = s.replace(" ", "").lower()`。

8. **AB**。C 错：`split()` 返回的是列表而不是字符串；D 错：`join()` 是把序列连接成一个字符串，拆分用的是 `split()`。
