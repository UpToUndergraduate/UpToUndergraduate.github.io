# 3.1 演示文稿基础：创建、视图与幻灯片操作

> **考纲对应**：演示文稿制作 第 1~4 条——了解应用场景与制作流程，掌握创建、打开、保存、退出，熟悉视图方式，掌握幻灯片的创建、复制、删除、移动（层次：掌握）
> **教材对应**：单元 3 · 任务 制作产品介绍演示文稿

演示文稿是"讲给别人看"的文档，它的评价标准不是字数，而是信息能否在几秒内被看懂。本节先把工具用顺：文件怎么建、怎么存，五种视图各管什么，幻灯片怎么增删挪移。这些操作看着琐碎，却是后面设计、动画、放映的地基。

## 一、应用场景、界面与制作流程

### 1. 三类典型场景

| 场景 | 典型例子 | 对演示的要求 |
| --- | --- | --- |
| 汇报宣讲 | 工作总结、答辩、竞标 | 结构清晰，数据用图表说话，页数受时间约束 |
| 教学培训 | 课程讲授、操作演示 | 每页信息量小，重点靠动画分步呈现 |
| 展台展示 | 展会循环播放、大堂导览 | 无需人操作，自动循环，画面冲击力强 |

场景决定了放映方式（有人讲还是无人值守）、信息密度和动画策略，制作前必须先明确。

页数与时长要匹配。经验值是每页讲 1~2 分钟，20 分钟的汇报做 15~20 页正文为宜；页数远超时长，只能靠快速翻页，听众什么都留不下。反过来，一页停留超过 3 分钟而没有新信息，注意力同样会流失，这时应把该页拆成"结论页 + 证据页"。

### 2. 操作界面

WPS 演示的窗口由五部分组成：

- **选项卡与功能区**：开始、插入、设计、切换、动画、幻灯片放映、审阅、视图等选项卡，命令按任务分组。
- **幻灯片窗格**：左侧缩略图列表，可切换为"大纲"，用于快速录入和调整层级。
- **编辑区**：当前幻灯片的编辑画布，占位符虚线框提示"此处放什么"。
- **备注窗格**：编辑区下方的"单击此处添加备注"，写讲稿用，放映时观众看不到。
- **状态栏**：显示当前页/总页数、视图切换按钮与缩放滑块。

### 3. 制作流程

1. 明确目标、受众与时长，先写一句话主题；
2. 用大纲列提纲，一页一个观点；
3. 选主题与配色，确定版式体系；
4. 逐页填充文字、图表、图片；
5. 通过母版统一字体、页码、Logo；
6. 设置切换与对象动画，控制在"辅助表达"的范围；
7. 排练计时，检查超时页；
8. 放映前试放，或导出为 PDF、视频分发。

## 二、创建、打开、保存与退出

### 1. 新建

启动 WPS 演示后，在首页选"新建"：可选"空白演示文稿"，也可从"模板"库中按"产品介绍""工作总结"等关键词挑选现成设计，联网时云端模板更丰富。编辑过程中按 `Ctrl+N` 新建空白文稿。

新建后应先定**幻灯片大小**：设计 → 幻灯片大小，常用"宽屏 16:9"（1920×1080）或"标准 4:3"（1024×768）。尺寸改晚了的代价是全部元素重新排版，所以这一步要前置。

### 2. 打开

`Ctrl+O` 打开对话框；首页"最近"列表可快速回到近期文件。WPS 支持直接打开 `.pptx`、`.ppt`、`.ppsx`，也可导入 PDF 转成可编辑幻灯片（版式会有偏差，需人工修整）。

### 3. 保存与另存为

`Ctrl+S` 保存，首次保存会要求选路径与文件名；`F12` 为另存为，用于换格式或留版本。

| 格式 | 说明 | 适用场合 |
| --- | --- | --- |
| `.pptx` | 新版默认格式，兼容 PowerPoint 2016 及以上 | 日常编辑、交付 |
| `.ppt` | 97-2003 旧格式 | 对方软件版本很旧 |
| `.ppsx` | 放映格式，双击直接全屏播放 | 只给人看、不需修改 |
| `.pdf` | 版面固定，字体不乱 | 定稿传阅、打印 |
| `.dps` | WPS 自有格式 | 仅在本机 WPS 环境流转 |

> **注意**：另存为 `.ppt` 时，新版特有的切换、动画效果可能降级或丢失，交付前应实际放映检查一遍。

WPS 默认开启定时备份，误删或崩溃后可到"文件 → 备份与恢复 → 备份中心"找回历史版本。这是最后一道保险，不能替代主动保存。

### 4. 退出

关闭窗口或 `Alt+F4`。若有未保存修改，会弹出"保存/不保存/取消"三选一；选"取消"则回到编辑状态，不要把它当成"关闭"。

## 三、五种视图方式

| 视图 | 入口 | 主要用途 |
| --- | --- | --- |
| 普通视图 | 视图 → 普通，或状态栏第一个按钮 | 逐页编辑，左侧可切换"幻灯片/大纲" |
| 幻灯片浏览 | 视图 → 幻灯片浏览 | 全局看顺序与风格是否统一，可多选、拖动排序、批量设切换 |
| 备注页 | 视图 → 备注页 | 编辑备注，一页幻灯片配一页备注 |
| 阅读视图 | 视图 → 阅读视图 | 在窗口内试放，不占满全屏，`Esc` 退出 |
| 幻灯片放映 | `F5` 从头，`Shift+F5` 从当前页 | 正式放映 |

**大纲录入**是提速的关键：普通视图左侧切到"大纲"，直接敲标题，`Enter` 产生同级标题，`Tab` 降为下一级正文，`Shift+Tab` 升回上一级。整份讲稿的骨架几分钟就能成形，比一页页插入文本框规范得多。

两个窗格的分工要分清：缩略图看整体，大纲改结构。在大纲里删掉一行标题，对应整页随之消失；把某个条目拖到别处，连同它的下级要点整块搬家。排版阶段则应回到缩略图和编辑区，因为大纲只显示文字，图表、图片、形状通通看不到，容易误判页面是否已满。

## 四、幻灯片的基本操作

### 1. 新建与套用版式

`Ctrl+M` 在当前页之后插入新页，新页继承当前页的版式。要换版式：在缩略图上右键 → 版式，选择"标题幻灯片""标题和内容""两栏内容""仅标题""空白"等。版式只决定**占位符的位置与种类**，不含具体内容。

### 2. 选择、复制、移动、删除

| 操作 | 方法 |
| --- | --- |
| 选中一页 | 单击缩略图 |
| 选中多页 | `Ctrl` 单击不连续页，`Shift` 单击连续页 |
| 复制 | 右键"复制幻灯片"，或 `Ctrl+C` 后 `Ctrl+V` |
| 移动 | 在缩略图区按住拖动到目标位置 |
| 删除 | 选中后按 `Delete` |
| 全部选中 | 缩略图区按 `Ctrl+A` |

复制出的幻灯片与原页完全一致，适合"同一结构、不同数据"的分页，改完内容即成新页。

移动与复制容易混淆：按住拖动是**移动**（原位置不再保留），按住 `Ctrl` 再拖动是**复制**（拖到哪就在哪生成一份副本）。页码不是手工输入的，它由位置决定，所以移动之后不需要"重新编号"；如果页面上有手写的数字，那才是真正的隐患。

### 3. 幻灯片大小与方向

设计 → 幻灯片大小 → 自定义，可改宽高或切换纵向。改动后弹出"最大化/确保适合"：最大化按新比例放大内容（可能超出边界），确保适合按比例缩小以完整显示（可能留白）。已有大量手工排版时，两者都要逐页复查。

### 4. 交付前的兼容性检查

把文件发给别人之前，至少做三件事：删掉批注、清空不想外传的备注，并检查文档属性中的作者信息；`F12` 另存一份 `.pdf` 作为版式基准；在自己机器上按 `F5` 完整放一遍。若对方使用旧版软件或手机端，应提前另存 `.ppt` 或导出 PDF，而不是等对方打不开再来补救。文件名建议"主题+日期+版本"，例如 `产品介绍_20261128_v3.pptx`，避免"最终版""最终版2"这类无法分辨的命名。

**例 3.1-1** 要在 40 分钟内做出一份 12 页的产品介绍初稿，手上只有文字资料，没有设计稿。

**解**

1. 文件 → 新建，在模板库搜索"产品介绍"，选一套 16:9 模板创建；模板已含配色、字体与版式，省去从零设计。
2. 在普通视图左侧切到"大纲"，第一行输入产品名作为标题页，`Enter` 后逐条输入各章标题。
3. 每个章标题下按 `Tab` 降级，录入 2~3 条要点；`Enter` 生成同级要点，`Shift+Tab` 可升回章标题级。
4. 大纲转成幻灯片后，检查是否有页面内容溢出占位符，超出的拆成两页而不是缩小字号。
5. `Ctrl+S` 保存为 `产品介绍.pptx`，再 `F12` 另存一份带日期的副本作为过程版本。

**例 3.1-2** 一份 8 页讲稿中，第 6 页"价格"被放到了"案例"之前，且第 3 页之后各页版式混乱，需一次整理。

**解**

1. 视图 → 幻灯片浏览，8 页并排显示，顺序问题一目了然。
2. 拖动第 6 页到第 3 页之后松手，其余页自动顺延，页脚编号随位置重排。
3. 按住 `Shift` 单击第 3 页至最后页，右键 → 版式 → "标题和内容"，一次套用到所选全部页面。
4. 逐页检查切换版式后文字是否溢出、图片是否被占位符遮挡，必要时用"开始 → 排列 → 对齐"重新定位。
5. 切回普通视图，用 `F5` 试放一遍确认逻辑连贯，再保存。

- **易错点**：① 用 `Enter` 在正文里换行来"新建一页"，实际只是加了空段落，正确做法是 `Ctrl+M`；② 删除幻灯片用 `Delete`，若光标停在编辑区文字中，删掉的是文字而不是整页，需先点中缩略图；③ 改幻灯片大小后只检查首页，后面的图片往往已出血或被裁切。

## 本节小结

1. 演示文稿是文件整体，幻灯片是其中一页；场景决定放映方式与信息密度。
2. 制作流程：定目标 → 列大纲 → 选主题 → 填内容 → 统一母版 → 加动画 → 排练计时 → 放映或导出。
3. `Ctrl+N` 新建、`Ctrl+O` 打开、`Ctrl+S` 保存、`F12` 另存为；交付优先 `.pptx`，只读分发用 `.pdf` 或 `.ppsx`。
4. 五种视图：普通、幻灯片浏览、备注页、阅读视图、幻灯片放映（`F5`/`Shift+F5`）。
5. `Ctrl+M` 新建页，拖动缩略图改顺序，`Delete` 删除，右键"版式"换布局。
6. 幻灯片大小应在动手排版前确定，16:9 为当前主流。

6.（填空）要同时选中第 2 页和第 5 页这两张不相邻的幻灯片，应按住 ________ 键分别单击。

7.（填空）在缩略图区拖动幻灯片，可以改变幻灯片的 ________。

8.（多选）关于视图与幻灯片操作，下列说法正确的有（　）。
A. 幻灯片浏览视图可同时显示多页，适合调整顺序与检查风格统一
B. 备注页中录入的内容在放映时不会显示给观众
C. 在普通视图左侧缩略图区拖动，可以调整幻灯片顺序
D. 阅读视图下可以直接修改幻灯片中的文字

### 参考答案

1. **B**。演示文稿指整个文件，幻灯片指其中一页。
2. **B**。`Ctrl+M` 插入新幻灯片；`Ctrl+N` 是新建文件。
3. **A**。`F5` 从头放映，`Shift+F5` 从当前页放映。
4. **C**。阅读视图在窗口内播放，`Esc` 退出。
5. **错**。`.ppt` 为 97-2003 格式，新版效果可能降级或丢失，需实际放映核对。
6. `Ctrl`。
7. 顺序（排列位置）。
8. **ABC**。D 错：阅读视图是预览状态，不能编辑内容。
