# 3.6 放映与导出

> **考纲对应**：演示文稿制作 第 9、10 条——了解幻灯片的放映类型，会使用排练计时进行放映；了解幻灯片不同格式的导出方法（层次：了解）
> **教材对应**：单元 3 · 任务 制作产品介绍演示文稿

内容做得再好，放映环节出问题就前功尽弃：投影切不过来、动画时间对不上、发给客户的文件字体乱成一团。本节讲清三种放映类型的差别、放映中的控制手段、排练计时的用法，以及把成品导出为 PDF、图片、视频的具体路径。

## 一、三种放映类型

入口：幻灯片放映 → 设置放映方式。对话框上半部分为"放映类型"，三个选项对应三种完全不同的使用环境。

| 类型 | 呈现方式 | 换片控制 | 适用场合 |
| --- | --- | --- | --- |
| 演讲者放映（全屏） | 全屏 | 演讲者用鼠标、键盘或翻页笔控制 | 汇报、答辩、培训 |
| 观众自行浏览（窗口） | 窗口内显示，带滚动条 | 观众自己滚动或点击 | 发给他人自学、展台旁查询 |
| 在展台浏览（全屏） | 全屏，屏蔽大部分操作 | 按预先设定的时间自动换片 | 展会、大堂循环播放 |

选择"在展台浏览"时，鼠标点击不再翻页，必须配合自动换片时间使用，否则画面会停在第一页；该模式下结束放映需按 `Esc`。同一对话框还可设置"循环放映，按 Esc 键终止"、换片方式（手动 / 如果存在排练时间则使用它）以及放映范围（全部 / 从第几页到第几页）。

三种类型的差别，本质是"谁掌握换片权"：演讲者放映把控制权交给讲者，适合需要临场发挥的场合；观众自行浏览把控制权交给观众，适合对方按自己节奏翻阅；展台浏览把控制权交给时间，适合无人值守。选错类型的典型后果是——用演讲者放映做展台，画面永远停在封面；用展台浏览做汇报，讲者想停也停不住。

## 二、放映中的控制

| 操作 | 方法 |
| --- | --- |
| 从头放映 | `F5` |
| 从当前页放映 | `Shift+F5` |
| 下一页 / 上一页 | 单击、`PageDown`、`→` / `PageUp`、`←` |
| 跳到指定页 | 输入页码后按 `Enter` 直接跳转 |
| 临时黑屏 / 白屏 | 右键 → 屏幕 → 黑屏 / 白屏 |
| 在画面上标注 | 右键 → 画笔，选笔型与颜色，画完可"橡皮擦"清除 |
| 结束放映 | `Esc`，或右键 → 结束放映 |

几个细节：放映时鼠标指针会自动隐藏，移动鼠标才出现；右键菜单里的"定位至幻灯片"可按标题选页，比记页码可靠；标注只在当前次放映中有效，不会改动原文件。

上台前还有两件事要确认：一是投影分辨率与幻灯片比例一致，16:9 的文稿投到 4:3 的幕布上，左右会被裁掉或上下留黑边，需在显示设置中调成"扩展"并匹配比例；二是关闭电脑的屏保、通知与自动更新，放映中弹出的消息框会被所有观众看到。

## 三、排练计时

排练计时用于"自己讲一遍，让软件记下每页用了多久"，之后可自动播放，也可用来检查是否超时。

1. 幻灯片放映 → 排练计时，进入放映状态，左上角出现计时器，显示本页用时与累计总时间。
2. 按平时语速讲解，讲完一页点"下一项"（或单击）进入下一页，计时自动切换。
3. 全部讲完后弹出提示，显示总时长，选择"是"保留计时，选择"否"则丢弃。
4. 保留后，在设置放映方式中把换片方式设为"如果存在排练时间，则使用它"，放映即按记录自动换片。
5. 若某页明显偏长，可到"切换"选项卡查看该页的自动换片时间，直接改成需要的秒数，不必重新排练整场。

排练计时的两个用途要分清：一是**自动放映**（展台、自助浏览必须用）；二是**时间管理**（汇报限时 15 分钟，排练一次即知哪几页该删）。需要注意的是，排练记录的是"顺序播放"的时间，若现场要临时跳页讲解，自动换片反而会打乱节奏，此时应改回手动换片。

## 四、导出为其他格式

入口集中在"文件 → 导出"，也可用"另存为"选择格式。

| 格式 | 路径 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| PDF | 文件 → 导出 → 输出为 PDF | 版式固定，字体不乱，不可编辑 | 定稿传阅、打印、存档 |
| 图片 | 文件 → 导出 → 输出为图片 | 每页一张 PNG/JPG，可选全部或当前页 | 微信推文配图、插入其他文档 |
| 视频 | 文件 → 导出 → 输出为视频 | 生成 mp4，可设每页停留时间与清晰度 | 展会循环播放、线上课程 |
| 放映格式 | 另存为 `.ppsx` | 双击直接全屏播放 | 只给看不给改 |
| 讲义 | 文件 → 打印 → 打印内容选"讲义" | 每页排 2/4/6 张幻灯片 | 现场发纸质提纲 |

导出 PDF 时注意两点：一是导出前删掉不想外传的备注页；二是导出后在另一台设备上打开检查，确认特殊字体已被嵌入、图片没有被压缩得发虚。导出图片默认按幻灯片原始尺寸输出，需要更高清晰度时应在导出选项中提高分辨率。

导出视频会把动画、切换、计时一并录进去，因此必须先用排练计时确定节奏，否则视频会以默认每页 5 秒播放，讲得快的页面显得拖沓。视频文件体积较大，用于展台播放时建议另存一份到本地硬盘，不要直接从 U 盘读取。

还有一处常被忽略：导出得到的 PDF 与图片都是"死"的，动画只剩首帧或末帧，分步出现的几行文字可能叠在一起。所以面向打印或推送的版本，应先把动画元素设为最终可见状态，或另存一份"全展开"的副本再导出，而不是直接拿放映版去导。

**例 3.6-1** 展会现场无人值守，要求自动循环播放一份 12 页产品介绍，每页停留约 8 秒，观众不能随意点击打乱。

**解**

1. 先按正常语速排练一遍：幻灯片放映 → 排练计时，逐页讲解后点"下一项"，结束时保留计时。
2. 到"切换"选项卡逐页核对自动换片时间，把偏短的页面改为 8 秒左右；也可选中全部幻灯片后统一设置。
3. 幻灯片放映 → 设置放映方式，放映类型选"在展台浏览（全屏）"，勾选"循环放映，按 Esc 键终止"，换片方式选"如果存在排练时间，则使用它"。
4. 检查首页是否有"点击开始"之类的提示文字，展台模式下无法点击，应删掉或改为自动播放。
5. 音视频若在首页，确认已设为自动播放；把放映所需字体、媒体文件与演示文稿放在同一文件夹。
6. 现场用 `F5` 试放一轮，确认循环衔接处不黑屏、不卡顿；结束测试按 `Esc`。

**例 3.6-2** 汇报结束后，需要把 30 页演示文稿发给客户（对方可能没有安装 WPS），并挑 4 页关键内容做成图片用于推文。

**解**

1. 文件 → 导出 → 输出为 PDF，范围选"全部幻灯片"，导出后在其他设备打开，检查字体与图片是否正常。
2. 若客户需要可编辑版本，另存为 `.pptx` 一并发送，并说明使用的字体，避免对方缺失字体后版式错位。
3. 导出图片：选中第 5 页，文件 → 导出 → 输出为图片，选择"当前幻灯片"与 PNG 格式，保存到指定文件夹。
4. 依次导出其余三页；若想一次导出全部，选"全部幻灯片"，事后再挑用。
5. 检查导出的 PNG 是否有透明区域、分辨率是否够推文使用，必要时提高导出分辨率后重导。
6. 发送前删除批注、清空不愿外传的备注，确认没有内部信息外泄。

- **易错点**：① 选了"在展台浏览"却没设自动换片时间，画面停在首页不动；② 排练计时保留后忘记把换片方式改为"使用排练时间"，仍要手动点击；③ 只发 `.pptx` 给没有相应字体的客户，导致文字换行、版面错乱，应同时提供 PDF。

## 本节小结

1. 三种放映类型：演讲者放映（全屏手控）、观众自行浏览（窗口）、在展台浏览（全屏自动），入口在幻灯片放映 → 设置放映方式。
2. `F5` 从头放映，`Shift+F5` 从当前页放映；页码加 `Enter` 可跳页，右键可黑屏、白屏、调画笔。
3. 排练计时记录每页用时，保留后需把换片方式设为"如果存在排练时间，则使用它"。
4. 自动换片时间也可在切换选项卡逐页微调，不必整场重排。
5. 导出常用 PDF（版式固定）、图片（每页一张）、视频（含动画与计时）、`.ppsx`（直接放映）。
6. 导出前清理备注与批注，导出后在另一台设备上验证字体与媒体。
