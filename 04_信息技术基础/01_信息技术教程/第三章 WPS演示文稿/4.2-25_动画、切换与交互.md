# 3.5 动画、切换与交互

> **考纲对应**：演示文稿制作 第 8 条——掌握幻灯片切换动画、对象动画的设置方法及超链接、动作按钮的应用方法（层次：掌握）
> **教材对应**：单元 3 · 任务 制作产品介绍演示文稿

动画的目的不是"动起来好看"，而是控制信息出现的**顺序与节奏**：让听众先看整体，再跟着讲解逐条深入。切换管"页与页之间"，动画管"页内元素"，超链接与动作按钮则让演示文稿从"线性播放"变成"可按需跳转"。三者常被混为一谈，考试也最爱在这里设陷阱。

## 一、幻灯片切换

切换是两页之间的过渡效果。选中幻灯片后，切换到"切换"选项卡，在效果库中选择即可，效果分细微、动态内容、华丽三类。

| 设置项 | 说明 | 建议 |
| --- | --- | --- |
| 效果 | 淡出、推进、擦除、分割等 | 商务场合选淡出、推进，全篇 1~2 种 |
| 效果选项 | 方向（从左、从右、向下等） | 与内容走向一致，如流程页用"推进" |
| 持续时间 | 过渡时长 | 0.5~1 秒，过长会拖慢节奏 |
| 声音 | 可加"单击""风铃"等 | 正式场合一般不加 |
| 换片方式 | 单击鼠标时 / 设置自动换片时间 | 有人讲用单击，展台用自动 |
| 应用到全部 | 一键套用到所有页面 | 统一风格时使用 |

要点：**"应用到全部"只作用于切换，不影响对象动画**；反过来，在某页设的换片时间只对该页有效，除非重新应用。

切换是"全局节奏"，不宜逐页换花样。整份文稿用同一种切换，听众不会注意它，注意力才留给内容；若每页都换一种效果，观看体验像幻灯片模板演示，反而削弱专业感。同一场合中，章节过渡页可以用稍明显的效果（如推进）以示分段，其余页面一律淡出。

## 二、对象动画

### 1. 四种类型

| 类型 | 作用 | 典型效果 | 用途 |
| --- | --- | --- | --- |
| 进入 | 元素从无到有 | 淡出、飞入、擦除、缩放 | 分步呈现要点 |
| 强调 | 元素已在页面上，吸引注意 | 脉冲、变色、放大 | 突出关键数据 |
| 退出 | 元素从有到无 | 淡出、飞出 | 替换旧内容 |
| 动作路径 | 沿指定轨迹移动 | 直线、弧形、自定义路径 | 演示运动、流程走向 |

### 2. 设置三要素

选中对象 → 动画选项卡 → 选择效果，随后必须确认三件事：

1. **开始方式**：单击时（讲者控制）、与上一动画同时（并行）、上一动画之后（自动接续）。三个以上元素按顺序出现时，"上一动画之后"最省操作。
2. **持续时间**：单个动画 0.3~0.8 秒较自然；与讲解配合的分步出现，宁快勿慢。
3. **延迟**：需要"停顿一下再出现"时填延迟，比手工掐时间可靠。

### 3. 效果选项与按段落发送

文本占位符的动画默认整段一起出现。若希望三条要点逐条显示，在"效果选项"中选"按段落"，一次设置即可，无须把每行拆成独立文本框。这也是"分步呈现"最规范的做法——结构仍是原来的占位符，便于后续统一改格式。

### 4. 动画窗格

动画 → 动画窗格，右侧列出本页所有动画，编号即播放顺序。可拖动条目调整先后，右键可"删除""效果选项""计时"。**同一页动画超过四个就该怀疑是否必要**：听众的注意力被反复牵动，反而记不住内容。

动画的验收标准是"不看屏幕也能跟上"：文字出现的位置应固定在它最终该在的地方，不要用大幅飞入把元素从画面外甩进来，长距离运动让人眼疲劳且容易错位。同一页内多个对象同时入场时，让它们"与上一动画同时"并统一时长，比依次排队更干净。检验方法只有一个：关掉讲解，自己安静地放一遍，若觉得某处"卡了一下"，那里就是节奏出了问题。

## 三、超链接

选中文字、图片或形状，插入 → 超链接（`Ctrl+K`），在对话框中选择链接目标：

- **本文档中的位置**：跳到指定幻灯片，用于目录页导航；
- **现有文件或网页**：打开外部文件或网址，放映时需联网或文件同路径；
- **电子邮件地址**：点击后唤起邮件客户端；
- **新建文档**：较少使用。

超链接的文字会变成主题强调色并带下划线，可用"开始 → 字体颜色"改色以融入版面，但保留可识别的提示（如加粗或加箭头）更符合可用性。取消链接：右键 → 取消超链接。

> **注意**：编辑状态下，普通单击只是选中对象，需按住 `Ctrl` 再单击才能测试跳转；只有在放映时才是"单击即跳"。

导航类链接要成体系：目录页每个条目都指向一页，每页都能回到目录，听众才不会"进去出不来"。链接目标若被删除或调整顺序，原有链接不会自动跟随，需重新指定，所以内容定稿之后再统一设置跳转更稳妥。

## 四、动作按钮

动作按钮是预设好交互的形状，常用于翻页与返回。插入 → 形状，在最下方的"动作按钮"组中选择：上一张、下一张、第一张、最后一张、开始、结束、自定义等。

插入时会自动弹出"动作设置"对话框：

1. **激活方式**："单击鼠标"或"鼠标移过"。正式场合一律用单击，移过容易误触连跳。
2. **动作**：超链接到"上一张幻灯片""下一张幻灯片""第一张幻灯片""最后一张幻灯片""结束放映"或指定幻灯片。
3. **播放声音**：一般留空。

按钮应统一尺寸、统一样式、统一位置（如右下角），并配上简短文字说明。由于按钮是形状，可复制粘贴到其他页面，保证一致性。

交互做完必须实测：从封面开始，按真实讲述顺序点完每一页，检查链接是否落错页、按钮是否遮挡内容、返回后能否继续。测试时用 `Shift+F5` 从当前页起放，比每次从第一页重放效率高得多。

**例 3.5-1** "三大核心优势"页中，标题与产品图先出现，三条优势随讲解逐条出现，讲完不再变化。

**解**

1. 选中标题与产品图，动画 → 进入 → 淡出，开始方式设为"与上一动画同时"，让页面开场干净利落。
2. 选中放有三条优势的正文占位符，动画 → 进入 → 擦除，效果选项方向选"自左侧"。
3. 在"效果选项 → 序列"中选择"按段落"，三条要点即按段落依次出现。
4. 打开动画窗格，确认三条的编号连续，开始方式统一为"单击时"（或第一条"单击时"、后两条"上一动画之后"并设 0.3 秒延迟）。
5. 持续时间统一设为 0.5 秒；点"播放"预览，节奏过快就加延迟，不要加时长。
6. `F5` 从当前页放映，按讲解速度点击，确认三条出现时机与话术对得上。

**例 3.5-2** 目录页列出六个章节，要求点击条目直接跳到对应页；各内容页右下角放"返回目录"按钮。

**解**

1. 在目录页选中"产品参数"文字，`Ctrl+K` 打开超链接，左侧选"本文档中的位置"，右侧选中第 6 页，确定。
2. 其余五个条目同样处理，逐条对应目标页；完成后按住 `Ctrl` 逐个单击测试，确认都能跳到位。
3. 切到第 6 页，插入 → 形状 → 动作按钮 → 自定义，在右下角拖出小按钮。
4. 弹出的动作设置中选"单击鼠标"，动作选"超链接到 → 幻灯片"，指定目录页，确定。
5. 右键按钮 → 添加文字，输入"返回目录"，字号 12 磅、白色；调整填充与轮廓，使其不抢画面。
6. 复制该按钮，粘贴到其余内容页的同一位置（粘贴后位置一致，无须逐页对齐）。
7. 从第一页起完整放映一遍，检查每个链接与按钮的落点是否正确、返回后是否停在目录页。

- **易错点**：① 把"切换"当成"动画"设置，结果整页一起动，无法分步；② 文本动画不做"按段落"，只能整块出现，只好拆成多个文本框，后期改格式极麻烦；③ 动作按钮设为"鼠标移过"，鼠标划过就连跳几页。

## 本节小结

1. 切换作用于页与页之间，动画作用于页内对象；"应用到全部"只管切换。
2. 动画四类型：进入、强调、退出、动作路径。
3. 三个必设项：开始方式（单击/同时/之后）、持续时间、延迟。
4. 文本逐条出现用"效果选项 → 按段落"，不要拆成多个文本框。
5. 超链接用 `Ctrl+K`，可跳本文档位置、文件网页、邮件地址；编辑时需 `Ctrl+` 单击测试。
6. 动作按钮用于翻页与返回，激活方式选"单击鼠标"，并保持位置与样式统一。

A. 切换效果作用于幻灯片之间，对象动画作用于页内元素
B. 动画的开始方式有单击时、与上一动画同时、上一动画之后
C. 动作按钮可设置为跳转到指定幻灯片或结束放映

### 参考答案

1. **B**。按段落发送既实现逐条出现，又保留占位符结构。
2. **B**。`Ctrl+K` 打开超链接对话框。
3. **C**。"上一动画之后"无需点击即自动接续。
4. **B**。切换选项卡中的"应用到全部"。
5. **错**。编辑时需按住 `Ctrl` 再单击，放映时才是单击即跳。
6. 动画。
7. 鼠标移过。
8. **ABC**。D 错："应用到全部"只作用于切换效果，不会复制对象动画。
