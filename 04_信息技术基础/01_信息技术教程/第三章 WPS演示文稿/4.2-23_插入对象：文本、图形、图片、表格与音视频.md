# 3.3 插入对象：文本、图形、图片、表格与音视频

> **考纲对应**：演示文稿制作 第 6 条——掌握在幻灯片中插入文本框、图形、图片、表格、音频、视频等各类对象的方法（层次：掌握）
> **教材对应**：单元 3 · 任务 制作产品介绍演示文稿

幻灯片的说服力来自"看得见"的证据：一张实拍图胜过三段形容词，一个表格能让参数一目了然，一段短视频能展示产品运转。本节按对象类型逐一说明插入路径与常用设置，重点解决"插进去容易、摆好看难"的问题。

## 一、文本框

插入 → 文本框，可选"横排文本框"与"竖排文本框"，然后在页面上拖出矩形即可输入。

- 文本框与占位符不同：占位符来自版式，继承母版格式；文本框是手画的独立对象，不随版式变化。正文内容优先填占位符，只有标签、注释这类零散文字才用文本框。
- 文字放不下时会溢出边框，可用"文本工具 → 自动调整"选择"溢出时缩排文字"或"调整形状以适应文字"。前者会缩小字号，后者会改变框的大小，两者都可能打乱对齐，根本办法还是精简文字。
- 文本框默认有内边距，文字看起来"没对齐"往往是内边距在作怪。在"设置形状格式 → 文本选项"中把上下左右边距调为 0，文字才能与参考线严丝合缝。

## 二、形状与智能图形

### 1. 形状

插入 → 形状，分组提供线条、矩形、基本形状、箭头、流程图符号、标注等。按住 `Shift` 拖动，可画正方形、正圆与水平/垂直线；按住 `Ctrl` 从中心向外画。

选中形状后出现"绘图工具"选项卡：填充（纯色、渐变、图片）、轮廓（颜色、粗细、虚实）、效果（阴影、映像、发光）。多个形状要表达流程时，用"对齐"和"分布"摆整齐，再"组合"成一个整体。

### 2. 智能图形

插入 → 智能图形（即 SmartArt），提供列表、流程、循环、层次结构、关系、矩阵、图片等类型。它把"图形 + 文字"整合成可整体换版式的结构：在文本窗格中按 `Enter` 增加同级、按 `Tab` 降级，图形自动增删，比手工拼形状省力，也更整齐。

## 三、图片

插入 → 图片 → 本地图片，选中文件插入；也可用"截图"直接截取屏幕区域。插入后"图片工具"提供以下常用命令：

| 命令 | 作用 | 使用场景 |
| --- | --- | --- |
| 裁剪 | 拖动裁剪柄，或"裁剪为形状""按比例裁剪" | 统一多图比例、去掉多余背景 |
| 删除背景 | 自动识别主体，用"标记要保留/删除的区域"微调 | 产品去底、人物抠图 |
| 图片样式 | 一键加边框、阴影、映像、柔化边缘 | 快速统一观感 |
| 压缩图片 | 按用途降低分辨率 | 文件过大、发送受限 |
| 重设图片 | 撤销全部裁剪与效果，回到原图 | 改坏了想重来 |

关键一条：**等比缩放**。拖动四角控制柄可保持比例，拖动边中控制柄会单向拉伸导致变形；确需固定宽高时，右键"设置对象格式"中同时输入宽和高，并保证与原图比例一致。

## 四、表格与图表

### 1. 表格

插入 → 表格，选择行列数后生成。"表格工具"中可插入/删除行列、合并与拆分单元格、调整行高列宽、套用表格样式、设置边框与底纹。表格内的文字用单元格对齐方式控制，不要用空格顶位置。

幻灯片上的表格宜"少而精"：列数控制在 5 列以内，行数不超过 8 行，单位写在表头而非每个单元格。数据量大的表格应截取关键几行，或改为图表。

表格常见的两个毛病：一是默认样式带深色表头与粗边框，与整份文稿的浅色主题冲突，应在"表格样式"中换成简洁样式并调细框线；二是行高不一致，因为单元格里换行数不同，可选中整表后用"平均分布各行"统一。

### 2. 图表

插入 → 图表，选择柱形图、折线图、饼图等类型，在弹出的数据表中替换示例数据即可生成。图表与数据表联动，改数据图就变；类型不合适可在"图表工具 → 更改类型"中更换。饼图类别不宜超过 6 项，折线图适合表现趋势，柱形图适合比较大小。

## 五、音频与视频

### 1. 插入音频

插入 → 音频 → 插入音频，选本地音频文件，页面上出现喇叭图标。选中图标后"音频工具"可设置：

- **跨幻灯片播放**：从当前页开始，翻页后音乐继续，适合做全场背景音乐；
- **循环播放直到停止**：配合跨页播放，音乐不会中途断掉；
- **放映时隐藏**：喇叭图标不显示，避免遮挡画面；
- **淡入/淡出**、**裁剪音频**：控制起止与衔接。

### 2. 插入视频

插入 → 视频，可选本地视频或在线视频。插入后"视频工具"可设置"自动播放"或"单击播放"、"全屏播放"、"循环播放"，也可裁剪起止点、指定封面帧。

需要注意：用"链接到文件"方式插入的媒体，文件一旦移动位置就会失效；"嵌入"方式会把媒体保存进演示文稿内部，文件体积变大但便于拷贝。交付前务必在目标电脑上试放，确认解码正常。

## 六、对象的选择、对齐与层次

| 需求 | 操作 |
| --- | --- |
| 选中被遮挡的对象 | 开始 → 选择 → 选择窗格，按名称点选 |
| 对齐多个对象 | 选中后 开始 → 排列 → 对齐（左对齐、居中、顶端对齐等） |
| 等间距排列 | 排列 → 对齐 → 横向/纵向分布 |
| 叠放次序 | 右键 → 置于顶层/上移一层/下移一层/置于底层 |
| 合并为一个对象 | 选中后右键 → 组合，或 `Ctrl+G` |
| 旋转 | 拖动对象上方旋转柄，或在"设置对象格式"中填角度 |

排版的顺序建议是"先底层、后上层"：先摆背景与大图，再放说明文字，最后加标注箭头。这样做的好处是后来的对象自动压在上层，不必反复调整叠放次序。若页面元素超过十个，用选择窗格重命名（如"图-正面""文-卖点"），后续修改时不必靠猜。

**例 3.3-1** 制作"产品外观"页：左侧放产品图，右侧列三条卖点，要求图片去底、比例统一，文字与图片顶端对齐。

**解**

1. 插入 → 图片 → 本地图片，选产品实拍图；拖动四角控制柄缩放到合适大小，避免拉伸。
2. 图片工具 → 删除背景，用"标记要保留的区域"补上被误删的边角，"保留更改"完成去底。
3. 若图片比例与版面不符，用"裁剪 → 按比例"统一为 1:1，再拖动裁剪框取舍构图。
4. 右侧用"标题和内容"版式的正文占位符输入三条卖点，字号 22 磅，行距 1.3 倍。
5. 同时选中图片与占位符，开始 → 排列 → 对齐 → 顶端对齐；需要精确定位时用方向键微调（按住 `Ctrl` 移动步长更小）。
6. `F5` 试放，检查去底边缘是否有白边，必要时给图片加 2 磅浅灰轮廓线收边。

**例 3.3-2** 首页需要一段 30 秒产品视频自动播放，并配轻柔背景音乐贯穿全场，但图标不能出现在画面上。

**解**

1. 插入 → 视频 → 本地视频，选中文件插入；拖动视频框到画面中央并调整大小。
2. 视频工具 → 开始方式选"自动"，勾选"全屏播放"；用"裁剪视频"去掉片头空白。
3. 插入 → 音频 → 插入音频，选背景音乐文件；音频工具中勾选"跨幻灯片播放""循环播放直到停止""放映时隐藏"。
4. 若音乐盖住视频原声，选中音频，在"音量"中调低，或对视频设置"淡入淡出"。
5. 在"动画窗格"中确认自动播放的项目排在首页最前，避免视频先于页面元素出现。
6. 拷贝到另一台电脑上试放一次，确认音视频都能正常解码，再定稿。

- **易错点**：① 拖动图片边中控制柄造成拉伸变形，应拖四角等比缩放；② 音频默认只在本页播放，翻页即停，需勾选"跨幻灯片播放"；③ 用链接方式插入的视频换机后找不到源文件，交付应改用嵌入或随文件一同拷贝。

## 本节小结

1. 文本框用于零散文字，正文优先用版式占位符；边距归零才能与参考线对齐。
2. `Shift` 画正圆正方形，`Ctrl` 从中心绘制；形状可填充、描边、加效果并组合。
3. 智能图形把图形与文字绑定，增删条目自动排版。
4. 图片四角缩放保持比例，裁剪、删除背景、压缩、重设是四个高频命令。
5. 表格控制在 5 列 8 行内，图表与数据联动、可随时更换类型。
6. 音频要"跨幻灯片播放 + 放映时隐藏"，视频注意播放方式与嵌入/链接的区别。

### 参考答案

4. **B**。`Shift` 约束为正方形、正圆与水平垂直方向。
5. **错**。默认只在本页播放，需手动勾选"跨幻灯片播放"。
6. 组合。
7. 删除背景。
8. **ABC**。D 错：拖动边中控制柄会单向拉伸，导致图片变形。
