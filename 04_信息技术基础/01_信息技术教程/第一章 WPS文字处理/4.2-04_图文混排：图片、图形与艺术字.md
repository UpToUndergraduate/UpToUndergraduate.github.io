# 1.4 图文混排：图片、图形与艺术字

> **考纲对应**：文档处理 第 3 条——掌握图片、图形、艺术字等对象的插入、编辑和美化（层次：掌握）
> **教材对应**：单元 1 · 任务 1.2 编制产品说明书

插图不难，难在让图**听话地待在该待的位置**。这一节的考点集中在两处：对象是"嵌入型"还是"浮动型"，以及浮动对象锚定在哪个段落。

## 一、图片

### 1. 插入途径

"插入 → 图片 → 本地图片"选择文件；也可直接复制粘贴或拖入。插入后功能区出现"图片工具"上下文选项卡。

### 2. 图片的编辑与美化

- **大小**：拖动四周控制点缩放；按住 `Shift` 拖角点可按比例缩放，按住 `Ctrl` 以中心为基点缩放。在"图片工具 → 大小"中可精确输入高宽。
- **裁剪**：图片工具 → 裁剪，可裁掉多余边缘；"裁剪为形状"可把图片裁成圆形、圆角矩形等。
- **调整**：亮度、对比度、饱和度、色调，以及"设置透明色"（把某一种颜色变透明，适合去白底）。
- **样式**：一键套用边框、阴影、柔化边缘、三维旋转等预设。

### 3. 文字环绕方式（核心考点）

| 类别 | 环绕方式 | 特点 |
| --- | --- | --- |
| 嵌入型 | 嵌入型 | 对象被当作**一个字符**，随文字移动，不能拖到文字旁边 |
| 浮动型 | 四周型 | 文字沿对象**矩形边框**环绕 |
| | 紧密型 | 文字沿对象**实际轮廓**环绕 |
| | 穿越型 | 文字可进入对象轮廓内部的空白处 |
| | 上下型 | 文字只在对象上下排列，左右留空 |
| 衬于/浮于 | 衬于文字下方 | 对象在下层，可作背景、水印，不遮挡文字 |
| | 浮于文字上方 | 对象在上层，会遮挡文字 |

**判断口诀**：能拖动到文字中间的，一定是浮动型；怎么拖都只能整行移动的，是嵌入型。

### 4. 锚点

浮动对象**锚定在某个段落**上。打开"显示编辑标记"后可见锚形符号，它标出对象依附的段落。锚定段落移动或被删除，对象会随之移动或消失——这是"图突然跑到别的页"的常见原因。

## 二、形状

1. "插入 → 形状"选择线条、矩形、箭头、流程图符号等。按住 `Shift` 绘制可得到正圆、正方形与水平/垂直线。
2. 形状上可直接键入文字（右键"添加文字"），文字随形状移动。
3. 多个形状可**组合**成一个整体（选中后右键 → 组合），统一设置大小、环绕与位置；也可设置"叠放次序"决定谁在上层。
4. 形状默认填充蓝色、带轮廓线，可在"绘图工具"中改填充、轮廓、效果。

## 三、艺术字

艺术字是**带装饰效果的文字对象**，本质仍是文字，可继续编辑内容。

- 插入：插入 → 艺术字，选择样式后输入文字。
- 可设置填充（渐变、图片）、轮廓、阴影、映像、发光、三维旋转。
- 适合做标题；正文中大量使用会降低可读性。
- 艺术字默认是浮动对象，需要与文字混排时同样要设环绕方式。

**例 1.4-1** 在产品说明书中插入一张产品照片：要求图片位于页面右侧、文字环绕在图片左边，且插入或删除上方段落时图片不跑位。

**解**

1. 光标定位在要插图的位置，"插入 → 图片 → 本地图片"，选中照片插入。
2. 选中图片，"图片工具 → 环绕"，选**四周型**。此时图片由嵌入型变为浮动对象，可自由拖动。
3. 把图片拖到页面右侧，拖动角点（按住 `Shift`）调整到合适大小。
4. 观察锚点符号：若锚在上方某段，把锚点拖到"产品参数"这一段上，图片即随该段移动，正文增删时不会乱跑。
5. 若希望文字紧贴产品轮廓，可改用**紧密型**；若只想图独占一行，用**上下型**。

**例 1.4-2** 说明书封面要有一个弧形渐变效果的标题"智能音箱 X1"。

**解**

1. 不要用文本框加渐变填充后再调文字——虽然可行，但文字与框体绑定，改字麻烦。
2. 用"插入 → 艺术字"，输入"智能音箱 X1"。
3. 在"文本工具"中选择渐变填充并调整方向；再设置"转换 → 跟随路径"中的弧形，文字即沿弧线排列。
4. 调整艺术字的环绕方式为"浮于文字上方"，拖到封面居中位置。

- **易错点**：①图片插进来后怎么拖都只能整行移动——因为它还是嵌入型，需先改环绕方式；②用空格和回车"推"图片到指定位置，段落一改就全乱；③误删锚点所在段落，导致图片一起消失；④把艺术字当图片处理，想改字时发现改不了（应双击进入文字编辑）。

## 本节小结

1. 图片默认以嵌入型插入，被视为一个字符随文字流动；改为四周型、紧密型、穿越型、上下型后才成为浮动对象。
2. 四周型沿矩形边框环绕，紧密型沿实际轮廓环绕；衬于文字下方可作背景，浮于文字上方会遮挡文字。
3. 浮动对象锚定在某个段落，锚点移动对象即移动，锚点段落被删对象随之消失。
4. 形状按住 `Shift` 可画正圆、正方形与直线；多个形状可组合后统一设置。
5. 艺术字是带装饰效果的文字对象，可设渐变、轮廓、阴影与路径变形，本质仍是文字。

## 自测题

1.（单选）图片以"嵌入型"插入后，下列描述正确的是（　）。
A. 可任意拖到文字上方　B. 作为字符嵌入文本行、随文字移动　C. 自动成为背景　D. 不能调整大小

2.（单选）要让文字环绕在产品图片的不规则轮廓周围，应选用（　）。
A. 嵌入型　B. 四周型　C. 紧密型　D. 上下型

3.（单选）要让标题呈现弧形渐变效果，应插入（　）。
A. 文本框　B. 艺术字　C. 图片　D. 形状

4.（判断）"衬于文字下方"的图片会遮挡正文文字。（　）

5.（判断）绘制形状时按住 `Shift` 拖动可画出正圆或正方形。（　）

6.（填空）浮动图片锚定在某个段落，该位置用"________"符号标记，打开编辑标记可见。

7.（简答）比较"四周型"与"衬于文字下方"两种环绕方式的适用场合。

8.（多选）关于图片、形状与艺术字，下列说法正确的有（　）。
A. 图片默认以"嵌入型"插入，被当作一个字符随文字流动
B. "紧密型"环绕沿图片实际轮廓排列文字
C. 多个形状可以先组合成一个整体，再统一设置环绕方式
D. 按住 `Ctrl` 拖动绘制矩形，可直接得到正方形

### 参考答案

1. **B**。嵌入型把图片当作字符处理，随文字移动，不能浮动。
2. **C**。紧密型沿实际轮廓环绕；四周型沿矩形边框环绕。
3. **B**。艺术字是带装饰效果的文字对象，题干问"弧形渐变"即文字特效。
4. **错**。"衬于文字下方"的图片在文字下层，不遮挡文字；"浮于文字上方"才会遮挡。
5. **对**。`Shift` 约束为正圆、正方形与水平/垂直线。
6. 锚点（⚓）。
7. 四周型使文字环绕在图片矩形边框四周，适合普通配图，图文互不遮挡；衬于文字下方把图片置于文字下层作为背景或水印，文字显示在其上，适合底图与装饰性背景，但需注意对比度以免影响阅读。
8. **ABC**。D 错：约束为正方形、正圆的是 `Shift` 键，`Ctrl` 用于以中心为基点绘制。
