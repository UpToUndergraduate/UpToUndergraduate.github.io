# 1.5 表格：创建、编辑、美化与公式

> **考纲对应**：文档处理 第 4 条——掌握在文档中插入和编辑表格、对表格进行美化、灵活应用公式对表格中数据进行处理（层次：掌握）
> **教材对应**：单元 1 · 任务 1.2 产品说明书、任务 1.3 图书订购单

文档表格与电子表格不同：它服务于**版面上的排列**，公式能力有限但足够做小计与合计。本节的重点在"结构调整"和"公式的方向引用"。

## 一、创建表格

| 方式 | 操作 | 适用 |
| --- | --- | --- |
| 网格插入 | 插入 → 表格，在网格上拖动选行列 | 行列较少、尺寸规整 |
| 对话框插入 | 插入 → 表格 → 插入表格，输入行列数 | 行列较多或需精确 |
| 绘制表格 | 插入 → 表格 → 绘制表格，手工画边框 | 不规则表格（如带斜线表头） |
| 文本转换 | 选中已用分隔符分列的文本 → 插入 → 表格 → 文本转换成表格 | 已有成段数据 |

光标进入表格后，功能区出现"表格工具"，含"设计"（样式、边框、底纹）与"布局"（行列增删、合并拆分、对齐、公式）两组命令。

## 二、编辑表格

### 1. 选择

| 目标 | 操作 |
| --- | --- |
| 整个表格 | 单击表格左上角的十字移动柄 |
| 一行/一列 | 光标置于该行/列，布局 → 选择 → 选择行/列 |
| 一个单元格 | 三击单元格内文字，或用布局 → 选择 → 选择单元格 |
| 连续区域 | 从起点拖到终点 |

### 2. 行列与单元格的增删

- 插入：光标定位后，布局 → 在上方/下方插入行、在左侧/右侧插入列。
- 删除：布局 → 删除 → 删除行/列/单元格/表格。
- **合并单元格**：选中多个单元格 → 布局 → 合并单元格。合并后**只保留左上角单元格的内容**，其余内容丢失。
- **拆分单元格**：布局 → 拆分单元格，指定拆成几行几列。

### 3. 行高与列宽

拖动边框线可粗略调整；要精确设置，用"布局 → 单元格大小"输入数值，或右键"表格属性"统一设置。勾选"允许调整单元格间距"可做出分隔效果。

## 三、美化表格

1. **表格样式**：设计 → 表格样式，一键套用带表头、隔行底纹的配色方案，省去逐格设格式。
2. **边框与底纹**：可自定义线型、粗细、颜色，做三线表时把外框设为粗线、内线设为细线或去掉竖线。
3. **单元格对齐**：布局中提供 9 种对齐（靠上/居中/靠下 × 左/中/右），表格内容常用"水平居中 + 垂直居中"。
4. **文字环绕**：右键 → 表格属性 → 环绕，可让正文绕表格排版。
5. **重复标题行**：长表跨页时，选中首行 → 布局 → 重复标题行，每页顶端都会出现表头。

## 四、公式与计算

### 1. 公式的写法

光标置于要放结果的单元格，"布局 → 公式"，在公式框中输入。规则：

- 必须以英文 `=` 开头（对话框内通常已预填）。
- 单元格用 `A1` 式地址：**列用字母、行用数字**，左上角为 `A1`。
- 可用方向词代替地址：`ABOVE` 表示当前格上方的连续数据区，`LEFT` 表示左侧连续数据区，`RIGHT`、`BELOW` 同理。

### 2. 常用函数与编号格式

| 函数 | 作用 | 示例 |
| --- | --- | --- |
| `SUM` | 求和 | `=SUM(ABOVE)` 对本列上方数据求和 |
| `AVERAGE` | 平均值 | `=AVERAGE(LEFT)` |
| `COUNT` | 计数 | `=COUNT(ABOVE)` |
| `MAX`/`MIN` | 最大/最小值 | `=MAX(ABOVE)` |

"编号格式"决定结果显示方式：`0.00` 保留两位小数、`#,##0.00` 加千位分隔符、`0%` 显示为百分比。

### 3. 更新的方式

表格中的公式结果是**域**，修改被引用的数据后**不会自动重算**。需选中结果按 `F9`，或右键"更新域"。这是本节最容易失分的一点。

**例 1.5-1** 制作"图书订购单"：表头为"序号、书名、单价（元）、数量、小计（元）"，共 6 行数据；第一行跨列作为标题"图书订购单"，最后一行为"合计"，跨前四列、最后一格填总金额。

**解**

1. 插入 8 行 5 列的表格（1 行大标题 + 1 行表头 + 6 行数据，合计行在数据之后另加）。
2. 选中第一行 5 个单元格，布局 → 合并单元格，输入"图书订购单"，设为居中、加粗。
3. 第二行依次填入"序号、书名、单价（元）、数量、小计（元）"。
4. 逐行录入 6 条数据；"小计"列放光标，布局 → 公式，输入 `=C3*D3`（按实际行列调整），确定。
5. 最后一行：选中前 4 格合并，输入"合计"并右对齐；末格用 `=SUM(ABOVE)` 求小计列总和。
6. 选中表头行 → 布局 → 重复标题行（若表格会跨页）。
7. 设计 → 表格样式选一种带表头底纹的样式，或手工设外框粗线、内线细线。

**例 1.5-2** 订购单中单价列有两处录错，改正后要求小计与合计同步更新。

**解**

1. 修改单价单元格的数值。
2. 选中"小计"列中受影响的公式结果，按 `F9` 更新域；或全选表格后按 `F9`。
3. 再选中"合计"格按 `F9`，合计随小计变化。
4. 若更新后数值未变，检查该格是否被手工输入成了普通数字（不再是域），需重新插入公式。

- **易错点**：①合并单元格后以为内容都保留，实际只留左上角；②用 `SUM(LEFT)` 时左侧存在空列，导致求和范围被截断；③改了数据不按 `F9`，结果永远是旧值；④用连续回车把表格挤到下一页，而不是设置"允许跨页断行"或调整行高。

## 本节小结

1. 创建表格有网格插入、对话框插入、绘制表格、文本转换四种方式；光标入表后出现"表格工具"。
2. 合并单元格只保留左上角内容；拆分会把内容分配到左上区域。
3. 美化包括表格样式、边框底纹、9 种单元格对齐、文字环绕；长表跨页用"重复标题行"。
4. 公式以 `=` 开头，用 `ABOVE`/`LEFT` 等方向词或 `A1` 式地址；函数有 `SUM`、`AVERAGE`、`COUNT`、`MAX`、`MIN`；编号格式可设 `0.00`。
5. 公式结果是域，改数据后须按 `F9` 更新，不会自动重算。

## 自测题

1.（单选）要求某单元格对其左侧所有数值求和，应输入（　）。
A. `=SUM(ABOVE)`　B. `=SUM(LEFT)`　C. `=AVERAGE(LEFT)`　D. `SUM(LEFT)`

2.（单选）合并单元格后，单元格中的内容会（　）。
A. 全部丢失　B. 只保留左上角单元格内容　C. 只保留右下角内容　D. 按字符数平均分配

3.（单选）表格中第一行第一列单元格的地址是（　）。
A. `A1`　B. `1A`　C. `A0`　D. `11`

4.（判断）修改表格数据后，公式计算的结果会自动立即更新。（　）

5.（判断）"文本转换成表格"时，分隔符必须统一，否则可能转换失败。（　）

6.（填空）表格中公式必须以"________"开头；修改数据后按 ________ 键可更新公式结果。

7.（填空）长表格跨页时，为让每页都显示表头，应使用"表格工具 → 布局 → ________"命令。

8.（多选）关于 WPS 文字中的表格，下列说法正确的有（　）。
A. 合并单元格后只保留左上角单元格的内容
B. 表格公式以 `=` 开头，可用 `LEFT`、`ABOVE` 等方向词引用区域
C. 修改表格数据后，公式结果会自动重算
D. "文本转换成表格"要求各行使用的分隔符一致

### 参考答案

1. **B**。`LEFT` 表示当前格左侧的连续数据区；D 项缺少 `=`，写法错误。
2. **B**。合并后仅保留左上角内容，其余内容被丢弃。
3. **A**。列标用字母、行号用数字，左上角即 `A1`。
4. **错**。公式结果是域，需按 `F9` 或右键"更新域"才刷新。
5. **对**。分隔符不统一（如中英文逗号混用）会导致列数错乱或转换失败。
6. `=`（等号）；`F9`。
7. 重复标题行。
8. **ABD**。C 错：表格公式不会自动重算，须手动更新域。
