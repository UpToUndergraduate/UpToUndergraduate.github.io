# 1.6 页面布局：页面设置、分页分节与页眉页脚

> **考纲对应**：文档处理 第 5 条——熟悉分页符和分节符的插入，掌握页眉、页脚、页码的插入和编辑；第 7 条——掌握页面设置操作（层次：掌握）
> **教材对应**：单元 1 · 任务 1.2 产品说明书、任务 1.4 毕业论文编辑排版

一份文档如果从头到尾只有一种版式，事情很简单；一旦出现"封面无页码、摘要用罗马数字、正文从 1 开始、中间还要横排一页宽表"，就必须靠**分节**。本节的主线就是：分节决定版式边界，页眉页脚和页码在节内生效。

## 一、页面设置

"页面布局"选项卡提供以下项：

| 项目 | 内容 |
| --- | --- |
| 页边距 | 上、下、左、右，以及装订线位置与宽度 |
| 纸张方向 | 纵向 / 横向 |
| 纸张大小 | A4、A3、B5、16 开等，也可自定义宽高 |
| 版式 | 节的起始位置、页眉页脚距边界距离、垂直对齐方式 |
| 文档网格 | 每页行数、每行字符数，决定"行距受网格控制"的基准 |

页面设置的作用范围可在对话框底部选择"整篇文档"或"插入点之后"。选"插入点之后"会自动插入一个分节符。

## 二、分页符与分节符

### 1. 分页符

- 插入：插入 → 分页符，或按 `Ctrl+Enter`。
- 作用：**只强制换页**，不改变任何版式。换页后的内容仍属原来的节，页眉页脚、纸张方向都不变。
- 显示：普通视图下为一条虚线并标"分页符"。

### 2. 分节符

| 类型 | 效果 |
| --- | --- |
| 下一页 | 新节从**下一页**开始 |
| 连续 | 新节从**当前位置**开始，不另起页 |
| 偶数页 | 新节从下一个**偶数页**开始 |
| 奇数页 | 新节从下一个**奇数页**开始 |

分节符的意义在于：**节是版式的独立单位**。页边距、纸张方向、页眉页脚、页码格式、分栏都以节为作用范围。

> **易错点**：删除分节符会把后一节并入前一节，后面的版式（含页眉页脚）会立刻变成前一节的样式。要删就先确认版式能接受这个后果。

## 三、页眉与页脚

### 1. 进入编辑

双击页面顶端或底端的空白区即可进入页眉页脚编辑状态，此时正文变灰；按 `Esc` 或双击正文区退出。也可用"插入 → 页眉和页脚"。

### 2. 节之间的继承关系

- 新建的节默认**链接到前一节**，页眉页脚与前节相同。
- 要让本节独立设置，必须先**取消"链接到前一节"**（在页眉页脚工具中点击该按钮），否则改了本节、前节也跟着变。
- "首页不同"：本节第一页不显示页眉页脚，常用于封面。
- "奇偶页不同"：左右页分别设置，用于双面打印的书籍。

### 3. 可放置的内容

页眉页脚中可插入页码、日期时间、文件名、图片（如公司标志）。这些多为**域**，会随文档变化自动更新。

## 四、页码

1. 插入 → 页码，选择位置（页面顶端/底端）与对齐方式。
2. "设置页码格式"中可选编号格式（阿拉伯数字、罗马数字、中文数字等），并指定"起始页码"或"续前节"。
3. "第 X 页 共 Y 页"的写法：X 用 `PAGE` 域（当前页码），Y 用 `NUMPAGES` 域（文档总页数），通过"插入 → 域"分别插入。

**例 1.6-1** 毕业论文结构为：封面 → 中文摘要 → 正文 → 参考文献。要求封面无页眉页脚；摘要与正文分别设置不同页码格式；正文中有一张宽表需要横向页面。

**解**

1. 在封面末尾插入"下一页分节符"（页面布局 → 分隔符 → 下一页），摘要末尾、正文末尾同理，共得四个节。
2. 双击摘要页的页眉，取消"链接到前一节"，输入"摘要"；封面节保持页眉空白。
3. 双击正文页的页眉，同样取消链接，输入论文题目。
4. 页码：摘要节插入页码，设编号格式为罗马数字、起始页码 1；正文节插入页码，设阿拉伯数字、起始页码 1、选择"续前节"以外的"起始页码"。
5. 正文中宽表所在位置前后各插入一次"下一页分节符"，把该节纸张方向改为**横向**，表格排版完毕后再切回纵向。
6. 横向节若不想显示页眉，可取消其"链接到前一节"后清空页眉内容。

**例 1.6-2** 上例中，摘要页要显示"i、ii"这样的页码，正文从 1 开始重新编号，封面不显示任何页码。

**解**

1. 封面节：插入页码后直接删除该节的页码域，或勾选"首页不同"使封面不显示。
2. 摘要节：取消链接到前一节，插入页码 → 设置页码格式 → 编号格式选小写罗马数字，起始页码设 1。
3. 正文节：取消链接到前一节，设置页码格式 → 编号格式选阿拉伯数字 → 起始页码选"起始页码"并填 1。
4. 逐页核对：封面无页码，摘要为 i、ii，正文首章为 1。

- **易错点**：①用连续回车把摘要挤到下一页，导致正文版式全部错位；②没取消"链接到前一节"就改页眉，结果全文页眉一起变；③页码从 1 重新编号时选了"续前节"，导致页码接着摘要往下数；④删除分节符后版式串节。

## 本节小结

1. 页面设置含页边距、纸张方向与大小、版式、文档网格；作用范围可选整篇文档或插入点之后。
2. 分页符（`Ctrl+Enter`）只换页不改版式；分节符产生新节，节是页边距、纸张方向、页眉页脚、页码、分栏的独立单位。
3. 分节符有下一页、连续、偶数页、奇数页四种；删除分节符会让后节并入前节。
4. 页眉页脚双击进入编辑；新节默认"链接到前一节"，要独立设置必须先取消链接。
5. 页码是域，可设编号格式与起始页码；"第 X 页 共 Y 页"分别用 `PAGE` 与 `NUMPAGES` 域。

7.（填空）设置页码时可选择"续前节"或指定"________"，以决定新节的页码从几开始。

8.（简答）比较分页符与分节符的区别，并说明毕业论文为何要用分节符。

9.（多选）关于分页符、分节符与页眉页脚，下列说法正确的有（　）。
A. 分节符可使不同节拥有不同的纸张方向
B. 分页符也会产生新节，因此可单独设置该页页眉
C. 取消"链接到前一节"后，本节页眉即可单独设置
D. 删除分节符后，其后的内容会改用前一节的版式

### 参考答案

1. **B**。只有分节符能让不同节拥有独立版式，分页符不能。
2. **A**。分页符（`Ctrl+Enter`）只强制换页，不产生新节。
3. **C**。`NUMPAGES` 为文档总页数，`PAGE` 为当前页码。
4. **对**。节之间默认链接，取消链接后才能独立设置。
5. **错**。删除分节符会合并前后两节，后者改用前节的版式。
6. `Ctrl+Enter`；连续。
7. 起始页码。
8. 分页符仅强制换页，不改变页边距、纸张方向、页眉页脚、页码与分栏；分节符产生新节，各节可独立设置上述版式。毕业论文的封面、摘要、正文需要不同页码格式（如摘要用罗马数字、正文从 1 开始）、不同页眉（封面不显示），宽表还需横向页面，这些都要靠分节符隔离，分页符无法实现。
9. **ACD**。B 错：分页符只强制换页，不产生新节，版式与页眉仍随所属节。
