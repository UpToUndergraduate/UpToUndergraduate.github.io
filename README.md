# Up To Undergraduate (UTU) · 升本之路

福建省普通高校专升本考试理工科四门公共课/专业基础课，**一站式服务**。

此外，针对英语词汇，我们还提供了一个单独的站点：[Vocabulary · 英语词汇 3000 背词工具](https://uptoundergraduate.github.io/Vocabulary/)。

## 高等数学

站点层级：**主栏 → 高等数学 → 高数教程**。

- **考纲原文**：[3.1 高等数学考试说明](03_高等数学/3.1-01_考纲原文.md)
- **高数教程**：6 章 35 节，另有 1 节导学，共 36 篇。每节独立成篇，例题随概念穿插，重点讲清“为什么”与“怎么用”。

建议从 [0.1 考纲解读与学习路线](03_高等数学/3.2-01_考纲解读与学习路线.md) 开始，先看分值地图与全书结构，再按章节推进：

1. **函数、极限与连续**（7 节）：函数性态、极限的精确定义、两个重要极限、无穷小、连续与闭区间性质。
2. **导数与微分**（5 节）：导数与局部线性化、求导法则、隐函数与参数方程、高阶导数、微分。
3. **导数的应用**（4 节）：罗尔与拉格朗日中值定理、洛必达法则、单调性与极值最值、凹凸性与作图。
4. **一元函数积分学**（9 节）：原函数、基本积分表、换元、分部、定积分、微积分基本定理、广义积分与应用。
5. **空间解析几何**（4 节）：坐标系与向量、平面、空间直线、球面与柱面。
6. **常微分方程**（6 节）：基本概念与可分离变量、一阶线性、可降阶、解的结构、二阶常系数齐次、应用。

## 大学英语

站点层级：**主栏 → 大学英语 → 语法教程**。

- **考纲原文**：[2.1 大学英语考试说明](02_大学英语/2.1-01_大学英语.md)
- **语法教程**：13 章 81 节，另有 4 节导学，共 85 篇。按「词法 → 句法 → 信息」三层编排，每节独立成篇，例题随概念穿插，每章末带小结与自测。

建议从 [0.0 教程说明](02_大学英语/语法教程/00_导学/2.2-01_教程说明：13%20章地图与使用方法.md) 开始，先看 13 章地图、语言点穿插表与三条阅读路线，再按阶段推进：

1. **词性**（9 节）：十类词与句法功能、名词、代词（两节）、数词、形容词与副词、动词、连词、构词法。
2. **五大基本句型**（7 节）：句子成分总图、SV、SVP、SVO、SVOO、SVOC、句型诊断与转换。
3. **冠词与介词**（6 节）：指称与限定、a/an、the 与零冠词、介词的空间隐喻、时间介词、方位介词与搭配。
4. **简单句与并列句**（5 节）：四种扩展、句类、否定与疑问的构造、并列连词、关联并列与标点。
5. **时态**（8 节）：时与体、一般现在、一般过去、将来表达、进行体、现在完成（两节）、过去完成与时态呼应。
6. **被动语态**（5 节）：语篇动机、构成、特殊被动、被动与系表、语篇运用与翻译。
7. **三大从句**（9 节）：从句总图、名词性从句（两节）、定语从句（三节）、状语从句（三节）。
8. **非谓语动词**（6 节）：三形态、不定式、动名词、分词、句法功能与独立主格、选择算法与从句互换。
9. **情态动词**（6 节）：情态系统、can/may、must/have to、should/will/would、情态 + have done、语用。
10. **主谓一致**（4 节）：三原则、并列与伴随、集合名词与数量短语、从句与特殊名词。
11. **虚拟语气**（5 节）：虚拟的本质、条件句三型、混合与倒装、wish 等结构、(should) do。
12. **倒装、强调与省略**（6 节）：语序与焦点、完全倒装、部分倒装、强调句、其他强调手段、省略。
13. **比较句式**（5 节）：比较的语义结构、同级、比较级、最高级、特殊比较与省略替代。
