# 11.2 条件句三型：现在、过去与将来

条件句是虚拟语气最集中的地方，也是错误最集中的地方。

**错**：If I will have more free time, I will join the club.
**错**：If he would study harder, he would pass the exam.
**错**：If I would have known the truth, I would have told you.

第一句把「将来」和「真实条件」搅在一起：真实条件句里，if 从句用一般现在时表将来，不能出现 will。第二句在 if 从句里放了 would，而 would 在虚拟条件句里属于主句。第三句是「双重虚拟」，把两个 would have 叠在一起，形式直接崩掉。

三句的错误都能归结为一个动作：**说话人没有先判断「这件事与事实差多远」，就直接往句子里填时态。**  条件句的三型，本质上是三种距离，不是三个时间。

## 一、与现在事实相反

形式：if 从句用一般过去时（be 动词用 were），主句用 would/could/might + 动词原形。

- If I **had** a car, I **would drive** you to the airport.（如果我有车，我就送你去机场。）现在没有车。
- If she **knew** the answer, she **would tell** us.（如果她知道答案，就会告诉我们。）现在不知道。
- If he **were** more careful, he **would not make** so many mistakes.（如果他用点心，就不会犯这么多错。）现在不够细心。

为什么用过去时表示现在？因为虚拟语气把「形式」往后推一格，用距离告诉对方「这不是现在的事实」。过去时在这里不承担时间功能，只承担「非现实」功能（见 11.1）。** 不要去翻译这个过去时**，一翻译就会糊涂。

主句的三个情态动词有分工：would 表示结果，could 表示能力或可能性，might 表示较小的可能性。

- If I had more time, I **could** finish the whole book.（如果有更多时间，我就能读完这本书。）能力。
- If we left now, we **might** catch the last bus.（如果现在走，也许能赶上末班车。）可能性。

## 二、与过去事实相反

形式：if 从句用 had + 过去分词，主句用 would/could/might + have + 过去分词。

- If I **had set** the alarm, I **would not have been** late.（如果我定了闹钟，就不会迟到。）事实上没定，已经迟到了。
- If they **had left** ten minutes earlier, they **could have caught** the train.（如果早走十分钟，他们就赶上火车了。）事实上没赶上。
- If you **had told** me about the problem, I **might have helped**.（如果你早告诉我这个问题，我也许能帮上忙。）

过去的事情已经无法改变，所以要「推得更远」：现在的事实退一格用过去时，过去的事实退一格就要用过去完成时。这条逻辑贯穿整个虚拟体系。

两个高频错误要单独点出：

**其一，if 从句不能用 would have done。**  汉语说「如果我早知道」，学生会顺手写成 If I would have known。英语的 would 属于主句，if 从句只负责提出条件，不负责给出结果。

**其二，主句的 have 不能丢。**  would have done 是一个整体，写成 would did 或 would done 都不成立。** 考点**：看到 if 从句是 had done，主句一定要有 would have done，两边必须对称。

## 三、与将来事实相反

将来的事还没发生，谈不上「与事实相反」，只能说「可能性很小」或「说话人认为不太可能」。英语给了三种形式，语气从弱到强。

| 从句形式 | 语气 | 例句 |
|---|---|---|
| If + 一般过去时 | 可能性小，最常用 | If it **rained** tomorrow, we **would** stay at home. |
| If + were to do | 计划性、推测性，较正式 | If he **were to resign**, the team **would** be in trouble. |
| If + should do | 可能性最小，「万一」 | If you **should see** him, please give him my message. |

三种形式的共同点是主句都用 would/could/might + 动词原形，因为它们指向的是「将来可能的结果」，不是「已经发生的结果」。

为什么将来要用三种形式？因为「将来」本身就有不同的确信度。were to 暗示这是人为设想的情形，常带「假如真的发生」的意味；should 最客气，几乎是「万一」，常用于礼貌的请求和提醒；一般过去时最中性，是考试和口语里的默认选项。

- If you **should change** your mind, just let me know.（万一你改变主意，告诉我就行。）语气最轻。
- If the company **were to close** the branch, hundreds would lose their jobs.（假如公司真把分部关了，数百人会失业。）设想一个重大情形。

## 四、三型总表与 if 从句的禁忌

| 类型 | if 从句 | 主句 | 语义 |
|---|---|---|---|
| 与现在相反 | 一般过去时（were） | would/could/might + do | 现在不是这样 |
| 与过去相反 | had + 过去分词 | would/could/might + have done | 过去没这样 |
| 与将来相反 | 过去时 / were to do / should do | would/could/might + do | 将来大概不会这样 |

**if 从句不用 would** 是一条硬规则，理由在逻辑：if 从句提出的是条件，条件本身不能是「结果」。If I would have money 相当于「如果我将会有钱」，把结果塞进了条件里，句子就没有条件可谈了。

但这条规则有一个例外，必须分清：**if 从句里的 would 表示「愿意」时是情态动词，不是虚拟助动词，可以出现**。

- If you **would** wait a moment, I'll check the schedule for you.（您愿意稍等片刻的话，我帮您查一下日程。）would = 愿意，礼貌请求。
- If he **would** listen to advice, he wouldn't be in this mess.（他要是肯听劝，就不会弄成这样。）would = 肯。

判断方法：把 would 换成 be willing to，句子意思基本不变，它就是「愿意」，合法；换不通，它就是虚拟助动词，必须删掉。

另一个固定说法是 **If I were you**，用于给建议，永远用 were，不用 was，也不用 am。

## 五、真实条件与虚拟条件：看可能性，不看时间

同样是 if，可以是真实条件，也可以是虚拟条件，区别不在时间，而在说话人对可能性的判断。

| 句子 | 类型 | 说话人的判断 |
|---|---|---|
| If it **rains** tomorrow, we **will** cancel the trip. | 真实 | 明天下雨是可能的 |
| If it **rained** tomorrow, we **would** cancel the trip. | 虚拟 | 明天下雨的可能性很小 |
| If he **is** at home, he **will** answer the phone. | 真实 | 他可能在家 |
| If he **were** at home, he **would** answer the phone. | 虚拟 | 他不在家 |

真实条件句的形式是「主将从现」：if 从句用一般现在时，主句用一般将来时。这条规则和虚拟条件句的「过去时 + would」长得很像，但机制完全不同，混用就会出错。

**错**：If it will rain tomorrow, we will cancel the trip.
**对**：If it rains tomorrow, we will cancel the trip.

真实条件句的 if 从句不用 will 表将来。英语在条件从句里不许诺「将来」，只陈述「现在具备的条件」，将来的意义由主句的 will 承担。这条规则叫「主将从现」，是四级的常考点。

**错**：If I would have more time, I would take another course.
**对**：If I had more time, I would take another course.

从句是与现在事实相反，用过去时 had；would 只能出现在主句。这一句同时犯了「if 从句用 would」和「虚拟形式不全」两个错。

判定顺序建议这样走：先问「这件事可能发生吗」。可能，走真实条件（主将从现）；不可能或可能性很小，走虚拟条件，再问「这个不可能发生在现在、过去还是将来」，选对应的形式。** 先定可能性，再定时态**，顺序反了就会写出 If it will rain 这种句子。

> **一句话总结**：条件句三型对应三种距离，从句退一格、主句加 would，if 从句里永远不放虚拟助动词 would。

### 即学即练

1. 选择：If the flight ______ on time, we would have arrived before dark.
   A. took off　B. had taken off　C. would take off　D. has taken off
2. 填空：If I ______ (be) in charge of the project, I would start with a survey of users.
3. 改错：If you would finish the report by Friday, we will be able to submit the application on time.

<details><summary>参考答案</summary>

1. **B**。主句是 would have arrived，说明与过去事实相反，从句必须用 had taken off。
2. **were**。与现在事实相反，be 动词在虚拟条件句中统一用 were。
3. would finish → **finish**（或 **should finish**）。这里 if 从句提出的是真实条件，用一般现在时表将来；would finish 把虚拟助动词放进了条件里。若确实想表达「您愿意周五前完成」，可写 If you would finish...，此时 would 是「愿意」，但主句应改成 we would be able to，前后保持一致。
