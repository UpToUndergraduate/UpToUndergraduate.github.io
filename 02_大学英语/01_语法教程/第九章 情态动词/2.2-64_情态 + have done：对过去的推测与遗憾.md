# 9.5 情态 + have done：对过去的推测与遗憾

四级作文里常出现这样的句子：

**错**：Last term I should study harder, but I spent too much time on games.
**对**：Last term I should have studied harder, but I spent too much time on games.（上学期我本该更用功，却把太多时间花在游戏上。）

学生想说的是「本该」。汉语的「该」没有形态变化，时间由「上学期」承担；英语的 should 却只能指向现在或将来，要把它拉回过去，必须在后面加一个 have done。

同一个缺口还出现在推测里。看到地上的积水，学生写：

**错**：It must rained last night.
**对**：It must have rained last night.（昨晚肯定下过雨。）

must 后面不能接过去式，这是情态动词的老规矩（见 9.1）。但学生真正没掌握的并不是形式，而是英语处理「过去」的方式：情态动词没有过去完成的形式，过去的痕迹只能留在它后面的动词上。

must have done 和 should have done 长得很像，意义却分属两个系统。前者是**推断**——说话人凭证据判断过去发生了什么；后者是**评价**——说话人认为过去本应发生而没发生。一个谈「是不是」，一个谈「该不该」。这一节要把这条共同的形式线索和它背后的两套意义分开，并且说清它与情态 + do 的时间差。

## 一、形式的统一：情态不动，have 不动

结论只有一句：**情态动词 + have + 过去分词**。三个位置各有分工——情态标态度，have 标「先于参照点」，过去分词标完成或被动。情态永远保持原形，have 永远是 have，不随人称、数、时变化。

| 形式 | 核心意义 | 例句 |
|---|---|---|
| must have done | 肯定推断，把握接近 100% | He must have missed the last bus. |
| can't / couldn't have done | 否定推断，排除可能 | She can't have finished the report so fast. |
| may / might have done | 弱推断，五成上下 | They may have left the office already. |
| should / ought to have done | 本该做而未做 | You should have told me about the change. |
| shouldn't have done | 本不该做却做了 | I shouldn't have said that at the meeting. |
| needn't have done | 做了，但事后看不必 | You needn't have waited for me in the rain. |
| could have done | 本可以做，实际没做 | We could have won the match with a little luck. |
| would have done | 虚拟条件下的结果 | I would have called you if I had your number. |

这张表有一个统一的读法：have done 表示动作发生在「参照点之前」，情态表示说话人怎么看待这件事。八个形式的差别全在情态上，时间信息则完全由 have done 承担。

还有两个形式细节。被动语态嵌进来时，结构是 **情态 + have been + 过去分词**：The window must have been broken by the kids.（窗户肯定是孩子们打破的。）have been 同时承担「更早」和「被动」，情态仍留在最前面。进行体嵌进来时是 **情态 + have been doing**，表示动作从过去持续到参照点：She must have been working all night.（她肯定干了一整夜。）

这就是情态 + have done 与情态 + do 的分界线。

| 形式 | 时间指向 | 例句 |
|---|---|---|
| 情态 + do | 现在或将来 | He must be at home now. |
| 情态 + be doing | 此刻正在进行 | He must be sleeping in his room. |
| 情态 + have done | 先于此刻的过去 | He must have gone home already. |

严格说，have done 不是「过去时」，而是「完成」——它表示动作相对于某个参照点已经结束。情态句的参照点默认是说话的此刻，所以情态 + have done 几乎总指过去。参照点若在未来，同一个 have done 就变成将来完成：By June he will have finished the course.（到六月他就学完这门课了。）所以不能说情态 + have done 是「情态的过去时」，它标的是「更早」，不是「过去」。

**错**：He must forgot to lock the door.
**对**：He must have forgotten to lock the door.（他肯定是忘了锁门。）

错因有两层：must 后不能接过去式；「忘记」发生在「我推断」之前，这层「更早」必须由 have done 承担，不能靠动词变形。

## 二、对过去的推测：must、can't、may 的分工

肯定推断用 must have done，依据是可见的证据，不是随口的猜测：

- The ground is wet, so it must have rained last night.（地面是湿的，昨晚肯定下过雨。）
- He knew the answer, so he must have read the paper before class.（他知道答案，课前肯定读过那篇论文。）

否定推断不用 mustn't have done，而用 can't have done 或 couldn't have done：

- She can't have received my email, or she would have replied.（她不可能收到我的邮件，否则早回了。）
- They couldn't have finished the report in a single night.（他们不可能一夜之间写完报告。）

这里有一个中国学生最常踩的坑。mustn't 在英语里是「禁止」（见 9.3），根本不承担否定推断的功能。must 的推断义由 can't 来否定，这与 must 的义务义用 don't have to 否定是同一个道理：**情态的否定常常换词，不换词就换义。** 

弱推断用 may have done 或 might have done，把握在五成上下：

- She may have left her keys in the office.（她可能把钥匙落在办公室了。）
- They might have taken the wrong train this morning.（他们今天早上也许上错了车。）

might 比 may 更犹豫，过去形式带来额外的距离感（见 9.2）。could have done 也能表推测，但它同时承担「本可以」的虚拟义，容易歧义，写作中表推测优先用 may/might。

推测句常带 last night、already、by then 这类时间标记，但它们是判断的线索，不是使用 have done 的条件。只要被推断的动作先于说话时刻，就必须用 have done，句子有没有时间状语都一样。

**考点**：must have done 的反义表达是 can't have done。选择题里 mustn't have done 几乎总是错的。

**错**：He mustn't have seen the notice, or he would have come.
**对**：He can't have seen the notice, or he would have come.（他不可能看到通知，否则就来了。）

错因：mustn't 表禁止，用它表「不可能」是把道义情态错接到了认识情态上。否定推断的专用形式是 can't / couldn't have done。

## 三、本该与本不该：should have done 的两副面孔

should have done 的核心是「按理应该发生，实际没有发生」。它不陈述事实，而是拿事实与一个标准对照，落差就是情绪。

对自己，落差是后悔：

- I should have checked the address before sending the parcel.（寄包裹前我该核对地址的。）
- We shouldn't have spent so much on that dinner.（那顿饭我们不该花那么多钱。）

对别人，落差是批评或提醒：

- You should have told me about the change earlier.（你该早点告诉我这个变动。）
- He ought to have apologized, but he never did.（他本应道歉，却始终没有。）

ought to have done 与 should have done 同义，语气更正式、道义色彩更重，多用于书面议论。口语和邮件里用 should 更自然。

shouldn't have done 只表示「做了不该做的事」，不表示「没做该做的事」。翻译时容易混：

- 你本不该告诉他。→ You shouldn't have told him.
- 你本该告诉他。→ You should have told him.

should have done 还有第二种用法：表「按理应该已经」，是推断而不是批评。

- The parcel should have arrived by now.（包裹现在应该到了。）

这句的重音落在 by now，说话人是按常规推算，不是责怪谁。判断依据看主语和动作性质：主语是人、动作可控，多半是批评；主语是物或不可控事件，多半是推断。

**错**：You should came to the meeting yesterday.
**对**：You should have come to the meeting yesterday.（你昨天该来开会的。）

错因：should 后必须接原形，不能直接接过去式；「昨天」这层时间只能由 have come 承担。

## 四、没有发生的那条路：could、might、would have done

这三个形式都指向「本来可能发生、实际没有发生」的分支，区别在说话人强调什么。

could have done 强调「有能力、有机会，但没做」：

- I could have finished the report by noon, but the network went down.（我本来中午前能写完报告，但网络断了。）

它还可以用于委婉的批评：You could have at least sent a message.（你至少可以发条消息。）这句话的杀伤力比 You should have sent a message 更大，因为它暗示「你明明做得到」。

要注意它与 was able to do 的分工。She could have passed the exam 是说她本可以通过（实际没有）；She was able to pass the exam 是说她当时确实通过了。前者指向没走的那条路，后者陈述已经发生的事实，两者不能互换。

might have done 强调「概率上的另一种结果」：

- If we had left ten minutes earlier, we might have caught the train.（要是早走十分钟，我们也许就赶上火车了。）

would have done 是虚拟条件句主句的标配，表示「如果……就会……」：

- I would have applied for the job if I had known about it.（要是早知道这个职位，我就申请了。）

这三个形式常与 if 从句配合，构成第 11 章讲过的第三类条件句（见 11.2）。** 考点**：从句用 had done，主句用 would/could/might have done，两边不能只变一边。

**错**：If you told me earlier, I might helped you.
**对**：If you had told me earlier, I might have helped you.（你要是早点告诉我，我也许就帮上忙了。）

错因：与过去事实相反的假设，从句要用 had done，主句要用 might have done。原句两边都停在「过去时 + 原形」，是把第二类和第三类条件句混在了一起。

## 五、needn't have done 与 didn't need to do：做了与没做

这一组是专升本选择题和四级改错的常客，因为两个形式的字面意思几乎一样，实际所指相反。

needn't have done：**做了**，但事后看没有必要，含「白做了」的意味。

- You needn't have bought so much food; we already had plenty.（你本不必买这么多吃的，我们本来就有很多。）

didn't need to do：**没有必要**，通常**没有做**，只是陈述当时的情况。

- I didn't need to buy any food, so I cooked what was in the fridge.（我不需要买吃的，就用冰箱里的东西做了饭。）

| 形式 | 实际做了吗 | 说话人的态度 |
|---|---|---|
| needn't have done | 做了 | 可惜、轻微责备、浪费 |
| didn't need to do | 通常没做 | 中性陈述 |

needn't have done 的前提是动作确实发生了。对方根本没等，就不能说 You needn't have waited，只能说 You didn't need to wait.（你不必等的。）

美式口语里 didn't need to 有时也被用来替代 needn't have done。考试仍按上表区分：要点明「白做了」，一律用 needn't have done，这样不会出错。

**错**：You needn't waited for me at the station.
**对**：You needn't have waited for me at the station.（你本不必在车站等我的。）

错因：needn't 是情态动词，后面只能接原形；要表达「已经等了」，必须用 have waited。

> **一句话总结**：情态 + have done 把态度标在过去：must/can't 管推断，should 管亏欠，could/might/would 管那条没有走的路。

### 即学即练

1. The road is still wet, so it ______ last night.
   A. must rain　B. must have rained　C. should have rained　D. can't have rained
2. 填空：You ______ (not, need) ______ (buy) so much food; the fridge is already full.
3. 改错：You should came to the meeting yesterday. / He mustn't have seen the notice.

<details><summary>参考答案</summary>

1. **B**。地面还是湿的，是可见证据，构成肯定推断；「昨晚」先于此刻，必须用 must have done。C 表「本该下雨」的评价，D 表否定推断，都与证据方向相反。
2. **needn't have bought**。食物已经买了，才说「本不必」，用 needn't have done。若写成 didn't need to buy，意思是当时不需要买，通常暗含没买。
3. 第一句改 **You should have come to the meeting yesterday.** should 后接原形，过去的未实现由 have come 承担。第二句改 **He can't have seen the notice.** 否定推断用 can't have done，mustn't 表禁止，不能用于推断。
