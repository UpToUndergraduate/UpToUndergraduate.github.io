# 11.3 混合虚拟、倒装与含蓄条件

11.2 的三型有一个隐含前提：条件和结果发生在同一个时间。真实的表达经常不这么整齐。

**错**：If I had studied medicine, I am a doctor now.
**错**：Had I if known the truth, I would have acted differently.
**错**：But for your help, I would fail the exam yesterday.

第一句的条件在过去（当初学医），结果却在现在（现在是医生），两半不能都用同一型；第二句把倒装和 if 叠在一起，等于给从句装了两个引导词；第三句用 but for 代替了 if 从句，却把主句写成了与现在相反的形式，而事情发生在昨天。

三句说明：**虚拟的形式服务于「距离」，而距离可以分段计算。** 条件离现实有多远，结果离现实有多远，可以不一样；条件也可以用介词短语、副词甚至一个连词来承担，不必写成 if 从句。

## 一、混合虚拟：条件和结果不在同一时间

条件句的两半各有各的时间，只要分别判断，就不会乱。

| 组合 | 从句 | 主句 | 例句 |
|---|---|---|---|
| 过去条件 + 现在结果 | had done | would do | If I **had taken** the job, I **would be** in Shanghai now. |
| 现在条件 + 过去结果 | 过去时（were） | would have done | If I **were** more careful, I **wouldn't have made** that mistake. |
| 过去条件 + 将来结果 | had done | would do（+ 将来时间） | If we **had booked** earlier, we **would be** flying tomorrow. |

- If I **had taken** the job in Shanghai, I **would be** earning twice as much now.（当初要是接了上海那份工作，我现在收入会翻倍。）
- If she **were** better at numbers, she **wouldn't have lost** that client last month.（她要是数字再强一点，上个月就不会丢掉那个客户。）

判断的抓手是**时间状语**。now、at the moment、these days 指向现在；last month、yesterday、at that time 指向过去。先看主句的时间状语定主句，再看从句说的事发生在什么时候定从句，两半各走各的。

为什么允许这种错位？因为虚拟语气标记的是「非现实」，不是「同一时间」。只要每一半各自表达了它该表达的距离，句子就成立。反过来，很多学生一看到 if 从句用了 had done，就把主句也写成 would have done，结果把「现在是医生」说成了「过去会是医生」，时间整个错位。

**错**：If I had studied medicine, I would have been a doctor now.
**对**：If I had studied medicine, I would be a doctor now.

now 已经把主句锁定在现在，用 would have been 就自相矛盾。

## 二、省略 if 的倒装

if 可以省略，代价是**从句必须倒装**：把 were、had、should 提到主语前面。

| 倒装形式 | 还原后 | 例句 |
|---|---|---|
| Were I ... | If I were ... | **Were I** you, I would ask for more time. |
| Had I ... | If I had ... | **Had I** known earlier, I would have changed my plan. |
| Should he ... | If he should ... | **Should he** call, tell him I'm in a meeting. |

还原的方法很机械：把提到句首的 were/had/should 放回主语后面，前面补上 if。

- **Were it not for** the rain, we would be at the beach.（要不是下雨，我们就在海滩上了。）= If it were not for the rain.
- **Had it not been for** your support, I would have given up.（要不是你的支持，我早就放弃了。）= If it had not been for your support.
- **Should you need** any help, just call this number.（万一你需要帮助，打这个电话。）= If you should need any help.

否定的倒装有两种写法：Had I not known 或 Hadn't I known。前者更正式，后者多见于口语；考试里遇到，按 Had I not 理解。

**错**：Had I if known the truth, I would have acted differently.
**对**：Had I known the truth, I would have acted differently.

倒装是「省略 if」的补偿手段，两者只能取其一。既倒装又保留 if，等于一个从句有两个引导词，结构不成立。

倒装句在写作里的作用是调节语气：Were I you 比 If I were you 更书面、更凝练，适合议论和正式书信；口语里说 If I were you 更自然。**不要为了显得高级而整篇倒装**，一段里出现一次就够。

## 三、含蓄条件：条件藏在短语里

条件不一定写成从句。英语有一批词和短语，本身就把「如果不是这样」压缩了进去。

| 表达 | 相当于 | 例句 |
|---|---|---|
| but for + 名词 | If it were not for / If it had not been for | **But for** your help, I would have failed. |
| without + 名词 | If there were no / If we had not had | **Without** water, no plant could survive. |
| otherwise | If that had not happened | I was ill; **otherwise** I would have come. |
| or | If you don't / If you didn't | Hurry up, **or** we will miss the train. |
| but that | except that | He would have come, **but that** he was ill. |

- **But for** the traffic jam, we would have arrived on time.（要不是堵车，我们就准时到了。）
- **Without** your encouragement, I would never have finished the course.（没有你的鼓励，我根本读不完这门课。）
- The alarm went off at six; **otherwise** we would have overslept.（闹钟六点响了，否则我们就睡过头了。）

判断主句形式的方法和 if 从句一样：看主句说的是现在还是过去。but for 后面跟的是名词，不携带时间信息，时间只能从主句和上下文推。

**错**：But for your help, I would fail the exam yesterday.
**对**：But for your help, I would have failed the exam yesterday.

yesterday 把结果锁定在过去，主句必须用 would have done。但 for 本身不告诉你时间，很多人误以为它只配 would do。

还有一处混用要避免：**but for 与 if 不能叠加**。But for if you hadn't helped me 是双重条件，正确写法是 But for your help 或 If you hadn't helped me，二选一。

## 四、语篇功能：遗憾、批评、建议

虚拟语气在篇章里主要干三件事，语气由弱到强。

| 功能 | 常用形式 | 例句 |
|---|---|---|
| 建议（委婉） | It would be better if ... / You might want to ... | **It would be better if** we met earlier. |
| 批评（克制） | could have done / should have done | You **could have told** me about the delay. |
| 遗憾（强烈） | If only ... / I wish ... | **If only** I had checked the address. |

这三种功能共享一个语用逻辑：**说话人不想把话钉死在事实上，所以退后一步说**。建议用虚拟，是不想显得命令；批评用虚拟，是把指责包装成「本来可以」；遗憾用虚拟，是承认事实无法更改。

与情态动词 + have done 的衔接也在这里（见 9.5）。should have done 表示「本该做而没做」，could have done 表示「本来能做」，needn't have done 表示「本不必做」，三者的形式骨架与虚拟的 would have done 相同，都是「情态动词 + 完成体」。区别在于：虚拟语气需要一个非现实的条件或愿望作依托，情态 + have done 可以独立成句，直接对过去作出评价。

- If you had told me, I **could have helped**.（虚拟，依赖 if 从句）
- You **could have helped**, but you didn't even ask.（情态，独立评价）

**写作提示**：虚拟语气在议论文里适合表达建议和反事实推论，一篇 150 词的短文出现两三次足够。通篇 if I were、if I had 会让文章显得空想，缺少事实支撑。

## 五、常见错误与判定

**错**：Were I to accept the offer, I would have resigned from my current job last week.
**对**：Were I to accept the offer, I would resign from my current job.

Were I to do 指向将来，主句不能用 would have done 指向过去。若事情确实发生在过去，从句要改成 Had I accepted the offer，主句才是 would have resigned。

**错**：Without your advice, I would make a wrong choice last year.
**对**：Without your advice, I would have made a wrong choice last year.

without 引出的条件本身不带时间，时间只能从主句读。last year 已把结果锁定在过去，主句必须用 would have done。含蓄条件的难点正在这里：条件没有形态，判断时间全靠主句的状语。

一旦句子有两个结果、分别落在两个时间上，就要拆开各自处理：

- **Without** your advice, I **would have made** a wrong choice last year, and I **would regret** it now.（要不是你的建议，我去年就选错了，到现在都会后悔。）

前半句结果在过去（would have made），后半句结果延续到现在（would regret）。判断时把两个分句拆开，各自对时间，不要用一条规则套全句。

判定流程可以固定成四步：

1. **找条件**：是 if 从句、倒装句，还是 but for/without/otherwise/or 这类含蓄条件。
2. **给条件定时**：现在、过去、将来。
3. **给结果定时**：看主句的时间状语，不要被从句带走。
4. **配形式**：过去条件用 had done，现在/将来条件用过去式，过去结果用 would have done，现在/将来结果用 would do。

四步里第三步最容易被跳过。多数混合虚拟的错，不是不知道形式，而是没意识到两半可以不同时。

> **一句话总结**：条件和结果可以各走各的时间，省略 if 必须倒装，but for 与 without 是把条件压缩进短语的 if。

### 即学即练

1. 选择：______ it not for the support of my family, I would have dropped out of school.
   A. If　B. Were　C. Had　D. Should
2. 填空：If I had followed your advice, I ______ (not, be) in such a difficult situation now.
3. 改错：Had I if taken the earlier train, I would be at the office by now.

<details><summary>参考答案</summary>

1. **B**。Were it not for 是 If it were not for 的倒装形式；空格后是 it not for，说明 were 已提到句首。若用 Had，需要搭配 been：Had it not been for。
2. **would not be**。条件在过去（had followed），结果在现在（now），属于混合虚拟，主句用 would do。
3. 删去 **if**。Had I taken the earlier train 已经是省略 if 的倒装句，不能再保留 if；主句 would be at the office by now 与现在结果一致，保持不变。
