# 0.0 教程说明：13 章地图与使用方法

这是一套按「词法 → 句法 → 信息」三层结构编写的英语语法教程，共 13 章、81 节。它不追求把语法知识一次讲完，而是按写句子的实际顺序组织：先认识词，再搭骨架，再处理复杂结构，最后才是情态、虚拟、倒装这些「包装」手段。

如果你是从「大学英语」这一栏点进来的，建议先读 2.1 的考试说明，了解考查范围；再回到这里，按下面的路线进入语法正文。

## 一、为什么这样分章

多数语法书的目录是「名词—冠词—代词—时态—从句—虚拟」，这是**知识的分类**，不是**使用的顺序**。真正写一个句子时，人的注意力是这样走的：

1. 先选词，决定每个词能占什么位置（第 1 章）；
2. 再选谓语动词，决定句子需要哪些成分（第 2 章）；
3. 给名词短语定位：特指还是泛指，用什么介词（第 3 章）；
4. 把短句接长、把对等的成分并列（第 4 章）；
5. 给动作定位：什么时候、什么视角（第 5 章）；
6. 决定谁作话题：主动还是被动（第 6 章）；
7. 把句子嵌进句子：三大从句（第 7 章）；
8. 把从句压成短语：非谓语（第 8 章）；
9. 表达态度：推测、义务、许可（第 9 章）；
10. 让谓语跟主语对齐（第 10 章）；
11. 表达非事实：虚拟（第 11 章）；
12. 调整焦点：倒装、强调、省略（第 12 章）；
13. 准确比较（第 13 章）。

这套顺序有一个好处：每一章都在用前一章的结构。讲从句时，你已经会分析成分；讲非谓语时，你已经会区分主谓；讲虚拟时，你已经熟悉时态与情态。**语法不再是并列的条目，而是一条生成链。**

## 二、三阶段与 13 章

| 阶段 | 章 | 主题 | 学完能做到 |
|---|---|---|---|
| 阶段一：基础骨架 | 1 | 词性 | 判断词性与句法功能 |
| | 2 | 五大基本句型 | 拆出任何句子的主干 |
| | 3 | 冠词与介词 | 决定名词短语的指称与关系 |
| | 4 | 简单句与并列句 | 扩展短句，正确并列 |
| | 5 | 时态 | 给动作定位，选对时与体 |
| | 6 | 被动语态 | 决定谁作话题，正确转换语态 |
| 阶段二：复杂句子 | 7 | 三大从句 | 让句子充当主语、定语、状语 |
| | 8 | 非谓语动词 | 把从句降级成短语 |
| 阶段三：进阶句式 | 9 | 情态动词 | 表达推测、义务、许可与委婉 |
| | 10 | 主谓一致 | 在复杂主语中找对谓语形式 |
| | 11 | 虚拟语气 | 表达与事实相反、愿望与建议 |
| | 12 | 倒装、强调与省略 | 调整焦点，写出有标记的句子 |

阶段一是「写得对」，阶段二是「写得长」，阶段三是「写得准、写得有重点」。三个阶段不是难度递增，而是**关注点递增**：从词，到句，到说话人的意图。

## 三、代词、数词、连词放在哪

这三类语言点没有单独成章，而是按「第一次需要它」的位置插入，再在更高层级的结构里复现。

| 语言点 | 首次系统讲 | 复现与深化 |
|---|---|---|
| 代词 | 1.3 人称/物主/反身/指示；1.4 不定/相互/it | 7.4 关系代词；12.4 强调句的 it；13.5 that of / those of |
| 数词 | 1.5 基数、序数、分数、倍数 | 3.5 时间与日期；10.3 分数作主语；13.2–13.3 倍数比较 |
| 连词 | 1.8 并列与从属连接系统 | 4.4–4.5 并列句；7.7–7.9 状语从句 |
| 冠词 | 3.1–3.3 指称、a/an、the 与零冠词 | 7.3 同位语从句；10.4 the + 形容词表一类 |
| 介词 | 3.4–3.6 空间隐喻、时间、搭配 | 6.2 by/with；8.5 with 复合结构；13.5 compare with/to |
| 构词法 | 1.9 派生、合成、转化 | 阅读猜词；9.6 学术 hedging 的词汇选择 |

安排逻辑是：**语言点不按「知识块」出现，而按「使用需求」出现。** 讲关系代词时，代词的人称与格已经在前文学过；讲倍数比较时，数词的分数与倍数已经打过底。复现不是重复，而是把同一个形式放进更复杂的结构里再判断一次。

## 四、每一节长什么样

每节 2000–3500 字，结构固定，便于快速定位：

1. 一个错句或语言现象开场，点明本节要解决的问题；
2. 3–5 个带编号的小节（一、二、三……），先结论、再例句、再对比；
3. 至少一张表格，至少两组「错 / 对」对比；
4. 一行「一句话总结」；
5. 「即学即练」3 题，答案解析折叠在文末。

每章最后一节额外带「本章小结」（形式—意义—使用三列表 + 3 条判断口诀）和「章末自测」（6 题）。读完一章，先做自测，再决定要不要重读。

## 五、三条阅读路线

**系统学习（7 周）**：从 0.1 开始，按第 1 章到第 13 章顺序读，每天一节，周末复盘错题。适合基础薄弱、准备时间充足的人。

**查漏补缺（按需）**：先做每章章末自测，错的章节再读正文。适合能写简单句、但长句和写作失分多的人。建议至少补读第 1、2、5、7、8 章。

**考前冲刺（2 周）**：只读每节「一句话总结」、每章「本章小结」与章末自测，配合错题本。适合已有基础、需要快速唤醒的人。

## 六、和其他栏目怎么配合

- **2.1 大学英语考试说明**：先看考查范围与题型，再决定语法的投入比例。
- **2.2 英语课程标准**：语法知识在课程标准中的定位，以及「形式—意义—使用」三维目标的来源。
- **词汇工具**：语法解决「怎么放」，词汇解决「放什么」。两者要并行，不要等语法学完再背单词。

## 七、编写体例

正文以 Markdown 编写，按 `NN_章/N.M_节.md` 编号；例句英文用半角标点，讲解用中文全角标点；错句前标 `*`，可接受但有争议的句子标 `?`；「考点」标记只出现在真正容易失分的地方。

语法术语在 0.3 统一约定，正文不再重复解释。遇到不确定的术语，回 0.3 查。

> **一句话总结**：这套教程按写句子的顺序编排——先词，再句，再包装；每节只解决一个问题。
